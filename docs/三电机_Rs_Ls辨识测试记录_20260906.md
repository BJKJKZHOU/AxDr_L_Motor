## 1. 记录范围

本文整理粗测电流斜率限制完成后，三台不同电机各 5 次 Rs/Ls 辨识结果。
仅使用 2026-09-06 已生成的 JSON 和对应终端输出，不进行额外复测。

共同测试条件：

- 母线电压约 `14.6 V`；
- commissioning current limit：`2.0 A`；
- host current guard：`2.2 A`；
- 每台电机执行 5 次 Rs/Ls 辨识；
- 单次辨识超时：`20 s`；
- 不 Apply Rs/Ls 到 RAM；
- 使用 `--skip-flux`，不执行 Flux 辨识；
- FAST/NORMAL 遥测允许丢帧数均为 0。

## 2. 验收口径

重复性采用相对中值的最大偏差：

```text
repeatability = max(abs(value - median)) / median
```

门槛与固件 `Rs_Ls.c` 内部 A/B/C 一致性要求保持一致：

| 参数 | 重复性门槛 |
|---|---:|
| Rs | `10%` |
| Ls | `15%` |

原始 Pp=11 JSON 由旧版脚本按 Rs/Ls 共用 `10%` 门槛生成，因此其中保留
`quality_failed`。本文不修改原始 JSON，只按 Rs `10%`、Ls `15%` 重新复核，
结果为 PASS。

## 7. 结论

1. 基于测量窗口时长限制粗测电流上升斜率后，三台不同阻抗量级的电机均完成
   5/5 次辨识，单轮时间为 `1.54～1.99 s`。
2. 三台电机的最大相电流峰值分别为 `1.611 A`、`1.853 A` 和 `1.692 A`，
   均低于 `2.0 A` commissioning current limit。
3. 按固件一致的 Rs `10%`、Ls `15%` 门槛，三组结果均为 PASS。
4. Pp=11 电机的 Ls 重复性 `10.45%` 高于旧主机统一门槛 `10%`，但低于固件
   Ls 门槛 `15%`；该差异属于验收口径差异，不是单轮辨识失败。
5. 本轮结果只确认完成率、重复性和电流峰值，不构成 Rs/Ls 绝对精度标定；三组
   Rs/Ls 均未 Apply 到固件 RAM。
