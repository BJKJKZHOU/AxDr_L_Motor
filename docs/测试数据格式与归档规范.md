# 测试数据格式与归档规范

适用于 AxDr_L_Motor 的固件实测、USB Plot 时域采集、控制环频响和离线分析。
本文件是**文件命名、数据格式、目录与质量标记的唯一权威规范**；
各专题文档只记录实际测量条件、分析口径和结论，不重新定义通用格式。

## 1. 工具职责与数据来源

| 工具 | 职责 | 可接入硬件 |
| --- | --- | --- |
| `tools/fft.py` | 普通 FAST/NORMAL USB Plot 采集；保存原始波形；从完整波形计算 FFT/PSD | 只通过 USB |
| `tools/current_waveform.py` | 离线重绘三相电流、局部时域与电角度周期叠加、正弦基波拟合 | **不接入硬件** |
| `tools/current_frf.py` | 需要固件正弦注入的电流/速度频率响应和 Bode 专用测试 | USB |
| `tools/plot_test.py` | USB Plot 协议、吞吐和基本完整性检查 | USB |

普通采集使用原有 AxDr USB Plot 的 `PLOT_CONFIG → START → FAST/NORMAL_DATA → STOP`。

## 2. 文件目录与命名（必须遵守）

```text
test-data/YYYYMMDD_测试主题/             # 本地测试，受 .gitignore 忽略
    Current-PI-6000RPM-2026-10-18.waveform.nmixx
    ...
docs/data/YYYYMMDD_测试主题/              # 确认长期价值后人工挑选正式归档
    Current-PI-6000RPM-2026-10-18.waveform.nmixx
    Current-PI-6000RPM-2026-10-18.waveform.png
    ...
```

- 一次实验及其多个控制器、带宽、前馈状态放在**同一个** `YYYYMMDD_测试主题/`；
  `YYYYMMDD` 是本地实验日期，主题使用简洁英文下划线命名，避免跨平台路径问题。
- 数据文件统一 `测试名称-YYYY-MM-DD.类型.nmixx`；示例：
  `Current-D-2026-10-10.bode.nmixx`、
  `Current-Noise-2026-10-18.fft.nmixx`、
  `Current-PI-6000RPM-2026-10-18.waveform.nmixx`。
  类型后缀一律小写，不能使用固定名称 `BODE.NMIXX`。
- 对应图片使用相同基础名加 `.<类型>.png`；波形额外分析图允许
  `.waveform-phase.png`、`.waveform-comparison.png`，不引入新数据类型。
- 同一目录同名文件**拒绝覆盖**。同日重复实验在测试名称加入
  `-Repeat2`、`-FF0`、`-BW2000Hz` 等工况后缀，或另建批次目录。
- `test-data/` 保留本机全部原始数据、失败尝试与诊断信息，不默认推送 Git。
  `docs/data/` 只归档必要的 `.nmixx` 与 PNG；不额外放重复 CSV、JSON、
  临时分析脚本、SVG 或逐次实验 README。一般功能测试仅记录专题 Markdown。
- 不修改、重命名、批量重写已归档的历史 Bode/FFT/PSD；旧 `.raw/.i16/.npz/.axdr`
  允许在兼容工具中离线读取，但不是新的正式归档格式。

## 3. NMIXX 格式与版本

`.nmixx` **不是自造二进制容器**，内部是标准 NumPy NPZ/NPY（ZIP）。
推荐 `numpy.load(path, allow_pickle=False)`，不保存 pickle 对象。
每种类型独立维护 `format_version`，不得把所有类型强行升为同一版本。

| 类型 | 后缀 | 当前版本 | 权威保存内容 |
| --- | --- | --- | --- |
| 频率响应 | `.bode.nmixx` | v2 | 实际频点、Ref/Fbk/Out 复数相量、增益参数和质量字段 |
| 快速傅里叶变换 | `.fft.nmixx` | v1 | 频率轴、复数频谱、窗口及通道配置 |
| 功率谱密度 | `.psd.nmixx` | v1 | 频率轴、线性 PSD（单位²/Hz）、窗口配置 |
| 原始时域数据 | `.waveform.nmixx` | v1 | Plot 原始数值、通道元数据、帧完整性和工况 |

Bode 详细字段（`ref/fbk/out`、`quality`、`point_valid`、`fit_residual`
等）沿用 `tools/current_frf.py`；FFT/PSD 沿用 `tools/fft.py` 的
`freq_hz/spectrum/segment_length/segment_count`。不为波形绘图另存一份
由原始数据换算出来的浮点 CSV/NPZ。

### Waveform v1 的必要字段

| 字段 | 类型 / 形状 | 语义 |
| --- | --- | --- |
| `format_version`、`kind`、`group` | int32 / 字符串 | v1、waveform、fast 或 normal |
| `sample_rate_hz` | float64 | 采样率；FAST 20000、NORMAL 1000 |
| `raw_samples` | `[N,C]` | FAST 原始 int16 或 NORMAL 原始 float32，未重新量化 |
| `channel_id/name/unit/scale` | `[C]` | 参数 ID、标准名、单位及 FAST int16→物理单位比例 |
| `frame_seq`、`frame_sample_count` | `[F]` | 实际收到的包序号和每包样本数，用于重建和审计 |
| `usb_seq_lost`、`malformed_frames` | 整数 | USB 层检测到的丢帧和格式错误 |
| `firmware_drop_before/after` | int64 | 采集前后通过 USB Parameter 读到的累计丢块数，-1 表示未知 |
| `quality`、`quality_reason` | 字符串 | valid / invalid / unknown 及原因 |
| `captured_at`、`metadata_json` | 字符串 | 本地时间与可选工况标签、固件 SHA、极对数、目标 RPM 等 |

波形电流本身应当直接从 `raw_samples * channel_scale` 解码；
`channel_scale` 随文件保存，不能把后来改变的参数生成文件套在旧波形上。
`metadata_json` 是容器中的一个字符串字段，**不是额外的 JSON 文件**；
只能保存实际已知的工况，不知道的值应留空而非推测。

## 4. USB 数据完整性与质量门槛

固件 `Comm/Plot.c` 中，FAST 先将 20 个 PWM 周期合成一个内部数据块。
`Plot_Fast_Drop` 在块未能发送前被覆盖时递增；`Fast_Seq` 在数据
被打包发出时才递增。因此仅仅 `seq_lost=0` **不能证明板端没有丢块**。

新固件通过既有 USB Parameter READ 提供只读：
`PARAM_PLOT_FAST_DROP=0x0030`、`PARAM_PLOT_NORMAL_DROP=0x0031`，
不修改 FAST/NORMAL Plot 数据帧格式；采集前后读两次，不连接调试器。
FAST 的每个丢块对应 20 个 FOC 采样点。

- **valid**：该段 USB 帧序号连续、无格式错、帧内计数与原始数值吻合，
  固件丢块计数成功读取且前后增量为零，接收量达到预期时长的基本检查。
  这只证明**数据传输和采样序列完整性**，不证明真实相电流正确。
- **invalid**：USB 丢帧、格式不正确、固件丢块增量非零或数量明显不足。
  必须保留可用的原始内容与状态，**不得压缩时间轴拼接成连续波形**。
- **unknown**：老固件无法通过 USB 读取板端丢块计数、缺少质量字段
  或历史格式证据不足。可离线查看接收顺序，不得声称原始序列连续。

只有 valid 波形允许按 `n/Fs` 构建连续时间轴，并作为正式 FFT/PSD、电角度周期叠加和基波拟合的输入；
其他波形以**接收样本索引散点**展示，并说明无法确认真实时间间隔。
电角度的同步与 ADC 的真实采样孔径仍需专项硬件验证。
旧 `.raw` 若确需探索性 FFT/PSD，结果必须保留 unknown 质量标记，不能视为正式连续频谱。
通信质量与真实绕组电流质量不能混为一谈。

## 5. 绘图与分析

统一输出横向 A4、180 DPI 的 PNG，轴有单位和网格；不绘制经过未声明
平滑、插值或滤波的“原始”电流波形。三相电流一图同轴，支持原始全程与
5 ms 局部采样点放大，质量未知时不连接跨缺口的线。
如果归档同时包含 `theta_e` 且质量 valid、角度覆盖足够多电周期，
可以按电角度叠加多个周期并拟合直流项 + sin/cos 基波；图中残差
**包含谐波、测量扰动、采样误差和拟合误差，不能直接命名为 ADC 噪声**。

Bode 使用原约定的横向 A4、上幅值下相位；FFT/PSD 横轴固定到各组
奈奎斯特频率。无效或未知的相量/采样不能被伪装成可靠带宽、THD 或稳定裕度。
