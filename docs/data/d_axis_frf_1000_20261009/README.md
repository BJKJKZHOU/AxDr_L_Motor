## 采样与计算

FAST 同步记录 Injection、实际 IdRef、Id、UdPI，四通道均以 0.001 的比例转换 int16 样本。每频点舍弃开始的 `max(4 个周期, 50 ms)`，以含直流项的正余弦最小二乘拟合同频相量。

闭环响应 `T = Id / IdRef`。图中的 `S = 1 − T`、`L = T / S` 由闭环数据推算，并非独立断环采样。相位不人为扣除延迟。相对 −3 dB 阈值以最低三个频点的闭环增益均值为基准；交叉频率在相邻采样点之间按对数频率插值。
