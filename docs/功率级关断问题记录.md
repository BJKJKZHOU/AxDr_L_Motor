# 功率级关断问题记录

更新时间：2026-08-22
问题类别：功率级安全语义 / 快慢环责任边界

## 1. 问题摘要

Flux 四点辨识完成后曾出现间歇性过流。Iq 收流已经正常，但快环返回
`FAST_OFF` 后功率级仍然输出三相 `50%` Duty 的零矢量。旋转 PMSM 在这个状态下是短路制动，不是端子高阻。

这一问题必须保留三阶段数据：

```text
7.452 A -> 2.618 A -> 0.403 A
```

它直接证明：

```text
FAST_OFF != 0 V SVPWM
0 V SVPWM != PWM Hi-Z
```

## 2. 三阶段定位过程

| 固件 | 结束处理 | 记录到的相电流峰值 | 结论 |
|---|---|---:|---|
| `0981105` | Iq 按 `20 A/s` 降到 0，随后返回 `FAST_OFF` | `7.452 A` | 收流正常，但 `FAST_OFF` 后仍输出零矢量 |
| `2305372` | `2 kHz` Motor Control 发现辨识完成后关闭 PWM | `2.618 A` | 零矢量窗口缩短，但仍有约 `150 us` 调度延迟 |
| `f58ac04` | `20 kHz` ADC 快环在 `FAST_OFF` 同周期关闭 PWM | 五次最大 `0.403 A` | 立即进入 Hi-Z，结束尖峰消失 |

### 2.1 `7.452 A`：零电压指令仍是主动 PWM

`0981105` 中 FINISH Iq 斜坡本身正常：

```text
FINISH start Iq         ~= 1.419 A
Iq decrease             = 20 A/s
phase current <= 0.2 A  = 40 consecutive samples = 2 ms
```

连续 `2 ms` 满足收流判据后，状态进入 DONE，但相电流立即上升：

```text
sample 386608  phase peak = 0.081 A
sample 386609  phase peak = 0.564 A
sample 386610  phase peak = 1.732 A
sample 386611  phase peak = 2.417 A
sample 386627  phase peak = 7.452 A
```

`Ia=-7.452 A` 在多个样本保持不变，表明 ADC 已削顶，真实瞬时峰值可能更高。
`Id/Iq/Ud/Uq` 已停止更新，排除 Iq 斜坡跟踪失败。

旧路径在 `FAST_OFF` 中将电压指令清零，但 `ADC_Run()` 仍继续：

```text
SVPWM_Calc(0, 0, Vbus)
PWM_Update(0.5, 0.5, 0.5)
```

三相 Duty 相等只表示线电压指令为零。TIM1 MOE 和输出通道仍开启时，逆变器会主动将三相端子周期性连接到同一母线电位。旋转电机产生的反电势因而形成制动电流。

### 2.2 `2.618 A`：慢环最终关断仍不够快

`2305372` 改由 `2 kHz` Motor Control 在辨识完成后执行 `PWM_Disable()`：

```text
sample 386816  phase peak = 0.645 A
sample 386817  phase peak = 1.652 A
sample 386818  phase peak = 2.618 A
sample 386819  phase peak = 0.081 A
```

电流上升只持续约 `150 us`，随 `PWM_Disable()` 生效立即恢复。这证明慢环最终能进入
Hi-Z，但快环 DONE 与下一次 Motor Control 之间的调度窗口仍足以触发过流。

### 2.3 `0.403 A`：快环同周期释放功率级

`f58ac04` 在 `ADC_Run()` 中明确解释 `FAST_OFF`：Motor State 仍为 RUN 时立即调用
`PWM_Disable()`，记录 FAST 样本后直接结束本周期，不再执行 `SVPWM_Calc` 和
`PWM_Update`。`2 kHz` Motor Control 只保留状态收尾职责。

修复后五次标准 Flux 的 DONE 邻域峰值为：

```text
0.322 A, 0.403 A, 0.282 A, 0.322 A, 0.403 A
```

没有再出现收流完成后的上升尖峰。

## 3. 根因和责任边界

根因不是 Flux 回归、Iq 斜坡或电流采样，而是控制状态与功率级物理状态的语义不一致。

| 操作 | 功率级是否在线 | 电机端子 | 用途 |
|---|:---:|---|---|
| `Ualpha=Ubeta=0` 后继续 SVPWM | 是 | 主动零矢量，非 Hi-Z | 受控制的零电压/制动 |
| `PWM_Disable()` | 否 | 高阻释放 | Disable、安全结束 |

最终责任规则：

- 安全关断的第一个生效时刻必须由 ADC/PWM 快环执行层负责；
- 慢环负责状态机和资源收尾，不承担过流风险窗口内的首次关断；
- `FAST_OFF` 如表达“释放功率级”，必须落实为真正的 PWM Hi-Z；
- 新增特殊模式退出路径时，回归必须同时检查指令值和功率级寄存器状态。
