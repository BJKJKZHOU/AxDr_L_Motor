## 6. 2026-08-30：未知电机粗 Rs/Ls Probe 的初始转子位置问题

### 6.1 背景

`feat/adaptive-identification-clean` 中，Rs/Ls 辨识采用两级频率策略：

```text
固定频率 bootstrap Probe
    -> 得到 Rs_Rough / Ls_Rough
    -> f_target = 0.5 * Rs_Rough / (2*pi*Ls_Rough)
    -> ALIGN
    -> 按自适应频率进行正式 A/B/(C) 测量
```

正式 Rs/Ls 测量频率已经由粗测结果自适应计算，但最前面的 bootstrap Probe 原先固定为 `100 Hz`。

本轮测试电机参数量级约为：

```text
Pp          = 11
Vbus        ~= 14.5 V
current lim = 2.0 A
Rs          ~= 6.2 ohm
Ls          ~= 1.6 mH
```

对应正式自适应频率约为：

```text
f ~= 0.5 * 6.2 / (2*pi*1.6mH)
  ~= 300 Hz
```

### 6.2 原始故障

部分初始转子位置下，`100 Hz` Probe 在 `PROBE_MEASURE` 后稳定进入失败阶段 `13`（`INVALID_LS`）。

典型失败 1：

```text
Vbus=14.508 V
stage=PROBE_RAMP
stage=PROBE_MEASURE
stage=13
Probe rough:
  Rs=8.978301 ohm
  Ls=-3845.7075 uH
  U=(0.000038, -1107.405762)
  I=(30.953180, -115.012032)
phase peak=0.645 A
```

典型失败 2：

```text
Rs=8.805414 ohm
Ls=-4400.5248 uH
U=(-0.000076, -1108.781860)
I=(35.990833, -114.619225)
phase peak=0.806 A
```

典型失败 3：

```text
Rs=8.985950 ohm
Ls=-3370.7954 uH
U=(0.000038, -1107.819702)
I=(27.527956, -116.795372)
phase peak=0.685 A
```

这些结果不是数值溢出：由同步积分得到的等效阻抗虚部确实为负。

第一组数据约对应：

```text
angle(U) ~= -90.0 deg
angle(I) ~= -74.9 deg
angle(Z) ~= -15.1 deg
```

也就是电流在 `100 Hz` Probe 下表现为超前软件施加电压。对于正常 RL 电机，这不是纯电气 Rs/Ls 响应。

### 6.3 排查过程

故障状态下检查：

```text
DCBUS ~= 14.5 V  normal
12 V gate-driver supply normal
5 V supply chain normal
```

曾考虑过调试器烧录、FD6288/功率级掉电状态、ADC 上电稳定时间等因素，但后续现象否定了“只有整板/母线掉电才能恢复”的解释：

- 多次完整断电并不能稳定消除该现象；
- 不修改软件、不修改供电，仅手动转动电机转子后，Probe 可以恢复正常；
- 同一固件在第一次 Rs/Ls 完成 ALIGN 后，后续多次 `100 Hz` Probe 通常可以直接通过。

因此当前最符合实测的解释是：

> 未对齐转子下的固定 alpha 轴低频交流 Probe 存在明显的初始转子位置依赖。某些位置下会产生机械微振/反电势等机电耦合，使同步积分得到的阻抗不再是单纯的 `Rs + j*w*Ls`，表现为 apparent negative inductance。

该结论是基于实测现象的工程判断；当前没有额外机械角传感数据证明具体的微振幅值。

### 6.4 修复方案

提交：

```text
b647c2c fix(rs-ls): retry rough probe at higher frequency
```

不修改后续正式自适应频率算法，只给 bootstrap Probe 增加有限频率阶梯：

```text
100 Hz Probe
    -> Ls valid: continue
    -> INVALID_LS: retry at 200 Hz

200 Hz Probe
    -> Ls valid: continue
    -> INVALID_LS: retry at 300 Hz

300 Hz Probe
    -> Ls valid: continue
    -> INVALID_LS: fail stage 13
```

只对 `INVALID_LS` 做频率升级：

- `NO_SIGNAL` 仍直接失败；
- `CURRENT_LOW` 仍直接失败；
- `INVALID_RS` 仍直接失败；
- 正式 A/B/(C) 测量仍使用原 `Result_Range_Check()` 和原自适应频率。

每次 Probe retry 都重新执行完整 Probe：

```text
Frequency_Set(new_freq)
Rs_Ls_Phase = 0
Rs_Ls_U_Ac_V = 0
Ramp_Reset()
Measure_Reset()
state = PROBE_RAMP
```

因此不会复用上一频率的同步积分数据。

### 6.6 当前结论

本轮可以确认：

1. 原 stage 13 不是正式 Rs/Ls 自适应频率失败，而是最前面的固定 `100 Hz` bootstrap Probe 鲁棒性不足；
2. 失败与初始转子位置存在明显相关性；
3. `100 -> 200 -> 300 Hz` 有限重试可以在不放宽有效性判据的情况下恢复 bootstrap；
4. Probe 一旦得到合法粗 Rs/Ls，后续正式自适应频率 + ALIGN + A/B/(C) 测量仍保持良好重复性；
5. 不建议简单把 Probe 永久固定到 `300 Hz`，当前阶梯方案保留了对不同 Rs/Ls 电机的低频起始兼容性；
6. 当前 Rs/Ls bootstrap 问题已不再作为 `feat/adaptive-identification-clean` 的 blocker。

### 8.3 DFT 数据口径

SWD 读取 `Identification/JB.c` 中的 `DFT.Iq_Cos`、`Iq_Sin`、
`Wm_Cos`、`Wm_Sin` 与样本数 `N`。复数基波和结果按固件的符号约定重算：

```text
Iq_1 = (2/N) × (Iq_Cos - j·Iq_Sin)
Wm_1 = (2/N) × (Wm_Cos - j·Wm_Sin)
Kt = 1.5 × Pp × Flux
Z = Te_1/Wm_1 = Kt × Iq_1/Wm_1

J = imag(Z)/(2πf)
B = real(Z)
angle(Te/Wm) = atan2(imag(Z), real(Z))
```

表中的 `|Wm_1|`、`|Iq_1|` 为基波峰值幅值，不是 RMS；速度为机械角速度。
相位正值表示转矩基波超前速度基波。J/B 包含原始计算的负值，
即使固件因 `JB_INTERNAL` 拒绝结果，也保留完整 DFT 重算值用于比较。
以下表格按显示精度舍入，完整数值保存在 CSV。

相邻频点总相位增量为 `3.77°、3.99°、1.37°、0.81°`，不是恒定斜率。

### 8.5 最小修改与修改后结果

仅将 DFT 采样速度改为：

```c
Wm = (Ident_PLL.State.We +
      Ident_PLL.Para.Kp * Ident_PLL.State.Err) /
     (float)Motor_Para.Pp;
```

`PLL_Run()` 使用 `We_Next + Kp·Err` 积分角度，随后保存 `State.We=We_Next`
和 `State.Err=Err`；因此新表达式取的是 PLL 角度积分使用的角速度。
速度环反馈仍用 `State.We`，Handover、Observer 和 PLL 参数均未修改，
未加入经验延时补偿。信号含义说明见 [NLOB + PLL 观测器测试记录](NLOB_PLL观测器测试记录.md#jb-dft-pll-speed)。

`cmake --build --preset Release` 通过；OpenOCD 烧录并 `verify` 通过，
烧录后复位恢复参数，再按同一方法扫频。

### 8.6 结论与边界

- J 保持在约 `1.65～1.74e-5 kg·m²`，与修改前处于同一量级。
- 原先 2～5 Hz 的负 B 消失，五点 B 均为正，总相位均小于 `90°`。
  本轮结果支持使用 PLL 角度积分速度作为 J/B DFT 的速度信号。
- 1 Hz 的 B 为 `5.20e-6 N·m·s`，仍明显低于 2～5 Hz 的
  `1.37～1.82e-5 N·m·s`；不能据此宣称 B 已不随频率变化。
- 修改前后每频点各一次，没有重复性统计或独立机械参考测量。
  不能仅凭五点通过就确认绝对 J/B 精度，也不能将剩余差异唯一归因于 PLL、Observer 或纯延迟。
- 前期单独 2 Hz 测试与正式扫频的结果不同，应保留各自条件和原始数值，不能混并成同一组。

### 9.4 默认参数决定

基于上述实测，J/B 固件启动默认值与 `tools/identification_test.py` 的 Host 默认值
统一改为 `3 Hz`、`20%`。Host 仍可通过 `--jb-hz`、`--jb-ratio` 调整；
参数对象仍为禁用状态可写，频率必须为正，比例必须在 `(0, 1)` 内。
默认值是本轮测试支持的起点，不代表对所有电机、负载的通用最优值。

在 DFT 速度采样处增加注释，明确 `We + Kp·Err` 是 PLL 实际推进 Theta 的角速度，
`State.We` 仅为积分状态，单独用于 DFT 会引入影响 B 的相位滞后；
这是信号选择，不是经验延时补偿。速度环反馈、Handover 和 Observer/PLL 参数保持原样。
本节全部实测通过 Host 显式设置参数完成，发生在此次默认值更新之前。
