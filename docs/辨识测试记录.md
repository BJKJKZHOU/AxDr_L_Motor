# 电机参数辨识与 I/F 启动测试记录

更新时间：2026-08-22
分支：`feat/sensorless-open-loop`

## 1. 记录范围

本文只记录：

- Rs/Ls 的 PROBE、ALIGN、正式测量、一致性和 `IDENT_APPLY`；
- Flux 四点辨识的数值、拟合质量和重复性；
- I/F 开环启动工作点和电气侧验收。

不在本文展开：

- Flux 结束后的 PWM/Hi-Z 问题，见 [功率级关断问题记录](功率级关断问题记录.md)；
- NLOB/PLL 和 `2fe` 纹波，见 [NLOB + PLL 观测器测试记录](NLOB_PLL观测器测试记录.md)；
- 快环耗时和 Deadline，见 [20 kHz 快环时序调试记录](20kHz快环时序调试记录.md)。

## 2. 已验证流程

```text
DISABLE / Vbus / current zero check
    -> Rs/Ls PROBE + ALIGN + MEASURE
    -> DISABLE
    -> Rs/Ls range review
    -> IDENT_APPLY
    -> I/F 120 rad/s check
    -> DISABLE
    -> Flux 120/160/200/240 rad/s
    -> DISABLE
    -> Flux review
    -> IDENT_APPLY when required
```

硬件操作优先由 `tools/rl_apply_test.py`、`tools/flux_capture_test.py` 和
`tools/control_test.py` 自动完成，调试器用于读取无法通过协议获得的计时和诊断字段。

## 3. 历史实测基线

当前电机的稳定量级为：

```text
Rs    ~= 0.077 ~ 0.085 ohm
Ls    ~= 15 ~ 18 uH
Flux  ~= 0.00318 ~ 0.00319 Wb
Voff  ~= 13 ~ 16 mV
```

`f58ac04` 后的五次标准 Flux 四点结果：

| 统计量 | 结果 |
|---|---:|
| Flux 均值 | `0.00318784 Wb` |
| 样本标准差 | `0.000004632 Wb` |
| 变异系数 | `0.145%` |
| 极差/均值 | `0.358%` |
| Voff 均值 | `0.0144769 V` |
| R2 最低值 | `0.999978` |

该结果支持将 `3.18~3.19 mWb` 作为当前电机的 Flux 实测基线。
