## 2. 方案背景

原 Voltage Align 在电流达到 `1 A` 后停止增加电压，但会继续保持当前
`Ualpha`。实测中电流在保持电压期间继续上升，约 `545.6 ms` 后触发
`2 A` 总保护：

```text
Ia max =  2.054 A
Ib min = -1.047 A
Ic min = -1.088 A
```

禁能时三相零点约在 `±0.16 A` 内，因此上述越限不是静态采样偏置导致的
误触发。这说明“达到目标电流后保持电压”不等于电流闭环，不能直接用于
未知电机的长时间 Align。

## 3. PROBE 后 Align 方案

新方案先用低电压交流激励获取粗略 Rs/Ls，再使用粗略参数设置临时电流环
执行 Current Align，最后完成正式的两段 Rs/Ls 测量。

```text
PROBE_RAMP
    100 Hz Ualpha 正弦激励，无直流分量
    Uac 每个完整周期增加 0.01 V
    Iac 目标 0.2 A
    Uac 最大 0.5 V
        |
        v
PROBE_MEASURE
    测量 5 个 100 Hz 周期
    同步提取复阻抗，获得 Rs_Rough/Ls_Rough
        |
        v
ALIGN
    按 Rs_Rough/Ls_Rough 设置临时 Id/Iq PI
    电流环带宽 200 Hz
    Id 目标 1 A，保持 0.5 s
        |
        v
RAMP
    Ualpha = Uhold + Uac * sin(2*pi*100*t)
    Iac 目标 0.4 A
    Uac 最大 1 V，每周期增加 0.005 V
        |
        v
SETTLE -> MEASURE_A -> MEASURE_B -> DONE/FAILED
```

临时 PI 参数按下式计算：

```text
Wc = 2*pi*200
Kp = Ls_Rough*Wc
Ki = Rs_Rough*Wc
```

Align 结束、辨识失败或中止时恢复原 Id/Iq PI 参数。`DISABLE` 在辨识过程中
仍可以关闭 PWM 并中止辨识。

## 4. 测试方法

普通辨识及阶段观察使用：

```bash
python3 tools/control_test.py \
    --port /dev/ttyACM0 \
    --identify rs_ls \
    --poll-interval 0.02
```

第一次完整测试同时通过 USB Plot 采集：

```text
Ia, Ib, Ic, Id, Ud
```

FAST 电流数据由 `20 kHz` ADC 快速环采集，辨识阶段状态每
`10 ms` 轮询一次。测试结束后发送 `DISABLE`，再读取辨识状态和 Vbus。

## 7. 结论和后续校验

`a2835b5` 的 PROBE 后 Align 方案实机测试通过：

- PROBE 低电压激励可以得到可用的粗略 Rs/Ls；
- 可以用粗略参数建立临时电流环并将 Id 稳定在约 `1 A`；
- 所有预期辨识阶段均可以进入；
- 三次辨识均成功，Rs/Ls 重复性良好；
- 全过程保持在 `2 A` 总保护以下。

由于 PROBE 命令电压只有约 `0.05 V`，死区、器件压降和逆变器低电压非线性
可能影响 Rs/Ls 绝对精度。当前结果可作为电流环初始参数，后续建议：

1. 用四线法或可靠微欧计测量线间电阻，换算并校验相电阻；
2. 检查 PWM 死区和器件压降对低电压正弦激励的影响；
3. 在不超过电流限制的前提下，对不同激励幅值和频率的辨识结果进行对比。

## 8. 正式辨识工作点扫描

### 8.1 目的和参数

通过改变正式 RAMP 的交流电流目标，检查 Rs 是否因逆变器固定压降或 PWM
死区而随电流增加明显下降，同时检查 Ls 是否随电流变化。

扫描过程中保持以下参数不变：

```text
PROBE Iac target = 0.2 A
ALIGN Id target  = 1.0 A
激励频率         = 100 Hz
Vbus             ≈ 14.5 V
相电流总保护     = 2 A
```

为减少低电压工作点的量化误差，测试固件临时将正式 RAMP 的电压步进从
`0.02 V/周期` 改为 `0.005 V/周期`。分别构建：

```text
Iac target = 0.2 A
Iac target = 0.4 A
Iac target = 0.5 A
Iac target = 0.6 A
```

`0.5 A` 工作点用作进入 `0.6 A` 前的安全检查。每个工作点的详细采集轮
同时记录 `Ia/Ib/Ic/Id`、阶段转换、实际 Iac 和相电流峰值。最终 Uac
根据 RAMP 阶段时间和每周期 `0.005 V` 的步进推算，不确定度约为
`±0.005 V`。

| 0.2 A | 0.275 A | 0.020 V | 1.531 A | 0.076008 ohm | 16.996 uH | Valid |
| 0.4 A | 0.465 A | 0.035 V | 1.611 A | 0.076881 ohm | 16.872 uH | Valid |
| 0.5 A | 0.577 A | 0.045 V | 1.813 A | 0.078860 ohm | 17.028 uH | Valid |

`0.5 A` 安全检查中相电流峰值为 `1.813 A`，低于 `2 A` 总保护。因此继续

### 8.4 工作点趋势分析

`0.2 A` 和 `0.4 A` 工作点的 Rs 平均值分别为 `0.076661 ohm` 和
`0.076631 ohm`，两者只相差约 `0.04%`。`0.6 A` 工作点的 Rs 平均值为
`0.079648 ohm`，比 `0.4 A` 结果高约 `3.9%`。

本次扫描没有出现“低电流 Rs 偏高，随电流增加而下降”的趋势，因此当前数据
不支持存在显著的逆变器固定压降或死区导致的 Rs 工作点偏差。`0.6 A`
结果略高，且该组内部极差为 `3.78%`，更可能与绕组温升或测量离散有关。

Ls 没有随电流增加而下降，所有工作点整体保持在约 `17 uH`。未观察到
明显的磁饱和趋势，当前 SPMSM 第一版使用单一 Ls 模型是合理的。但低电流
`0.2 A` 组的 Ls 离散度较大，说明该工作点的信噪比和相位误差仍需要注意。

扫描完成后已执行 `DISABLE`，并重新烧录当时仓库标准固件：

```text

RS_LS_AC_U_STEP_V   = 0.02 V/周期
IDENT state         = IDLE
Vbus                = 14.550292 V
```

上述 `0.02 V/周期` 是扫描结束时恢复的旧默认值。根据扫描结果，正式工程参数
现已采用：

```text
RS_LS_AC_I_TARGET_A = 0.4 A
RS_LS_AC_U_STEP_V   = 0.005 V/周期
```

`0.4 A` 工作点在重复性和 2 A 保护余量之间表现最好，因此作为正式默认值。

## 9. 辨识结果 Apply

辨识完成后结果不会自动覆盖电机参数，也不会自动写入 Flash。只有在：

```text
Servo = DISABLED
Identification = DONE
Result.Valid = true
```

时，显式执行 `IDENT APPLY` 才会把结果应用到 RAM：

```text
Motor_Para.Rs = Result.Rs
Motor_Para.Ld = Result.Ls
Motor_Para.Lq = Result.Ls
```

随后按照当前默认电流环带宽重新计算 Id/Iq PI：

```text
Kp_d = Ld * Wc
Ki_d = Rs * Wc
Kp_q = Lq * Wc
Ki_q = Rs * Wc
```

命令行入口：

```bash
python3 tools/control_test.py --port /dev/ttyACM0 --ident-apply
```

Apply 只修改 RAM。Flash 持久化留到新参数下的 Current Loop 实机验证完成后
再单独实现。

## 10. Apply 后低电流电流环验证

### 10.1 测试条件

在一次完整 `RS_LS` 辨识并执行 `IDENT APPLY` 后，通过 USB 运行原
Open Loop 路径。该次辨识结果为：

```text
Rs = 0.0752737 ohm
Ls = 15.9588 uH
IDENT_APPLY OK
Vbus = 14.47 ~ 14.50 V
```

Open Loop 仍使用原固定参数：

```text
ALIGN: Id_Ref = 0.2 A, Iq_Ref = 0 A, 0.5 s
RUN:   Id_Ref = 0 A,   Iq_Ref = 0.2 A, We = 20 rad/s electrical
```

USB FAST 以 `20 kHz` 同步采集 `Id/Iq/Ud/Uq/Ia/Ib/Ic`。为区分开关和
采样纹波与控制环低频振荡，分析时另外对原始数据做 `1 ms` 分组均值；该处理
只用于离线分析，不改变 FAST 采样率。

### 10.2 实测结果

| 阶段 | 信号 | 均值 | 1 ms 误差 RMS | 1 ms min/max |
|---|---|---:|---:|---:|
| ALIGN | Id | 0.19997 A | 8.46 mA | 0.1753 / 0.2255 A |
| ALIGN | Iq | -0.00001 A | 10.06 mA | -0.0290 / 0.0245 A |
| RUN | Id | 0.00001 A | 9.41 mA | -0.0304 / 0.0410 A |
| RUN | Iq | 0.19995 A | 9.49 mA | 0.1639 / 0.2332 A |

电压矢量峰值为 `0.0835 V`。按实测母线电压计算，电流环电压限幅约为
`7.94 V`，峰值只占限幅的 `1.05%`，没有电压饱和。

`700 ~ 1300 Hz` 范围内的 Id/Iq 最大离散谱峰约为 `3 ~ 4 mA`，未观察到
持续的 `1 kHz` 电流环振荡。原始瞬时电流纹波明显大于 `1 ms` 均值误差，
说明主要成分来自 ADC/PWM 采样纹波，而不是低频发散。

三相电流峰值为 `0.483 A`，没有单相异常。`Ia + Ib + Ic` 的 `1 ms` 均值
RMS 为 `34.3 mA`，仍存在可见的三相采样误差，后续测试继续观察。

该阶段结论为：辨识参数 Apply 后，原固定角度 Align 和低速 Open Loop 电流
环工作正常，当前 `1 kHz` 设计带宽没有表现出过激或电压饱和。

## 11. I/F 启动第一轮实机测试

### 11.1 测试版本和目标

第一轮使用以下提交：

```text

9ace1e5 feat(sensorless): add startup runtime control
```

I/F 参数为：

```text

ALIGN time          = 0.5 s
I/F Iq              = 0.2 -> 0.5 A
We_IF               = 0 -> 200 rad/s electrical
Acceleration        = 100 rad/s^2 electrical
HOLD time to Ready  = 0.3 s
```

烧录新固件后 RAM 参数丢失，因此先重新执行 `RS_LS` 和 `IDENT APPLY`。第一次
启动前辨识结果为：

```text
Rs = 0.0765615 ohm
Ls = 16.5616 uH
Valid = true
IDENT_APPLY OK
```

测试通过 USB 控制，不使用调试器控制或观察变量。USB FAST `20 kHz` 同步
采集 `Id/Iq/Ud/Uq/Ia/Ib/Ic`，NORMAL 采集 `Wm` 和 `Vbus`，同时轮询
Sensorless 的 `ALIGN/IF`、`ACCEL/HOLD`、`We_IF` 和 `Ready`。当前编码器无效，
因此本轮不使用 `Wm` 判断实际转速，NORMAL 数据只使用 `Vbus`。

当前 I/F 路径没有辨识路径中的 `2 A` 总电流硬限制，因此第一轮使用主机侧
`1.5 A` 提前停止作为附加保护。

### 11.2 第一次启动中止和原因

第一次 `SENSORLESS START FORWARD` 后约 `24 ms`，USB FAST 检测到：

```text
max(abs(Ia), abs(Ib), abs(Ic)) = 11.078 A
```

主机立即执行：

```text
SENSORLESS_STOP
DISABLE
PLOT_STOP
```

电机没有进入 IF/ACCEL。停止后状态为 `active=0`、`We_IF=0`，USB 通信和
辨识结果保持正常。

PWM 禁用状态下继续通过 USB Plot 读取到：

```text
Ud = +5.63 V
Uq = -5.63 V
sqrt(Ud^2 + Uq^2) ~= 7.96 V
```

该值正好接近当时的电压矢量限幅。原因是 PWM 禁用期间 `Current_Loop()` 仍以
零参考运行，采样偏差使 PI 积分逐渐累积；原 `Servo_Enable()` 会在使能 PWM
前清零 Id/Iq PI，而新的 Sensorless 启动路径在 `PWM_Enable()` 前没有清零。
原代码只在 `ALIGN -> IF` 切换时清零，无法避免启动瞬间把已饱和的 PI 输出加到
电机上。

### 11.3 最小修复和短 Align 验证

修复只在 `Sensorless_Start_Begin()` 中、`Start_Active=true` 之前调用已有的：

```c

```

保留原 `ALIGN -> IF` 切换处的清零，不增加新状态、协议、字段或保护逻辑。

修复版重新烧录后再次执行辨识和 Apply：

```text

Ls = 16.6312 uH

```

先只运行 `0.25 s` Sensorless Align，确保不会进入 IF。USB FAST 实测：


短 Align 没有再次出现大电流，启动前 PI 清零生效，因此继续执行完整 I/F。

### 11.5 实机观察电机未起转

当前编码器无效，采集到的 `Wm` 不代表实际转速，不能用于判断 I/F 是否同步。
本轮机械侧结论只依据现场实机观察：完整 ALIGN、ACCEL 和 HOLD 期间电机没有
转动。

因此，虽然定子电流矢量按 I/F 指令连续运行，电流也没有在 ACCEL 中途突然
掉落，但当前工作点没有使电机起转。可能原因包括启动转矩不足、Align 工作点
不适合当前较大电机、加速度过高、初始负载角或方向不合适；本轮数据不能继续
区分这些原因。

第一轮 I/F 总结：

| 检查项 | 结果 |
|---|:---:|
| We_IF 线性 0 -> 200 rad/s | PASS |
| ALIGN 后 Id 接近 0 | PASS |
| Iq 跟随 0.2 -> 0.5 A | PASS |
| Ud/Uq 无饱和 | PASS |
| 三相电流连续 | PASS |
| ALIGN -> IF 无明显电流冲击 | PASS |
| ACCEL 无突然掉电流 | PASS |
| ACCEL 期间电机实际转动 | FAIL，实机未转 |
| HOLD 期间电机稳定转动 | FAIL，实机未转 |

因此当前不能进入后续无感模块，也不应在相同参数下重复完整启动。下一轮应先
改变 I/F 启动工作点；在编码器恢复有效前，实际转动和稳定性继续以实机观察
为判据。

### 11.10 当前外转子电机极对数确认

实机检查确认外转子内部共有 `32` 块 N/S 交替排列的永磁体，因此：

```text
总极数 P = 32
极对数 p = 16
```

工程默认极对数相应由 `7` 修改为 `16`：

```c
#define MOTOR_PP_DEFAULT 16U
```

当前 I/F 启动直接生成电角度和电角速度，不依赖 `Motor_Para.Pp` 完成角度
积分，因此原 `Pp=7` 不是本轮 I/F 抖动的直接原因。但后续机械速度换算、
转矩常数、编码器电角度和无感观测器必须使用正确的 `16` 极对。

按 `p=16` 换算：

```text
We = 20 rad/s electrical -> Wm = 1.25 rad/s  ~= 11.9 rpm
We = 50 rad/s electrical -> Wm = 3.125 rad/s ~= 29.8 rpm
```
