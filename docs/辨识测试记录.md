### 8.3 DFT 数据口径

由电流、速度的同步积分与样本数 N 重算：

```text
Iq_1 = (2/N) × (Iq_Cos - j·Iq_Sin)
Wm_1 = (2/N) × (Wm_Cos - j·Wm_Sin)
Kt = 1.5 × Pp × Flux
Z = Kt × Iq_1/Wm_1
J = imag(Z)/(2πf)
B = real(Z)
angle(Te/Wm) = atan2(imag(Z), real(Z))
```

表中电流、速度均为基波峰值幅值，速度单位为机械 rad/s；正相位表示转矩超前速度。
表内包含导致辨识失败的负 B 原始计算值。
