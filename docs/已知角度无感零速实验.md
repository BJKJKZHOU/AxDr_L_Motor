# 已知初始角度的无感零速实验

本实验验证现有非线性磁链观测器（NLOB）与 PLL 在**初始电角度已知**时，能否从静止直接起动，并在减速到零、零速停留后继续工作。实验不包含首次无编码器角度辨识，也不声称已经实现真正的全无感冷启动。

## 模式及控制路径

| 模式 | 参数值 | 起动及低速行为 |
| --- | ---: | --- |
| `SENSORLESS_SPEED` | 5 | 现有 Align → I/F → NLOB+PLL；减速到阈值退回 I/F |
| `SENSORLESS_SPEED_KNOWN_ANGLE` | 7 | 仅 Run 起点读取一次已校准编码器电角度，NLOB+PLL 从零速直接控制，不执行低速回退 |

原有模式编号与行为不变。新模式仍使用同一个 `SENSORLESS_SPEED` 速度规划、速度 PI、dq 电流 PI、SVPWM 与限流/保护。

新模式 Run 起点执行：

1. 要求编码器 Ready、Valid、无 Fault，且 `Motor_Cal.Valid=1`（已完成极对数、方向和电角零位校准）。
2. 读取一次 `θe0 = wrap(Pp × Encoder.Theta_m + Motor_Cal.Theta_Off)`。
3. 根据电机模型和电流初值重置磁链观测器，PLL 使用 `(θe0, ωe0=0)`，重置速度 PI / 电流 PI。
4. 直接进入 `SL_OBS`，用 PLL 角度执行 Park 变换和 FOC，速度规划从零开始。

进入 Run 后控制律不再读取编码器角度或机械 ESO 速度。固件仍持续采集编码器，**仅用于实验真值、诊断 Plot**。没有在编码器故障时将其作为新模式运行中的闭环依赖；用于测试的 PC 脚本会在真值失效时中断实验。

已知角度必须对应启动瞬间静止的实际转子位置。该模式暂不缓存 Stop 后角度，也不支持 PWM 关闭后依靠旧角度再次 Run：每次 Run 都重新获取一次初始编码器角度。

## 停止与保持语义

- `RUN` 且目标速度为 `0 RPM`：PWM 不因目标归零自动关闭；继续用 NLOB+PLL、速度 PI 运行，观察零速估计漂移。
- `Stop` Action：保持原有受控减速和完成后进入 `ENABLED` 的语义，最终关闭 PWM。
- `Disable` Action：按已有流程立即关闭 PWM。
- 新模式**不**靠低速退回 I/F 掩盖 NLOB 的失锁；出现异常应在受控测试条件下立即停止实验。

## 实验诊断

新增只读 `PARAM_ENCODER_THETA_M = 0x0026`，在 FAST/NORMAL Plot 暴露方向修正后的编码器机械单圈角度。与原有 `PARAM_OBS_THETA` 配合计算：

```text
theta_encoder_e = wrap(Pp * theta_encoder_m + theta_offset)
error_e = wrap_pi(theta_obs_e - theta_encoder_e)
```

切勿把 `PARAM_RUN_THETA_E` 与 `PARAM_OBS_THETA` 的差值作为精度指标：在新模式里二者应当几乎一致。也不要把 `PARAM_RUN_WM` 当成真实机械速度；无感 Run 状态该量来自 PLL。机械速度参考对照可使用编码器驱动的 `PARAM_MECH_ESO_WM`。

## 采集

在空载、确认转子静止的台架上先使用小电流，逐步试验。示例：

```bash
python3 tools/sensorless_known_angle_test.py \
    --port /dev/ttyACM0 --run \
    --rpm 50 --rpm 150 --rpm 0 --rpm 50 --rpm 0 \
    --hold 5 --zero-hold 10 \
    --current-limit 0.8 --current-trip 1.5
```

脚本使用现有 AxDr USB Parameter/Action/Plot，配置 NORMAL 1 kHz 波形，记录机械真值角、PLL 角、FOC 角、速度、Id/Iq、各相电流、母线电压等；生成 `build/captures/sensorless_known_angle_*.csv` 和同名 `.json` 元数据。

`--current-limit` 只暂时降低用户 RAM 电流指令限制，结束时尝试恢复；不保存 Flash。脚本根据角度误差、电流、电压、通信与编码器状态中断测试；**上位机监测不是硬件保护**。该 AxDr-L 板目前没有接入 TIM1 BKIN 的硬件过流快速关断链路。实验必须有外部限流、可靠断电手段，并避免高能负载；目标电流限制并不等于实际电流不会瞬时超出。

## 判断标准

按完整的 Run → 加速 → 减速至零 → RUN 零速保持 → 再加速 → Stop 过程统计：

- 编码器电角度与 PLL 电角度的误差波形（包括角度回绕处理）。
- 编码器机械速度与 `PLL.We/Pp` 的差异。
- 静止阶段角度漂移、实际低速振动、Iq 输出和母线电压。
- 正反方向重复性、Plot 丢帧及 20 kHz 快环 Deadline Miss。

测试时不调整 NLOB、PLL 的公式和参数来掩盖问题。本分支仅实现实验机制，**尚无实机结果**。通过零速保持实验后再决定是否需要 Stop 角度保持/预测，以及独立无编码器 IPD。
