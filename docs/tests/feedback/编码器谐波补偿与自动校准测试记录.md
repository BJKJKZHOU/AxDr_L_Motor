# 编码器谐波补偿与自动校准测试记录

## 2026-10-20：编码器谐波补偿与 6000 RPM 对照

### 条件与操作过程

MT6835 保持连接和供电。电流环使用 PI，带宽 2000 Hz，速度环 Manual Kp=0.04、Ki=0.3，加减速度 100 rad/s²；有感运行开启 dq 前馈。有效电流限值沿用板上 10 A，本轮有效采集没有额外的主机电流限制。

初始从静止直接 VF 启动未同步，1000 RPM 指令下实际仅约 177.5 RPM、相电流峰值 6.687 A，该次结果不参与校准。改为编码器 PI 闭环升至 1000 RPM，在快环边界接续当时的电压矢量角度、幅值及运行频率，再切入 VF。切换后编码器仅用于采集诊断，不参与 VF 控制。首轮切换前约 998.57 RPM，稳定 VF 电压矢量幅值均值约 2.050 V；启动及切换段相电流峰值 3.062 A，稳定段峰值 2.900 A。

正向首轮采集约 6 秒并拟合四个系数，随后用独立正向和反向记录验证。应用时固定使用首轮系数，不重新拟合；写入系数后执行原有 Servo_Phase、保存并重启读回。6000 RPM 对照依次为 A1 无补偿、B 补偿、A2 恢复零系数复测；另采集无感 A1/B 作为诊断。

### 固定系数与 VF 验证

系数单位为机械 rad，θ 为方向处理和补偿前的原始编码器机械角：

```text
C1 =  0.00005873221555366483
S1 = -0.0006002208043825709
C2 = -0.0010067668844784465
S2 = -0.0014706962187730481
θcorr = θ − C1 cos(θ) − S1 sin(θ) − C2 cos(2θ) − S2 sin(2θ)
θe = wrap(7 × Enc_Dir × θcorr + Theta_Off), Enc_Dir = −1
```

下表角度均为机械度。残差为相对匀速拟合的角度残差；补偿后列始终使用首轮固定系数。

## 固件自动谐波校准修正与实测（2026-10-20）

运行前必须已有有效的编码器方向与电角度零位（`Motor_Cal.Valid=1`），并满足编码器、ESO 和原有保护条件。首次寻相仍使用原有 Servo_Phase；未做谐波补偿不影响这次有感闭环启动。

通过 `ACTION_ENC_CAL_START=0x1401` 触发完整流程：有感升至 1000 RPM → VF 稳定 2 秒 → 2 kHz 采集 6 秒 →有感减速 → PWM 关闭后拟合 → 直接应用系数 → 重新寻相 → 保存。Action 的初始响应表示接受，完成事件在保存成功或失败后返回。无需主机脚本参与采集、拟合或推进步骤；旧 `tools/encoder_harmonic_cal.py` 已删除，校准统一使用本固件入口。

### 修正内容

- 校准升速、减速在两处控制分派中均执行 SPEED；不修改用户 `Motor_Mode`、目标和电流限值。
- VF 继承闭环电压幅值，首周期推进一个电角度步长；随后保持该工作点，
  不再下降到 `|We|×Flux + Rs×0.2`。原有母线电压约束仍有效。
- 等待 2 kHz 线程准备减速时，电压矢量继续旋转；首个 DECEL ADC 周期按当时电流、
  电压初始化 PI/LADRC，并接续当前电流参考。避免冻结矢量和使用过期的控制器状态。
- VF 稳定阶段末至少连续 0.5 秒满足原有 ±10% 转速条件；采集期间持续检查同步，
  任一无效编码器帧或非有限角度使该次采集失败，不用恢复后的数据掩盖缺样。
- 以相对名义角增量累计误差，避免单精度累计约 600 rad 后相减损失精度。
  拟合检查残差 RMS ≤0.25°（机械角），并保留系数范围和平均速度检查；
  该门槛参考既有 VF 残差约 0.06～0.08°。
- 速度参考为零且实测速度绝对值 ≤10 RPM 连续 0.3 秒后才进入拟合，
  减速超过 `1000 RPM 对应角速度 / 配置减速度 + 4 秒` 则失败退出。
- Stop、Disable、运行切换和使能切换可中止校准；中止寻相时清除活动寻相流程。
  尚未结束的校准动作阻止同队列后续 Run/Enable/重新校准、保存和激励启动抢占。

拟合不通过不写系数；拟合通过后仍按既定设计直接应用并重新寻相保存。新系数应用时使旧相位校准失效，寻相失败时保持无效，不能直接复用旧零位运行。

### 烧录与固件自动校准

母线约 24.9 V。电流指令限值 10 A，寻相电流 0.5 A。

从用户转矩模式、目标为零、已有有效寻相结果的停机状态发送 `0x1401`。主机只触发动作并记录诊断量，不计算或写入校准系数，不推进校准状态。固件自行完成闭环升速、VF 采集、有感减速、拟合、应用、寻相及保存：

- 完成事件状态为 `0`，耗时 11.791 s；内部采样计数为 12000，终态 `CAL_DONE`，
  保存工作已完成，电机 Disabled，`CAL_VALID=1`。
- VF 继承电压幅值约 1.985 V，诊断抽样转速约 994～1005 RPM，未见激烈失步。
  随后减速至停止，再执行寻相。
- 用户模式、目标及电流配置保持；只更新四个补偿系数和寻相零位。
- 执行 MCU 复位后，四系数、方向、零位及有效标志与保存前完全一致，
  其余读取参数除实时母线电压外也一致。

| 参数 | 校准前 | 校准后及复位后 |
|---|---:|---:|
| C1 / rad | 0 | 0.000179586685 |
| S1 / rad | 0 | -0.000205121309 |
| C2 / rad | 0 | -0.000975495379 |
| S2 / rad | 0 | -0.001429463155 |
| 编码器方向 | -1 | -1 |
| 电角度零位 / rad | 4.472407818 | 4.350478172 |

全流程诊断流有 3 个固件发送丢块，本地 `result=failed` 由诊断波形连续性断言触发。固件内部 2 kHz 校准采样完成 12000 点，校准动作完成。VF 期间 `RUN_IQ` 保留进入电压模式前的值。

### 中止与实时性

补偿对比结束后，另从转矩模式触发一次自动校准，在约 582 RPM 升速阶段发送 Stop。6.27 ms 内收到校准完成事件 `status=7`（中止后的失败完成），电机 Disabled；约 0.52 s 后读取速度 -1.39 RPM。四系数、寻相结果、有效标志和其他配置均保持，内部状态为 `CAL_FAILED`，采样计数为零，保存工作空闲。本项没有重新拟合或覆盖成功校准结果。
