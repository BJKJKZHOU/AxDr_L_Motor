## 2026-11-11：PI / LADRC / DPCC 对照及 LADRC 参数扫描

完成 PI 1250 Hz、8 组 LADRC 参数和 DPCC 的 D/Q 扫频，共 20 组、480 个正式频点，并采集各配置的零指令噪声。**LADRC 增益与 ESO 频率需要分别权衡：增大反馈参数的收益并不单调，ESO=2000 Hz 组的噪声和中频衰减明显增大；DPCC 相位滞后较小，但低频跟踪幅值约为参考的 35%。**

### 工况与分析口径

- 本轮为 2 mΩ 电流采样、ABZ 4096 PPR、7 极对。TORQUE + ENABLED，零转矩目标，电机空载且未机械锁定；母线各组起始读数 24.84～24.99 V。
- 共用模型 Rs=0.282525539 Ω，Ld=Lq=71.382216 μH，Flux=0.002281195 Wb；电角度零位 5.999854088 rad。前馈开启，电流指令限幅临时设为 2 A。
- PI 使用模型带宽整定 1250 Hz。LADRC 表中的两个数分别为反馈增益对应频率、ESO 极点频率，单位 Hz；DPCC 使用共用模型，无独立带宽参数。
- 每轴注入峰值 0.1 A，每点 1 s；20 kHz 同帧记录 Injection / Ref / Fbk / Out，舍弃起始 4 个周期后拟合。频点为 20、40、70、100、150、220、330、500、700、1000、1250、1500、1750、2000、2500、3000、3500、4000、4500、5000、6000、7000、8000、9000 Hz。
- 每组另以 0.1 / 0.2 A 在 100、500、1500 Hz 做 D/Q 幅值对照，每点 0.6 s。零指令记录约 2 s，采集 Id/Iq/Ud/Uq；交流 RMS 为去均值标准差，Welch 使用 20000 点、50% 重叠，频率间隔 1 Hz。
- 图表报告实测 `T=Fbk/Ref`。幅值对照存在差异，部分弱响应点还出现拟合漂移，因此本轮 Bode 归档为 `quality=unknown`，线性带宽和稳定裕度为 N/A。图中叉号表示前后半段相量漂移超过 20%，对应 `point_valid=0`；完整原始相量仅在本机保留。

当前 PI 在 100、500、1500、3000 Hz 的 D 轴 `Out/(Ref−Fbk)` 与离散 PI 公式的相对误差为 0.10%～0.21%，支持当前增益配置及通道映射一致。采样电阻、编码器和零位与 10 月记录不同，三种控制器采用本轮 PI 基线比较。

### LADRC 参数取舍

**固定 ESO=1500 Hz：** 反馈参数从 500 提到 1500 Hz，D/Q 的 500 Hz 增益分别改善约 4.41/2.81 dB。继续提到 2000 Hz，500 Hz 两轴以及 Q 轴 1500 Hz 的衰减均增加；Iq 噪声由 0.1316 增至 0.1450 A，Q 轴 9000 Hz 增益由 +1.04 增至 +3.07 dB。因此本轮没有支持继续提高该反馈参数的中频跟踪收益。

![固定 ESO 的 LADRC Q 轴反馈参数对照](../../data/20261111_current_frf/ladrc-feedback.png)

**固定反馈=1500 Hz：** ESO 从 750 提到 1500 Hz，500 Hz 幅值更接近参考，但相位滞后增大；1500 Hz 处则是较低 ESO 组幅值更高。ESO 再提到 2000 Hz，500/1500 Hz 的 Q 轴衰减和滞后同时增大，Iq 噪声比 ESO=1500 Hz 增加约 39%，比 ESO=750 Hz 增加约 52%。该组还有 14 个频点的半段相量漂移超过 20%，主要位于反馈基波较弱的中高频段。

![固定反馈参数的 LADRC Q 轴 ESO 对照](../../data/20261111_current_frf/ladrc-eso.png)

## 2026-10-10：七档电流环带宽、前馈开关及 D/Q / FFT 对照

**结论：** 完成 500、1000、1500、2000、3000、4000、5000 Hz 七档 PI 设置，每档前馈关/开、D/Q 两轴共 28 组扫频，以及 14 组无注入 FFT/PSD。当前零转矩指令工况下，500～4000 Hz 的前馈开关差异较小；3000 Hz 开始出现明显高频增益峰，4000 Hz 的峰值和噪声明显增加。**5000 Hz 出现约 5.47 kHz 强振荡，瞬时电流远超 0.1 A 激励，接近电压限幅，该档数据标记为 invalid。**

### 固件、工况与采集

- Rs=0.282525539 Ω，Ld=Lq=71.382216 μH，Flux=0.002281195 Wb；
  编码器方向 −1，电角度零位 5.533890247 rad，标定有效。
- TORQUE + ENABLED，零转矩指令，无 Run/恒速工作点；母线测试前后约 24.6 V。
  前馈为已有 dq 解耦/反电动势前馈。
- 使用现有 `tools/current_frf.py`，峰值 0.1 A，每点 1 s，20 kHz 四通道
  `Injection / Ref / Fbk / PI Out`；按脚本舍弃起始 4 周期后作含直流项的同频拟合。
  每轴 24 点：20、40、70、100、150、220、330、500、700、1000、1250、1500、
  1750、2000、2500、3000、3500、4000、4500、5000、6000、7000、8000、9000 Hz。
- 每档先 FF=0、后 FF=1，每工况先 D、后 Q，再运行现有 `tools/fft.py`。
  FFT 无正弦注入，20 kHz、约 4 s，通道 `Id / Iq / Ia / Ib / Ic / Ud / Uq`；
  去均值、周期 Hann 窗，FFT 按相干增益校正峰值；Welch 为 20000 点、50% 重叠，
  频率间隔 1 Hz。下表 RMS 为完整原始记录的交流标准差。
- 正式扫频保存 17,732,340 个样本，FFT 保存 1,124,480 个样本。
