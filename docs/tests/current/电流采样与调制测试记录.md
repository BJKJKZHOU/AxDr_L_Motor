# 电流采样与调制测试记录

更新：2026-10-17。记录电流声排查、ADC 反馈噪声与硬件平均、采样触发和调制窗口，以及相关高速运行验证。

## 2026-10-07：转动及 Stop 保持使能时的电流声分析

现场观察：各类模式均能转动，运动和 Stop 保持状态下均有较明显的电流声。

### 已有证据

有感模式 Stop 后进入 ENABLED，`Motor_Fast_Run()` 仍返回 FAST_CURRENT，电流环和 PWM 持续工作。转矩模式参考归零，速度模式继续零速调节，位置模式保持停止点；后两者的 Iq_ref 不要求为零。

从[轨迹规划测试记录](../motion/轨迹规划测试记录.md#trajectory-20261007)最终 `samples.csv` 各指定阶段的最后 100 个样本计算总体标准差：

| 工况 | Iq_ref 均值 (A) | Iq_ref 标准差 (A) | Iq 测量标准差 (A) |
| --- | ---: | ---: | ---: |
| 转矩正向稳定参考 | 0.06000 | 0 | 0.13739 |
| 正向转矩 Stop 完成后 | 0 | 0 | 0.16269 |
| 转矩负向稳定参考 | -0.06000 | 0 | 0.12971 |
| 负向转矩 Stop 完成后 | 0 | 0 | 0.14679 |
| 速度模式零速段 | 0.00045 | 0.01425 | 0.13494 |

转矩模式不经过位置/速度 PI，零参考下仍有明显反馈波动。Iq 由板载 ADC 采样经 Park 变换得到。

代码电流换算使用 3.3 V、12 bit、1 mΩ、20 倍增益，相电流量化步长约 **0.04028 A/ADC count**。采样值直接进入 Clarke/Park 和 PI。电流环设计带宽 2000 Hz，Kp=0.8970154 V/A、Ki=3550.321 V/(A·s)；0.15 A 的反馈变化对应比例项约 0.135 V 的电压修正。

## 2026-10-07：失能底噪与 2000/1000/500 Hz 电流环对照

本轮对照电流环带宽。SystemCoreClock=160 MHz、TIM1 ARR=4000，PWM 为 20 kHz；沿用同期轨迹测试的电机模型。

### 对照条件

测试顺序为 DISABLED → TORQUE/Stop 2000 Hz → 1000 Hz → 500 Hz → 2000 Hz 复测。各组之间先失能；保持组均为 Id_ref=Iq_ref=0，经 Enable、Run、Stop 确认进入 ENABLED，MOE=1。每组前 2 s 用于稳定，随后统计约 12 s。

FAST 以 20 kHz 采集 Ia、Ib、Id、Iq、Ud、Uq，电流/电压遥测量化分别为 0.001 A/V；NORMAL 以 1 kHz 采集 Vbus、Wm、Iq_ref、电角度、用户位置。每组稳态有效 FAST 样本约 240100～240140 个，各保持组 Iq_ref 全程为零。每组带宽参数写入后读回 PI 增益，2000/1000/500 Hz 的 Kp 分别约0.897015 / 0.448508 / 0.224254 V/A，Ki 约 3550.321 / 1775.160 / 887.580 V/(A·s)。

DISABLED 组使用持续更新的 Ia/Ib 评价底噪。

### 结果

下表均为去掉起始段后的总体标准差；合成电压波动定义为`sqrt(var(Ud) + var(Uq))`，单位 V。Ud/Uq 是软件输出的电压指令。

| 工况 | Ia 标准差 (A) | Ib 标准差 (A) | Ud 标准差 (V) | Uq 标准差 (V) | 合成电压波动 (V) |
| --- | ---: | ---: | ---: | ---: | ---: |
| DISABLED，MOE=0 | 0.15890 | 0.16142 | 0 | 0 | 0 |
| 2000 Hz | 0.18382 | 0.22439 | 0.36728 | 0.12292 | 0.38730 |
| 1000 Hz | 0.17119 | 0.18275 | 0.16024 | 0.05891 | 0.17072 |
| 500 Hz | 0.16136 | 0.16678 | 0.07634 | 0.02933 | 0.08178 |

相对首次 2000 Hz，1000 Hz 和 500 Hz 的合成电压波动分别下降约 **55.9%** 和**78.9%**；回到 2000 Hz 后恢复至首次值的 99.3%，表明电气结果可重复。采样电流波动随带宽降低只部分下降，500 Hz 时已接近失能底噪。

失能组编码器位置不变，Ia/Ib 等效标准差均约 4 ADC count。按固件 3.3 V、12 bit、1 mΩ、20 倍换算，ADC 输入端等效标准差约 3.2 mV；Ia/Ib 相关系数约 **0.804**。

保持组稳态位置峰峰值约 0.45～0.62°，各组母线均值约 14.62～14.63 V，采样负载相同。

### 对照结果

PWM 关闭时采样链路已有明显波动，提高电流环增益会增大电压指令波动。

四次使能组的现场主观听感按测试顺序记录如下：

| 组次 | 电流带宽 | 现场反馈 |
| --- | ---: | --- |
| 第一次 | 2000 Hz | 声音较大 |
| 第二次 | 1000 Hz | 声音减小 |
| 第三次 | 500 Hz | 声音更小，但仍感觉不是正常的电机声音 |
| 第四次 | 2000 Hz 复测 | 与第一次差不多，声音较大 |

听感与电压指令波动随增益变化，500 Hz 组仍有现场观察到的异常声音。

### 时序与频谱口径

六路 FAST 采集负载下，快环累计最大 7117 周期，即 44.48125 μs。

PSD 使用 8192 点 Hann 窗、50% 重叠、逐窗去均值的单边 Welch 估计，电流/电压单位分别为 A²/Hz、V²/Hz；20 kHz 采样只能分析至 10 kHz。

## 2026-10-07：失能电流反馈波动的来源对照

本轮全程 DISABLED、TIM1 MOE=0，测量 ADC 原始码。

### 电流换算

当前软件按 3.3 V、12 bit、1 mΩ、20 倍增益换算：

- 1 ADC 码对应 0.0402832 A，4 码标准差约 0.161 A。
- 理想 1.65 V 中点对应约 ±82.5 A 的换算量程。
- 2 A 指令上限约对应 50 码，4 码标准差约占该上限的 8%。
- 直接采集组覆盖约 25～28 种码值。

### 20 kHz 连续采集：采样时间、触发位置、编码器 SPI

通过 SWD 临时修改寄存器。改变采样时间前停止注入转换，恢复 JSQR 后从 ADC2到 ADC1 重新启动。只修改 A/B 电流通道采样时间；母线通道保持原值。编码器对照仅屏蔽 TIM1 CC4 中断触发，最后一笔 SPI 完成后不再发起新传输。

每组先丢弃 1 s，再记录约 8 s，20 kHz FAST 六通道及 1 kHz NORMAL。FAST 的 Ia/Ib 为 1 mA 量化数据，结合原偏置 Ia=2064、Ib=2044 反推 ADC 原始码；回算电流与遥测差值均不超过 0.51 mA，远小于半个 ADC 码，确保原始码可唯一恢复。`adc.raw` 为逐点 uint16 A/B 原始码，`fast.raw` 保留原始六通道 int16 数据。

| 条件 | A/B 标准差（码） | A/B 换算标准差（A） | A/B 相关系数 | Deadline 增量 |
|---|---:|---:|---:|---:|
| 基线，47.5 周期 / CCR5=3665 | 4.032 / 4.080 | 0.1624 / 0.1643 | 0.788 | 0 |
| 采样 92.5 周期 | 4.078 / 4.127 | 0.1643 / 0.1663 | 0.841 | 0 |
| 采样 247.5 周期 | 4.084 / 4.133 | 0.1645 / 0.1665 | 0.848 | 0 |
| 采样 640.5 周期（仅失能诊断） | 4.100 / 4.153 | 0.1652 / 0.1673 | 0.857 | 17 |
| 恢复基线 | 4.100 / 4.150 | 0.1651 / 0.1672 | 0.795 | 0 |
| 触发 CCR5=800 | 4.090 / 4.135 | 0.1647 / 0.1666 | 0.794 | 0 |
| 触发 CCR5=2000 | 4.072 / 4.126 | 0.1640 / 0.1662 | 0.813 | 0 |
| 触发 CCR5=3000 | 4.061 / 4.117 | 0.1636 / 0.1658 | 0.804 | 0 |
| 暂停编码器 SPI 触发 | 3.978 / 4.046 | 0.1602 / 0.1630 | 0.802 | 0 |
| 恢复 SPI / 基线 | 4.048 / 4.095 | 0.1631 / 0.1650 | 0.804 | 0 |

延长采样时间及移动触发点未显著降低主波动；暂停 SPI 后仅小幅下降，恢复后返回原水平。

640.5 周期组出现 17 次快环跨周期，最大端到端耗时累计达到 8900 CPU 周期（55.625 μs）。

频谱用 8192 点 Hann 窗、50% 重叠、逐窗去均值的单边 Welch 估计，单位为码²/Hz。主要表现为宽带波动，未看到一个占主导的窄带尖峰。频谱分析范围为 0～10 kHz。

### USB 遥测负载对照

为了避免用 USB 数据评价 USB 自身的影响，改用 SWD 读取 RAM 中同一个 32 bit字内的 Ia_Raw/Ib_Raw，交替开关 FAST/NORMAL，每组 12 s，约 1400～2100 点。以非均匀 SWD 读数比较码值分布。

| 条件 | A/B 标准差（码） |
|---|---:|
| usb_off | 3.909 / 3.902 |
| usb_on | 4.098 / 4.192 |
| usb_off_repeat | 3.819 / 3.825 |
| usb_on_repeat | 4.076 / 4.143 |

关闭遥测后主波动仍在，USB 负载不是主来源。该组并发 SWD/USB 读取未按连续FAST 采集方式及时排空遥测，随后检查发送丢块累计增加 FAST/NORMAL 各 169；这些 FAST 数据不用于分析，此组统计仅来自 SWD 读数。

### 屏蔽电流计算中断及内部参考复核

先关闭 ADC1 JEOS 中断，但保留硬件注入转换；直接读取 JDR 原始码。然后临时将 ADC1 首个通道换为内部 VREFINT，ADC2 首个通道仍是 Ib，两者都使用 247.5 周期，保持首个转换时长一致。PWM 关闭，暂停电流计算期间不使用缓存的电流反馈做结论。

VREFINT 在 ADC1_INP18，使用 6.1875 μs 采样窗口；参考[STM32G474 数据手册 Table 20](https://www.st.com/resource/en/datasheet/stm32g474re.pdf)以及仓库 RM0440 §21.4.33。VREFINT 使能后等待超过 12 μs 稳定时间。

| 条件 | ADC1 标准差（码） | ADC2/Ib 标准差（码） |
|---|---:|---:|
| ab_irq_off | 3.888 | 3.953 |
| vref_ib | 4.952 | 3.913 |
| vref_ib_spi_off | 4.768 | 4.029 |
| ab_restored | 3.823 | 3.879 |

`ab_irq_off`、`ab_restored` 的 ADC1 测 Ia；`vref_ib`、`vref_ib_spi_off` 的 ADC1测 VREFINT。内部参考按 ADC 码值统计。所有有效组两路寄存器均在更新，至少覆盖 26 种码值。

电流计算停止后原始电流码仍波动，内部参考码也有明显波动。

首轮 `vref_compare.py` 曾尝试在 ADC1 增加第二个 VREFINT 通道，出现 ADC2 JDR1固定在 2042 的现象；该组已标为无效，不用于来源结论。恢复原序列后 ADC2 更新恢复。后续上述复核采用原序列长度并保持两路首个采样时长一致，独立检查两路码值确实变化。

### ADC 时钟对照

两路 ADC 完全停用后再改公共时钟，并屏蔽电流计算中断读取 JDR。原配置为 HCLK/4 同步 40 MHz；诊断配置为 SYSCLK 经异步预分频得到 20/10 MHz，采样周期数仍为 47.5，所以同时改变了时钟模式与物理采样时长。每组约 12 s、2100～2200 个 SWD 观测点。

| 条件 | A/B 标准差（码） |
|---|---:|
| clock40_before | 3.770 / 3.808 |
| clock20 | 3.917 / 3.457 |
| clock10 | 2.872 / 2.878 |
| clock40_after | 3.693 / 3.934 |

10 MHz ADC 时钟下，两路标准差约降到 2.87 码；恢复 40 MHz 后重新升高。

### 对照结论

ADC 原始码已有波动。延长采样窗口、移动触发、停 SPI、关 USB 遥测和停电流计算均未消除主波动；内部参考码同样波动，降低 ADC 时钟后标准差减小。

## 注入 ADC 窗口内硬件过采样验证（2026-10-07）

### 测试配置

临时修改 ADC 寄存器，依次采集失能状态下的电流和零转矩 Stop 下的电压指令。

依据仓库 RM0440 Rev 9 §21.4.29、§21.4.30、§21.7.5：双 ADC 注入同步模式支持过采样，两路使用相同倍率和右移设置。停两路注入序列后修改 CFGR2，恢复 JSQR并重新启动。两路配置分别为：原配置 `0x00`；2 次平均 `0x22`（JOVSE、OVSR=0、OVSS=1）；4 次平均 `0x46`（JOVSE、OVSR=1、OVSS=2）。结果仍保持原 ADC 码值尺度。

保持 ADC 40 MHz、12 bit、47.5 周期采样时间、TIM1 CCR5=3665、20 kHz 触发不变。ADC1 首通道 Ia、ADC2 首通道 Ib 同步配置；ADC2 第二通道 Vbus 也会过采样，并非仅对电流通道生效。单路电流结果的名义转换耗时为 1.5 / 3 / 6 μs，ADC2 两通道序列为 3 / 6 / 12 μs，均小于 50 μs 触发周期。

两轮均按“原配置 → 2 次平均 → 4 次平均 → 原配置复测”执行。每组先舍弃约 1 s，再采集约 8 s、16 万个连续 20 kHz 样本；额外读取 100 组运行时诊断字段观察时序。FAST 采集 Ia、Ib、Id、Iq、Ud、Uq；NORMAL 采集 Vbus、Wm、Iq_ref、Theta_e、Position。ADC 码由 FAST 电流值按既有换算和偏置反推，并检查量化误差不超过 0.51 mA。本轮偏置为 Ia=2065、Ib=2045；与[2026-10-07：失能电流反馈波动的来源对照](#adc-origin-20261007)跨上电采集的偏置不同，因此采用本轮首尾基线作比较。

2 次平均使标准差下降约 29%～31%，4 次平均下降约 49%～53%，接近不相关噪声平均后的 1/√N 趋势。恢复原配置后波动恢复，说明本次改善来自采样配置变化。这与[2026-10-07：失能电流反馈波动的来源对照](#adc-origin-20261007)“仅延长单次采样时间基本无效”不同：本次平均了多个独立转换结果。

有感转矩模式，电流环带宽保持 2000 Hz。各组均在失能状态切换 ADC 配置，随后Enable → Run → Stop，确认 ENABLED、MOE=1、Iq_ref=0 后采集；每组结束先失能。电流 PI 在 Stop 下工作。表中电压指标定义为 √(Var(Ud)+Var(Uq))，去掉直流分量。

| 配置 | Ia / Ib 反馈标准差（A） | Udq 交流 RMS（V） |
|---|---:|---:|
| 原配置 | 0.1883 / 0.2266 | 0.3930 |
| 2 次平均 | 0.1290 / 0.1656 | 0.2773 |
| 4 次平均 | 0.0903 / 0.1263 | 0.2025 |
| 原配置复测 | 0.1914 / 0.2283 | 0.3972 |

相对首轮基线，2 次平均降低电压指令扰动约 29.5%，4 次平均降低约 48.5%；恢复原配置后扰动恢复。

### 时序与适用范围

以下时刻以 TIM1 下溢 ISR 的 DWT T0 为基准，数值为 Stop 各组 100 次 SWD 读取的中位数。

| 配置 | ADC ISR 进入时刻（μs） | 快环结束时刻（μs） |
|---|---:|---:|
| 原配置 | 24.684 | 39.559 |
| 2 次平均 | 26.250 | 39.919 |
| 4 次平均 | 29.244 | 42.909 |

2 次、4 次平均使 ADC ISR 分别约晚 1.57、4.56 μs。快环结束时间变化不完全相等，因为 ADC 中断与其他中断的重叠关系也改变。硬件平均不跨多个 PWM 周期，但仍增加窗口内转换时长与结果可用延迟。

截至 Stop 基线和 2 次组，快环累计最大 44.5625 μs；4 次组后增至 47.26875 μs，距 50 μs 周期末约 2.73 μs。计数包含组间过渡。

窗口内硬件平均降低了失能采样波动和零转矩 Stop 下的电压指令扰动。

### 固定采样窗口与 0.88 限值

### 调制比定义与结果

本工程电压指令的归一化定义为：

```text
m_cmd = sqrt(3) * hypot(Ud, Uq) / Vbus
      = sqrt(3) * hypot(Ualpha, Ubeta) / Vbus
```

第一轮 FAST 同周期采集 Ia、Ib、Vbus、Iq、Ud、Uq；后两轮将 Ud/Uq 换为 Ualpha/Ubeta。超过线性区后，按当前 SVPWM 零序注入、0～1 截断及 ARR=4250 的整数截断反算占空比：

```text
Ualpha_pwm = Vbus * (2*Da - Db - Dc) / 3
Ubeta_pwm  = Vbus * (Db - Dc) / sqrt(3)
m_pwm     = sqrt(3) * hypot(Ualpha_pwm, Ubeta_pwm) / Vbus
```

m_pwm 由每个 PWM 周期的占空比反算平均电压矢量范数，表中再对采集窗口计算均值和峰值；电压分量与 Vbus 来自同一 FAST 样本。

| 临时指令上限 | 保持时速度指令（rpm） | 实际平均转速（rpm） | 平均 `m_cmd` | 平均 `m_pwm` 估算 | 最大 `m_pwm` 估算 | 相电流峰值（A） |
|---|---:|---:|---:|---:|---:|---:|
| 1.00 | 8500 | 8427.64 | 0.999996 | 约 1.0000 | 约 1.0001 | 1.893 |
| 1.1547 | 9000 | 8889.07 | 1.154697 | 1.054319 | 1.154701 | 1.853 |
| 2.00 | 9300 | 9230.69 | 2.000001 | 1.100288 | 1.154701 | 2.699 |

每行保持约 15 秒。第一行以未过调制的指令范数近似输出，微小超过 1 的数值包含遥测量化误差。边界前后情况如下：

- 1.1547 版本：8750 rpm 能准确跟随；9000/9250 rpm 指令时实际约 8886～8889 rpm，几乎所有样本发生占空比截断。

## 电压限幅、占空比边界与 0.98 上限（2026-10-17）

### 两个限制处于不同处理阶段

| 限制 | 代码位置 | 含义 |
|---|---|---|
| `VOLT_MOD_MAX=0.98` | `User/control_params.h`、电流环及前馈后的矢量限幅 | 限制 `hypot(Ud,Uq) ≤ 0.98*Vbus/sqrt(3)` |
| `Da/Db/Dc ∈ [0,1]` | `Algo/Voltage_Mod.c::SVPWM_Calc()` | 每个桥臂的有效导通比例为 0～100%，过界时截断 |
| `CCR=Duty*ARR` | `Motor/Motor_PWM.c::PWM_Update()` | 将可实现的占空比转换为定时器比较值 |

由本工程零序注入公式，三相未限幅占空比的跨度为 `(Umax-Umin)/Vbus`，最大/最小值对称分布于 0.5 两侧。对任意电角度，`Umax-Umin ≤ sqrt(3)*|U|`，所以本工程 `m≤1` 能在理想计算中保证占空比合法；`m>1` 时部分角度需要截断。

占空比范围合法不等于电压矢量 `m≤1`。例如 `(Da,Db,Dc)=(1,0,0)` 时，`Ualpha=2*Vbus/3`、`Ubeta=0`，因此 `m=2/sqrt(3)≈1.1547`，三个占空比仍都在 0～1 内。这个值是可实现电压六边形顶点的矢量幅值；不能保持相同幅值无失真地旋转一整圈。线性圆内保持幅值和相角，超过线性圆后需要处理可实现边界。ST 的[过调制说明](https://wiki.st.com/stm32mcu/wiki/STM32MotorControl:SDK_Overmodulation)也明确区分线性区与过调制区；其中调制指数的归一化不同，不能把其 `sqrt(3)/2` 直接当成本工程限值。

### 与此前 SVPWM 优化分支的关系

本轮动态采样及三套实验固件均保留三路占空比限幅。此前 `28d3299` 版本在上游电压限幅前提下删除了该限幅。

保留上游 0.88 时，理想占空比有 0.06～0.94 的余量，删去重复限幅具有明确前提。若同时把上游改为大于 1，该前提就不成立。以 `m=1.10`、`Ualpha=0` 为例，SVPWM 算出 `(Da,Db,Dc)=(0.5,1.05,-0.05)`；保留限幅时输出 `(0.5,1,0)`，取消限幅后则将越界值送入 `PWM_Update()`。

TIM1 不能输出 105% 或负 5% 占空比；PWM1 下比较值超过 ARR 会进入持续有效状态，而负浮点值乘 ARR 后转换为 `uint32_t` 不能作为可移植、受控的 0% 输出实现。不能假设硬件或编译器会等价替代当前软件限幅。定时器比较行为见[STM32G4 RM0440 的 PWM 模式说明](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)。

### 正式限值

**最终将动态采样版本的 `VOLT_MOD_MAX` 从 `0.88f` 改为 `0.98f`，保留三路 0～1 限幅。**线性边界及 1.00 保持试验结果见前文；最终采用 0.98。0.98 比本工程线性圆边界低 2%，理想占空比范围为 0.01～0.99。该常量同时影响电流环、前馈后的矢量限幅、辨识电压包络、I/F 电压预算及 Iq 电压能力估计。保留占空比边界还能覆盖数值误差。

限值变更对应独立触发、动态选相配置。

VOLT_MOD_MAX 限制电压指令，同时参与 Iq_Limit_Calc() 和 I/F 电压预算。实验中的 m_pwm≈1.10 对应 m_cmd≈2.00。

### 占空比直接比较优化与离线验证

`SVPWM_Calc()` 将三次 `Limit_Value(&D,0,1)` 改为每相两次独立 `if` 比较：先截断大于 1 的值，再截断小于 0 的值。

离线检查使用 ST Arm Clang 21.1.1+st.7、Cortex-M4 硬浮点、-Oz。最终 ELF 中 `SVPWM_Calc` 仍位于 CCMRAM；函数本体为 268 字节，三次限幅调用降为零，编译器报告的局部栈占用从原实现的 56 字节降为零。限幅段使用浮点比较、条件执行及寄存器赋值。

主机使用当前实际 `Voltage_Mod.c` 与 `69897b5` 原实现（调用实际 `Math.c::Limit_Value`）比较：扫描 4096 个母线 ADC 码、1024 个角度、8 个调制幅值，包含 0、0.49、0.98、1 的相邻浮点值、1、1.1547、2，并增加零/负母线及 `(0.5,1.05,-0.05)` 截断用例。合计 33,554,436 组输入的三相输出逐位一致；扫描中 `m≤0.98` 的占空比落在`[0.009999,0.990001]`（含浮点容差），全部用例的占空比均在 `[0,1]`，按 `ARR=4250` 转换的 CCR 均在 `[0,4250]`。
