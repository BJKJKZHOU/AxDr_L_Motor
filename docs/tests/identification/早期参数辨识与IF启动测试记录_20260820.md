## 方案背景

原 Voltage Align 在电流达到 `1 A` 后停止增加电压，但会继续保持当前`Ualpha`。实测中电流在保持电压期间继续上升，约 `545.6 ms` 后触发`2 A` 总保护：

```text
Ia max =  2.054 A
Ib min = -1.047 A
Ic min = -1.088 A
```

禁能时三相零点约在 `±0.16 A` 内，因此上述越限不是静态采样偏置导致的误触发。

## PROBE 后 Align 方案

新方案先用低电压交流激励获取粗略 Rs/Ls，再使用粗略参数设置临时电流环执行 Current Align，最后完成正式的两段 Rs/Ls 测量。

```text
PROBE_RAMP
    100 Hz Ualpha 正弦激励，无直流分量
    Uac 每个完整周期增加 0.01 V
    Iac 目标 0.2 A
    Uac 最大 0.5 V
        |
        v
PROBE_MEASURE
    测量 5 个 100 Hz 周期
    同步提取复阻抗，获得 Rs_Rough/Ls_Rough
        |
        v
ALIGN
    按 Rs_Rough/Ls_Rough 设置临时 Id/Iq PI
    电流环带宽 200 Hz
    Id 目标 1 A，保持 0.5 s
        |
        v
RAMP
    Ualpha = Uhold + Uac * sin(2*pi*100*t)
    Iac 目标 0.4 A
    Uac 最大 1 V，每周期增加 0.005 V
        |
        v
SETTLE -> MEASURE_A -> MEASURE_B -> DONE/FAILED
```

临时 PI 参数按下式计算：

```text
Wc = 2*pi*200
Kp = Ls_Rough*Wc
Ki = Rs_Rough*Wc
```

Align 结束、辨识失败或中止时恢复原 Id/Iq PI 参数。`DISABLE` 在辨识过程中仍可以关闭 PWM 并中止辨识。

## 测试方法

## 正式辨识工作点扫描

### 目的和参数

通过改变正式 RAMP 的交流电流目标，检查 Rs 是否因逆变器固定压降或 PWM死区而随电流增加明显下降，同时检查 Ls 是否随电流变化。

扫描过程中保持以下参数不变：

```text
PROBE Iac target = 0.2 A
ALIGN Id target  = 1.0 A
激励频率         = 100 Hz
Vbus             ≈ 14.5 V
相电流总保护     = 2 A
```

为减少低电压工作点的量化误差，测试固件临时将正式 RAMP 的电压步进从`0.02 V/周期` 改为 `0.005 V/周期`。分别构建：

```text
Iac target = 0.2 A
Iac target = 0.4 A
Iac target = 0.5 A
Iac target = 0.6 A
```

### 工作点趋势分析

`0.2 A` 和 `0.4 A` 工作点的 Rs 平均值分别为 `0.076661 ohm` 和`0.076631 ohm`，两者只相差约 `0.04%`。`0.6 A` 工作点的 Rs 平均值为`0.079648 ohm`，比 `0.4 A` 结果高约 `3.9%`。

Ls 没有随电流增加而下降，所有工作点整体保持在约 `17 uH`。未观察到明显的磁饱和趋势，当前 SPMSM 第一版使用单一 Ls 模型是合理的。低电流 `0.2 A` 组的 Ls 离散度较大。

## 辨识结果 Apply

辨识完成后结果不会自动覆盖电机参数，也不会自动写入 Flash。只有在：

```text
Servo = DISABLED
Identification = DONE
Result.Valid = true
```

时，显式执行 `IDENT APPLY` 才会把结果应用到 RAM：

```text
Motor_Para.Rs = Result.Rs
Motor_Para.Ld = Result.Ls
Motor_Para.Lq = Result.Ls
```

随后按照当前默认电流环带宽重新计算 Id/Iq PI：

```text
Kp_d = Ld * Wc
Ki_d = Rs * Wc
Kp_q = Lq * Wc
Ki_q = Rs * Wc
```

命令行入口：

Apply 将辨识结果写入 RAM。

## Apply 后低电流电流环验证

### 测试条件

在一次完整 `RS_LS` 辨识并执行 `IDENT APPLY` 后，通过 USB 运行原Open Loop 路径。该次辨识结果为：

```text
Rs = 0.0752737 ohm
Ls = 15.9588 uH
IDENT_APPLY OK
Vbus = 14.47 ~ 14.50 V
```

Open Loop 仍使用原固定参数：

```text
ALIGN: Id_Ref = 0.2 A, Iq_Ref = 0 A, 0.5 s
RUN:   Id_Ref = 0 A,   Iq_Ref = 0.2 A, We = 20 rad/s electrical
```

USB FAST 以 `20 kHz` 同步采集 `Id/Iq/Ud/Uq/Ia/Ib/Ic`。为区分开关和采样纹波与控制环低频振荡，分析时另外对原始数据做 `1 ms` 分组均值；该处理只用于离线分析，不改变 FAST 采样率。

### 实测结果

| 阶段 | 信号 | 均值 | 1 ms 误差 RMS | 1 ms min/max |
|---|---|---:|---:|---:|
| ALIGN | Id | 0.19997 A | 8.46 mA | 0.1753 / 0.2255 A |
| ALIGN | Iq | -0.00001 A | 10.06 mA | -0.0290 / 0.0245 A |
| RUN | Id | 0.00001 A | 9.41 mA | -0.0304 / 0.0410 A |
| RUN | Iq | 0.19995 A | 9.49 mA | 0.1639 / 0.2332 A |

电压矢量峰值为 `0.0835 V`。按实测母线电压计算，电流环电压限幅约为`7.94 V`，峰值只占限幅的 `1.05%`，没有电压饱和。

`700 ~ 1300 Hz` 范围内的 Id/Iq 最大离散谱峰约为 `3 ~ 4 mA`，未观察到持续的 `1 kHz` 电流环振荡。原始瞬时电流纹波明显大于 `1 ms` 均值误差，表现为瞬时电流纹波大于低频均值误差。

三相电流峰值为 `0.483 A`，没有单相异常。`Ia + Ib + Ic` 的 `1 ms` 均值RMS 为 `34.3 mA`，仍存在可见的三相采样误差。

该阶段结论为：辨识参数 Apply 后，原固定角度 Align 和低速 Open Loop 电流环工作正常，当前 `1 kHz` 设计带宽没有表现出过激或电压饱和。

## I/F 启动工作点与取舍

母线约 14.5 V，FAST 20 kHz 采集电流和电压。机械表现由现场观察记录，编码器当时无效。前五个工作点各次重新辨识的 Rs 为 0.072462～0.079221 Ω、Ls 为 16.2822～17.0531 μH；最后两组固定 Rs=0.075 Ω、Ld=Lq=16.6 μH。

### 启动前 PI 未清零导致电流冲击

首次启动约 24 ms 后，相电流峰值达到 11.078 A，主机按 1.5 A 阈值中止。中止后 PWM 禁用时读得 Ud/Uq=+5.63/−5.63 V，矢量幅值约 7.96 V；原因是禁用期间 PI 积分累积，Sensorless 路径在开启 PWM 前未清零 PI。

在 `Sensorless_Start_Begin()` 中开启 PWM 前调用 `Current_Loop_State_Reset()` 后，以 Id=0.2 A 做 0.25 s Align：Id 均值 0.19937 A，相电流峰值 0.4830 A。

### 工作点对照

速度和加速度均为电角量。前五组 Ready 确认时间为 0.3 s；表中的保持时长指 Ready 后继续观察的时间。

| 工作点 | Align Id / 时长 | Iq 起点→目标 A | 目标速度 rad/s | 加速度 rad/s² | 相电流峰值 A | 现场结果 |
|---|---|---|---:|---:|---:|---|
| 1 | 0.2 A / 0.5 s | 0.2→0.5 | 200 | 100 | 0.7650 | 电流跟踪连续，未起转 |
| 2 | 0.5 A / 0.5 s | 0.5→1.0 | 200 | 100 | 1.2890 | 明显抖动，未连续转动 |
| 3 | 0.5 A / 0.5 s | 0.5→1.0 | 50 | 20 | 1.2890～1.3290 | 保持 0.2、5、20 s；延长保持后仍断续转动 |
| 4 | 0.5 A / 0.5 s | 0.5→1.0 | 20 | 5 | 1.4100 | 保持 20 s，转子多在同一位置往复 |

前两组电压矢量峰值仅为 0.1711 / 0.3449 V，未起转时电流能够跟踪。降低速度至 20 rad/s 未改善启动；提高 Iq 后由局部往复变为转动，再提高速度至 120 rad/s 后抖动减弱，因此后续采用较高电角速度工作点。

实机确认转子有 32 极，极对数由原配置 7 改为 16。I/F 角度直接按电角速度积分；20 / 50 rad/s 分别对应机械速度约 11.9 / 29.8 rpm。

最后两组主机相电流阈值分别为 2.2 / 2.8 A。120 rad/s 组母线均值 14.536 V，Iq 均值 1.6000 A，按 1 ms 均值统计的 Iq / Id 纹波 RMS 为 18.6 / 28.2 mA，电压矢量峰值 0.5168 V。
