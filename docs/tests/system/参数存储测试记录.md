## Manual 配置与 Effective 增益分离、ESO 提交校验（2026-10-07，主机测试）

主机测试使用内存 NVS，Save/reboot 通过保存记录和重新初始化 RAM 验证。

### 配置与验证条件

Manual 配置与运行增益分开：原六个 Gain ID 对应独立、可保存的 Manual Kp/Ki；Bandwidth 派生增益不保存。速度实际增益通过只读 `0x0A14 / 0x0A15` 读取。

写 Gain 或 Bandwidth 时同步选择对应来源；相同值写入也执行来源选择。切换来源只发布 RAM 增益。例如保存 Kp=0.04 后在 RAM 改为 0.05，切 Bandwidth 再切回 Manual 仍为 0.05，重新上电后恢复 0.04。Save 要求 DISABLED，RUN 拒绝修改增益、带宽和来源。

模型与 ESO 系数先联合校验再发布，失败保留旧模型、带宽、系数及观测状态。Rs/Ls 粗探测临时模型不覆盖 Manual。NVS 恢复先收集完整候选：标量缺失/非法时保留 RAM 值；候选整体非法时返回 `-EINVAL`，保留旧模型和 ESO，其他独立配置照常恢复，拒绝该组校准且不重配编码器。启动配置被拒绝时 ESO 保持无效。
