# Mechanical ESO 有感速度测试记录（2026-09-17）

更新：2026-10-07。第 1～10 节保留历史结果；单圈角度修复见第 11 节，CCMRAM 见第 12 节；2000 Hz 电流环及速度环扫描见第 13 节；辨识模型、高转速长时间运行后保持使能测试及 30 Hz 默认值同步见第 14 节。第 15～17 节记录 ESO 持续运行、编码器 CRC 排查和中速 GPIO 后的位置往复。第 18 节记录三种有感模式的轨迹与 Stop 回归，第 19 节记录电流声初步分析，第 20 节记录失能底噪、电流带宽对照及现场听感；500 Hz 仍有异常声音，具体干扰源尚待定位。

## 1. 目的

本记录用于固化 `feat/mechanical-eso` 分支的首轮实机验证结论。

Mechanical ESO 的当前职责边界：

- 20 kHz 快环运行；
- 输入编码器连续机械位置、实际 `Iq` 和已辨识 `J/B/Flux/Pp`；
- `Wm_hat` 作为有感 Torque / Speed / Position 模式的速度反馈来源；
- `Theta_hat`、`Td_hat` 和观测误差仅用于诊断；
- FOC 电角度与 Position Loop 位置反馈仍直接使用编码器；
- 暂不加入 disturbance compensation、notch、encoder periodic correction 等额外控制功能。

测试电机本轮使用 MT6835，固件按完整 21-bit 角度读取。

## 3. ESO Bandwidth 扫描

固定：

- Speed BW = 50 Hz；
- current limit = 1 A；
- 相同 Motor 参数与 Servo Phase 结果。

测试 `ESO BW = 100 / 150 / 200 Hz`，每个非零速度保持 5 s，再回零 3 s。

非零段最后 2 s 的 `Wm_hat`：

| 速度指令 | ESO 100 Hz | ESO 150 Hz | ESO 200 Hz |
| --- | ---: | ---: | ---: |
| +1 rad/s | +0.881 ± 0.687 | +0.872 ± 0.794 | +1.091 ± 0.671 |
| -1 rad/s | -1.155 ± 0.636 | -0.937 ± 0.777 | -0.630 ± 0.691 |
| +2 rad/s | +1.968 ± 0.700 | +1.905 ± 0.738 | +1.969 ± 0.728 |
| -2 rad/s | -1.945 ± 0.705 | -1.973 ± 0.670 | -1.905 ± 0.719 |

结论：

- 提高 ESO BW 没有一致改善速度纹波；
- 旧编码器差分速度与 ESO 速度高度相关，相关系数约 0.99；
- 零速段均可稳定，末段平均速度绝对值低于 0.009 rad/s；
- ESO Error 随 BW 提高有所降低，但 `Td_hat` 波动没有明显改善；
- `Iq Ref` 采样峰值约 0.466 A，未触及 1 A 限幅；
- 本轮不继续通过提高 ESO BW 处理该速度纹波。

ESO BW 恢复为 100 Hz。

## 10. 当前结论

Mechanical ESO V1 当前可保留：

- 20 kHz 运行路径已建立；
- 正反方向平均速度跟踪正确；
- 零速可稳定；
- Speed Loop 使用 ESO `Wm_hat` 后无持续发散或保护故障；
- ESO BW 100~200 Hz 扫描没有解决现有周期速度纹波；
- 约 12/14 阶周期成分来源暂不下结论；
- 不因该未决问题继续扩大 observer/control 架构。

后续如需要定位 12/14 阶来源，应优先使用更高采样率和独立机械角度参考，而不是继续在当前 ESO 上叠加补偿算法。

## 11. 2026-10-06：单圈机械角度修复

### 原因与实现

旧实现将连续机械角度保存在 `float State.Theta`，每 50 μs 在这个大数上累加角度增量。
原代码主机回放中，同样的理想 80 rad/s 输入，位置起点为 0、4096、8192 rad 时，
ESO 平均输出分别约为 80.04、82.96、87.64 rad/s。保留输入量化、仅减去位置原点，
后两组恢复到约 80.00 rad/s，证实存在累计角度相关的数值偏差。

现在直接输入 `Encoder.Theta_m`；`State.Theta` 保持单圈，角度误差按最短方向回绕。
跨零时继续积分 `Wm` 和 `Td`，不重置状态。圈数和位置控制继续由原位置链路管理。
`PARAM_MECH_ESO_THETA` 诊断定义同步改为单圈机械角度；速度、扰动转矩公式及 20 kHz 周期不变。

`tools/test_mechanical_eso.py` 编译实际 ESO/Math C 源码进行主机回归，覆盖正反方向、
跨零、不同累计位置以及短时角度无效。它不代替 MCU 时序与电机闭环验证。

### 实机结果

使用下载前保留的 RAM 模型，Rs=0.271844 Ω、Ld=Lq=69.8889 μH、Flux=0.00228238 Wb、
J=1.67043e-5 kg·m²、B=8.00185e-6 N·m·s/rad，7 对极；电流限值 2 A，电流环 500 Hz、
速度环 20 Hz、机械 ESO 100 Hz。模型没有写入参数 Flash。

首先在无感运行时旁路计算 ESO，并将实际 Ia/Ib 按编码器电角度投影为 ESO 的 Iq 输入。
80、120、150、-80 rad/s 四组均产生正常的单圈 ESO 输出，平均速度与 PLL 基本一致。
但并行运行无感观测器、机械 ESO 和 6 通道 20 kHz 遥测时，ADC 快环主体约 29 μs，
加上触发位置和中断开销后跨过 50 μs 周期，并出现遥测丢块。
因此新增只用于 SWD 调试的 `Motor_ESO_Shadow` 开关，默认关闭；无感控制反馈仍取 PLL。
旁路条件仍要求有效校准及就绪、无故障的编码器。有感模式不受此调试开关影响。

最终固件直接以机械 ESO 为有感速度反馈，统计各组末段约 3 s：

| 目标 (rad/s) | ESO 均值 (rad/s) | 编码器差分均值 (rad/s) | ESO 标准差 (rad/s) | ADC 快环主体中位数 (μs) |
| --- | ---: | ---: | ---: | ---: |
| +20 | 19.8340 | 19.8334 | 0.8648 | 17.21 |
| +80 | 79.8081 | 79.8058 | 0.6032 | 17.16 |
| -80 | -79.8044 | -79.8014 | 0.6328 | 17.13 |

三组有感测试的编码器漏采样、遥测丢块和 `Deadline_Miss` 增量均为零。
稳态 ESO 角度误差峰值小于 0.0019 rad，没有整圈回绕尖峰；现有周期速度纹波仍然存在。
这些结果验证本次单圈修复与指定工况，不能代替全转速、全负载验证。

最终固件另完成一次旁路关闭的 +80 rad/s 无感启动回归。该组遥测丢块 3 个，
全程 `Deadline_Miss` 增量 48850，编码器无漏采样；稳态 ADC 主体约 21.35 μs。
不能把无感全流程的时序问题标为已解决。

测试结束已停机、失能，恢复下载前的 RAM 模型、模式和零速度目标，旁路开关为 0。
本轮未接入 CCMRAM；当前链接段为空，后续应评估已有 `feat/ccmram-fast-code` 实现，
并先处理普通 RAM 与 CCM 别名区的重复分配。

原始数据保留在本机 `/tmp/eso_single_turn_20261006/`：`capture/` 为首次无感旁路采集，
`reorder/` 为回绕调用顺序调整后的复核，`final_test/` 为最终无感及有感回归；
主机原代码回放保留在 `/tmp/eso_replay_20261006/`。


## 12. 2026-10-06：快环代码移入 CCMRAM

### 放置与启动验证

复用已有 CCMRAM 分支的 `FAST_CODE` 与 `.preinit_array` 启动复制方式，直接修改当前工作区，
没有切换、合并或回退分支。控制公式、20 kHz 快环、2 kHz 慢环调度、辨识代码及注入参数均未改变。

- `User/Fast_Memory.h` 将指定函数放入 `.ccmram_text`；`User/Fast_Memory.c` 在 `main()` 前由 Flash 复制到 CCM。
- 普通 RAM 改为 96 KB，栈顶为 `0x20018000`。末尾 32 KB 的 SRAM 别名不再与 CCM 代码重复分配。
- CCM 内包括 ADC/PWM/编码器中断入口、快环分派、电流环、Flux Observer、PLL、Mechanical ESO、
  I/F 与接管热点、数学运算、编码器读数处理、快速保护、PWM 更新及 FAST 采样。
- 2 kHz 控制、辨识专用流程、USB/RTOS 和通用 HAL 仍在 Flash；DMA 缓冲区留在普通 RAM，查表常量留在 Flash。

Release 构建占用：CCM 8,948 B / 32 KB，普通 RAM 26,744 B / 96 KB，Flash 101,380 B。
链接与反汇编确认关键函数位于 `0x10000000..0x100022F3`，启动复制函数本身仍位于 Flash。
下载校验通过；下载复位和额外一次复位后，SWD 读取的完整 CCM 代码均与 ELF 提取内容逐字节一致。
主机 ESO 回归与参数生成一致性检查通过。修改前后 C 源码比对确认仅增加段属性及头文件引用。

### 当前判断与验证顺序

优先假设是反馈噪声/采样误差与较高电流环增益共同造成电压、电流调节波动；
也需要区分真实 PWM 电流纹波、驱动死区/器件非线性及机械声学共振。
电流带宽 2000 Hz 是设计值，未测频响与稳定裕度，不能直接宣称过高或已振荡。
PWM 为 20 kHz 也不能单独证明听到的声音就是载波：低频电流调节波动仍可能产生可闻声。

建议后续按以下顺序做对照，本节未执行新增带宽扫描，也未改控制代码或持久化参数：

1. 在静止、同一电角位置比较 DISABLED 与 TORQUE/ENABLED、Id_ref=Iq_ref=0，
   采集 20 kHz Ia/Ib、Id/Iq、Ud/Uq 和电流参考，同时记录现场听感。
   DISABLED 时 `Motor_Run.Id/Iq` 可能保持旧值，应以仍在更新的 Ia/Ib 作为采样基线。
2. 保持 PWM 20 kHz、零转矩参考和其他参数不变，仅在 RAM 对照电流带宽
   2000/1000/500 Hz，参数切换在失能状态完成；完成后恢复原值。
   若声音和电压/电流波动随增益明显下降，支持电流环放大反馈扰动的假设，
   但仍需区分测量噪声和真实纹波，不能直接把降带宽当成最终修复。
3. 对照 PWM 关闭时的 ADC 底噪、开启后的放大器稳定时间和采样窗口；必要时用

不宜直接加入很重的电流反馈滤波或仅提高 PWM 频率：前者增加闭环延迟，后者改变

### 当前结论与恢复检查

1. 波动已直接出现在 ADC 原始结果中，电流换算、Clarke/Park、PI 不是其原始产生点；
   闭环 PI 会将测量噪声转成电压扰动，这与第 20 节实验相容。
2. 在本轮失能条件下，延长采样窗口、移动触发位置、停 SPI、关 USB 遥测、停电流

3. 内部参考也波动、较低 ADC 时钟有改善，下一层应区分 ADC/参考侧与外部电流输入

4. 几个码可以是正常底噪，但当前量程下对应的电流反馈扰动不小。应同时评估量程、

## 22. 注入 ADC 窗口内硬件过采样验证（2026-10-07）

### 目的与配置

验证单个 PWM 采样窗口内连续转换并平均，能否降低第 21 节的采样波动，以及
零转矩 Stop 下电流 PI 输出的电压扰动。先失能测试，再做短时 Stop 闭环测试。
本轮只临时修改 ADC 寄存器，未修改固件、控制参数或写入 NVS。

依据仓库 RM0440 Rev 9 §21.4.29、§21.4.30、§21.7.5：双 ADC 注入同步模式支持
过采样，两路使用相同倍率和右移设置。停两路注入序列后修改 CFGR2，恢复 JSQR
并重新启动。两路配置分别为：原配置 `0x00`；2 次平均 `0x22`（JOVSE、OVSR=0、
OVSS=1）；4 次平均 `0x46`（JOVSE、OVSR=1、OVSS=2）。结果仍保持原 ADC 码值尺度。

保持 ADC 40 MHz、12 bit、47.5 周期采样时间、TIM1 CCR5=3665、20 kHz 触发不变。
ADC1 首通道 Ia、ADC2 首通道 Ib 同步配置；ADC2 第二通道 Vbus 也会过采样，
并非仅对电流通道生效。单路电流结果的名义转换耗时为 1.5 / 3 / 6 μs，
ADC2 两通道序列为 3 / 6 / 12 μs，均小于 50 μs 触发周期。

两轮均按“原配置 → 2 次平均 → 4 次平均 → 原配置复测”执行。每组先舍弃约 1 s，
再采集约 8 s、16 万个连续 20 kHz 样本；额外读取 100 组运行时诊断字段观察时序。
FAST 采集 Ia、Ib、Id、Iq、Ud、Uq；NORMAL 采集 Vbus、Wm、Iq_ref、Theta_e、Position。
ADC 码由 FAST 电流值按既有换算和偏置反推，并检查量化误差不超过 0.51 mA。
本轮偏置为 Ia=2065、Ib=2045；与第 21 节跨上电采集的偏置不同，因此采用本轮
首尾基线作比较。本轮开始时 Deadline 与遥测丢块计数均为 0。

### PWM 关闭的采样波动

| 原配置 | 4.100 / 4.148 | 0.1652 / 0.1671 | 0.791 |
| 2 次平均 | 2.823 / 2.940 | 0.1137 / 0.1184 | 0.793 |

### 零转矩 Stop 闭环

有感转矩模式，电流环带宽保持 2000 Hz。各组均在失能状态切换 ADC 配置，随后
Enable → Run → Stop，确认 ENABLED、MOE=1、Iq_ref=0 后采集；每组结束先失能。
电流 PI 在 Stop 下工作。表中电压指标定义为 √(Var(Ud)+Var(Uq))，去掉直流分量。

| 配置 | Ia / Ib 反馈标准差（A） | Udq 交流 RMS（V） |
|---|---:|---:|
| 原配置 | 0.1883 / 0.2266 | 0.3930 |
| 2 次平均 | 0.1290 / 0.1656 | 0.2773 |

| 原配置复测 | 0.1914 / 0.2283 | 0.3972 |

这里的电流反馈仍同时包含测量噪声与可能的真实电流，不能据此宣称真实相电流

## 26. 0.95 调制度采样窗口核验（2026-10-07）

结论：当前固定 A/B 两相、47.5 周期采样、两次硬件平均的配置，不能在 0.95
调制度下保证整个电角周期的有效采样。本次完成板上只读配置核验和实际 SVPWM
算法的离线角度扫描；采样时序前提不通过，因此没有进行 0.95 带电升速试验，
不能将本节称为 0.95 电机运行实测或模拟波形测量。

### 板上核对与验证方法

SWD 读回 ARR=4000、PSC=0、CCR4=2375、CCR5=3800；ADC1/2 CFGR2 均为 0x22，
Ia/Ib 的采样时间字段均为 47.5 周期。对应当前 160 MHz 定时器、40 MHz ADC，
PWM 为 20 kHz，ADC 触发为周期起点后 23.750 μs。
只读 Flash 导出与当前 Release ELF 的二进制一致，ELF SHA256 为
`c229113ac2627a60fa96e8cfca32062f30a830ecdc702e3bc03a25cf73075c18`。

主机直接编译当前 `Algo/Voltage_Mod.c` 和 `Algo/Math.c`，调用 `SVPWM_Calc()`，
按 0.01° 步长扫描电压矢量角度 0～359.99°，每个调制度 36,000 点。
按 `PWM_Update()` 的 float 乘 ARR 后截断规则计算 CCR，再求固定 A/B 两相
共同低侧导通区间。调制度定义为 `m = sqrt(3) * |Uαβ| / Vbus`。

这是每个电压矢量在该 PWM 周期保持不变时的理想窗口检查，未扣除驱动死区、
传播延迟、运放恢复及 ADC 触发同步延迟；未模拟相邻周期占空比的变化。
“完整采样窗口不满足”不等于该角度必然出现某个幅值的电流误差。

### 为什么仅移动触发点不够

在当前设置下，单次采样阶段 47.5/40=1.1875 μs，单次采样加转换
(47.5+12.5)/40=1.5000 μs。两次平均的名义采样区间为：

- 第一次：23.7500～24.9375 μs；
- 第二次：25.2500～26.4375 μs。

从第一次采样开始到第二次采样结束共 2.6875 μs，两次采样保持时刻相隔
1.5000 μs。最后的 SAR 转换可在有效导通窗口之外完成，不计入上述采样跨度。

例如 m=0.95、电压矢量角度 30° 时，实际算法得到 CCR1/2/3=3900/2000/100，
A 相占空比为 97.5%，A/B 共同低侧导通窗口只有 24.375～25.625 μs，宽 1.250 μs。
第一次采样开始早于窗口 0.625 μs，第二次结束晚于窗口 0.8125 μs。
即使仅要求两个采样保持时刻都处于理想窗口，1.500 μs 的间隔也大于窗口宽度，
因此该角度不可能只通过平移触发时刻解决。

对称 SVPWM 最不利固定 A/B 窗口的连续值为 `25 * (1-m) μs`：

| 调制度 | 最窄理想窗口（连续值） | 当前固定触发完整采样窗口检查 |
|---|---:|---|
| 0.80 | 5.0000 μs | 扫描未发现越界 |
| 0.85 | 3.7500 μs | 扫描未发现越界；仍需模拟建立时间余量 |
| 0.885 | 2.8750 μs | 名义尾部余量为零，不能作为工程可用上限 |
| 0.90 | 2.5000 μs | 扫描约 22.88% 角度越界 |
| 0.95 | 1.2500 μs | 扫描约 47.19% 角度越界 |

扫描使用整数 CCR，个别最小窗口与表中连续值有一个计数附近的量化差异。
0.95 下 16,988/36,000 个角度不满足当前固定触发的完整采样区间条件；
其中 15,956 个角度的窗口本身小于 2.6875 μs，即使允许逐角度移动触发点仍放不下。
这些比例描述离线角度覆盖，不是实测坏样本率或故障概率。

在忽略全部建立时间的连续模型下，当前固定触发的完整孔径上限约为 0.885；
优化固定触发位置最多提高至 0.8925。这两个数都是零裕量数学边界，不能当作
经过验证的运行限值。固件 `VOLT_MOD_MAX=0.95` 只是电压矢量限幅，未自动保证
固定 A/B 电流采样在该范围内始终有效。

### 本轮状态与后续方向

全过程保持 DISABLED、MOE=0；母线读数约 24.62～24.63 V，Ready=Valid=1，
Fault/Error/Trip=0。持久化参数前后相同，用户电流限值保持 10 A；没有修改
固件、IOC、控制参数或 NVS。上一节 6000 rpm 一分钟实测仍是当前运行验证边界，
其全程最大监测调制度为 0.8232，不能外推到 0.95。

若保留两次平均并希望覆盖 0.95，应进一步设计按占空比选择有效的两相采样、
接入并校准 C 相电流通道，同时核对相选择、PWM 生效和 ADC 触发的一致性。

### 发现 1：Stop 后 Motion_Ref.Am 保留减速末值

## 29. Manual 增益保留与 NVS 选择保存回归（2026-10-07，主机测试）

本次解决 Bandwidth 下保存配置会覆盖已有手调增益、切回 Manual 无法恢复的问题。
不调整电流/速度/位置控制器数值，不改变参数 ID、Flash 记录格式或控制周期。
本轮没有重新烧录、操作电机或改写开发板 NVS；以下是主机回归和固件构建结果。

### 公共存储 API 与调用方策略

```c
int NVS_Storage_Save(const uint16_t *Ids, uint16_t Count, NVS_Select_e Select);
int NVS_Storage_Load(uint16_t Id);
```

| 调用 | 行为 |
|---|---|
| `Save(Ids, Count, NVS_INCLUDE)` | 按列表顺序保存指定持久化参数 |
| `Save(Ids, Count, NVS_EXCLUDE)` | 保存除列表所列 ID 之外的持久化参数 |
| `Save(NULL, 0, NVS_INCLUDE)` | 不保存任何参数 |
| `Save(NULL, 0, NVS_EXCLUDE)` | 保存全部持久化参数，包括当前运行增益 |
| `Load(Id)` | 读取指定 Flash 记录，经 `Parameter_Restore()` 校验后写入 RAM，不触发修改回调 |
| `Load(NVS_ALL)` | 全量恢复；缺失/非法记录保留 RAM 原值，之后统一更新模型、编码器和校准有效性 |

列表中含未知或非持久化 ID、非空数量配空指针、非法选择方式，保存返回错误；
列表校验在写入前完成。重复 ID 可以传入，底层 NVS 对相同记录返回 0 时仍算成功。
多项保存不是掉电事务；发生写错误时停止，之前已成功的记录仍保留。

`NVS_Storage_Save()` 不检查 Bandwidth/Manual。`MOTOR_CMD_PARAMETER_SAVE` 的处理处
根据两个环各自的来源生成最多六个排除 ID：电流环 Bandwidth 排除 Id/Iq 四个增益，
速度环 Bandwidth 排除速度 Kp/Ki。配置保存仍只允许 DISABLED。
直接调用公共保存 API 可以保存带宽计算出来的增益，这是公共接口的明确语义。

校准保存使用 INCLUDE 列表，保留原有顺序：先保存 `Valid=0`，然后保存极对数、
编码器配置、方向和偏置，最后保存 `Valid=1`。任一步失败立即返回，不继续写后续记录。

### Manual 切换

显式从 Bandwidth 切到 Manual 时，参数层按 ID 调用公共加载接口恢复对应增益。
重复写入 Manual 不重新加载，保留未保存的 RAM 调参结果；修改增益仍沿用原来的
隐式 Manual 行为，写入相同值不触发回调的原有规则也保留。

整组 Flash 记录均不存在时，沿用当前增益作为首次手调起点；部分缺失、长度错误、
非法数值或读取失败时，撤销本次已经恢复的增益并返回配置错误，来源保持 Bandwidth。
回退只使用本次调用的局部旧值，不增加常驻手调副本。
单项加载与回退逐项执行，不提供跨中断的整组原子切换，也不在 Flash 读取期间关中断。
来源切换继续只允许 DISABLED/ENABLED，RUN 拒绝修改。

上电全量加载保持原有规则：Bandwidth 根据恢复后的带宽和模型计算 PI，Manual 保留
Flash 中恢复的 PI。旧固件若已经用计算值覆盖了手调值，新固件无法找回历史值，需重新
手调并执行一次保存配置。

代码中位置规划/位置环每 1 ms 更新，编码器反馈在快环更新；NORMAL 每 1 ms
在电机线程中复制一次，各信号没有共同的状态快照。`Pos_Div` 与 `Normal_Div`
分别分频，存在 NORMAL 采样落在位置更新后的另一个 0.5 ms 节拍的可能。
1000 RPM 下 0.5 ms 对应 3°，与两组数据差异的量级相符。因此动态比较采用
位置环计算时已形成的 `Pos_Ctrl.Sig.Err`；不能将不同更新时刻的两个位置相减
直接称作位置环同步误差。精确的采样相位归属未做硬件时间戳验证。

第 31、32 节主机相减得到的“运行中最大跟随误差”也受此时序口径限制，历史原始值保留；
到位后的目标固定窗口、收敛表现及参数读回结果不据此撤销。本轮未改遥测代码。
