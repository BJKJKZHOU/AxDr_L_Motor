# PI / LADRC 电流内环与三环回归测试记录

测试日期：2026-10-17。分支：`feat/current-ladrc`。实测固件：`f30bead`。

**当前比较见[第二轮：固定手调 PI、LADRC 调参及保持/扰动测试](#manual-pi-tuning-20261017)。** 第一轮采用 PI 500 Hz Bandwidth；第二轮采用板上手调 PI 增益，保持速度、位置外环参数不变。

## 第一轮结论（PI 500 Hz Bandwidth）

PI 和 LADRC 作为电流内环时，本轮电流响应、速度正反转和位置往返的**基本功能均通过**。没有观察到保护触发或运动失控；电流注入和速度测试期间的快环 Deadline_Miss 均为 0。

两者速度跟踪表现接近，位置测试均到位。同帧电流响应的辅助幅相估计显示，LADRC 500/1500 Hz 在 200～1000 Hz 的幅值衰减更大、相位滞后更多。

三环采用 Id/Iq 电流内环、PI 速度环和 P 位置环；电流内环分别选用 PI 与 LADRC。

## 电流环响应

在 TORQUE / ENABLED 下，Id、Iq 分别注入峰值 0.3 A 的正弦，频点为 50、200、500、1000 Hz，每点激励 0.7 s。每种控制器共 8 个点，实际参考和反馈均有响应，未触发保护。

FAST 同帧采集 Ia、Ib、注入值、当前轴参考、反馈和控制器输出。采集期间出现 `Plot_Fast_Drop` 增长，关闭连续 SWD 读取后仍可复现，幅相分析采用同帧信号拟合。

下表为**辅助幅相估计**：使用同帧注入值和邻点变化方向估计局部正弦相位，剔除跳点边界与峰值附近样本后拟合反馈。增益为反馈幅值 / 实际参考幅值。

| 轴 | 频率 Hz | PI 增益 | LADRC 增益 | PI 相位 ° | LADRC 相位 ° |
|---|---:|---:|---:|---:|---:|
| Id | 50 | 0.985 | 0.980 | -6.71 | -9.07 |
| Id | 200 | 0.865 | 0.824 | -24.53 | -32.61 |
| Id | 500 | 0.629 | 0.520 | -42.20 | -54.47 |
| Id | 1000 | 0.488 | 0.299 | -54.87 | -69.12 |
| Iq | 50 | 1.003 | 0.992 | -7.24 | -9.60 |

| Iq | 500 | 0.665 | 0.543 | -49.34 | -61.89 |
| Iq | 1000 | 0.458 | 0.303 | -71.23 | -83.23 |

50 Hz 处两者幅值都接近参考，200～1000 Hz 处 PI 的幅值更接近参考、相位滞后更小。拟合残差约为 PI 0.147～0.170 A、LADRC 0.147～0.178 A，包含采样噪声、非正弦分量及拟合误差。

## 位置环：三环级联与编码器边界

## 第二轮：固定手调 PI、LADRC 调参及保持/扰动测试

### 比较基准与测试方法

先核对实际 PI 增益，再进行 LADRC 调参，最后固定选定参数比较。

板上回读的来源标志为 Bandwidth（0），实际 Id/Iq 增益均为 **Kp=0.897015393、Ki=3550.320800781**。测试将这组增益固定为 **Manual（1）**，每次配置和模型失配后均核对 PI 增益保持原值。

| 项目 | 两组共用设置 |
|---|---|
| 分支固件基点 | `f30bead` |
| 速度 PI | Manual，Kp=0.04、Ki=0.3 |
| 位置 P | Kp=40 |
| 机械 ESO | 100 Hz |
| 电流前馈 | 开启 |
| 标称模型 | Rs=0.282525539 Ω，Ld=Lq=71.382216 μH |
| 其他机械参数 | 沿用板上 Flux、J、B、极对数和标定 |
| 电流指令限幅 / 电压调制上限 | 2 A / 0.98 |
| 加减速度 / 位置规划速度 | 100 rad/s² / 5 rad/s |
| 主机电流保护 | 连续 5 点超过 4 A 或单点超过 5 A 退出 |

模型失配测试将板上 Rs 缩放为 70% / 130%，或将 Ld、Lq 同时缩放为 70% / 130%。其余模型值、PI 手调增益及速度、位置外环参数保持固定，解耦前馈使用缩放后的模型。

本轮使用临时测试固件，在 `/tmp` 副本的 `Motor_ADC.c`、`Plot.c` 加入以下测试入口：

- 快环采样计数：每个 FAST 样本携带计数，展开 16 bit 回绕后按实际采样时刻拟合正弦。
- q 轴电压脉冲：±0.2 V、150 ms，在控制输出后叠加；LADRC 接收的名义电压不包含测试脉冲，用于模拟未知电气输入。叠加后再次执行电压限幅。
- q 轴电流偏置：±0.3 A、150 ms，在外环输出后、电流指令限幅前叠加，产生额外驱动转矩，用于比较外环保持响应。

测试入口将电压/电流偏置分别限制在 ±0.3 V / ±0.5 A；脉冲由快环计数结束，禁能时清除。

### 到位与持续保持精度

PI/LADRC 交替顺序为 PI→LADRC、LADRC→PI、PI→LADRC。在相同机械目标下，执行 +1/4 圈、回起点、−1/4 圈、回起点，每组共 12 次到位。满足原到位判据后再等待 0.8 s，然后采集 2 s；统计编码器单圈角与目标的带符号最短角差，避免大多圈 float 值影响精度。

| 指标 | 手调 PI | LADRC 3000/750 |
|---|---:|---:|
| 到位次数 | 12 | 12 |
| 合并保持误差 RMS ° | 0.01818 | 0.01709 |
| 保持误差绝对值 P99 ° | 0.04666 | 0.04466 |
| 观察到的最大绝对误差 ° | 0.07796 | 0.09325 |
| 单次保持平均偏差的最大绝对值 ° | 0.00211 | 0.00334 |

LADRC 的保持误差 RMS 比 PI 低约 6.0%；PI 的最大瞬时误差和单次平均偏差更小。三次同目标重复的平均偏差极差最大值分别为 PI 0.00279°、LADRC 0.00340°。

### 本轮判断

**固定当前速度 PI、位置 P 后，两种电流内环的三环运行均正常。** LADRC 3000/750 Hz 的位置保持 RMS 和位置电气扰动偏移峰值较小；手调 PI 的最大位置保持误差、标称模型下速度波动及 ±1000 rpm 扰动速度峰值较小。±30% 参数失配下，LADRC 的位置保持 RMS 和速度标准差较小，PI 的电流偏置速度峰值较小。
