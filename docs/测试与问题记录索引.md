## 2. 问题归类判断

同一次实验可以为多个专题提供数据，但问题只在其主要责任文档中展开：

- Flux 辨识数值和重复性归“参数辨识”；
- J/B 固定参数扫频、J/B 数值和有效性归“参数辨识”；PLL 速度信号定义归“无感观测器”；
- Flux 结束后的短路制动归“功率级安全语义”；
- Observer 运行时间归“20 kHz 实时性”，其角度和速度质量归“无感观测器”；
- USB 是否丢帧归“USB Plot 数据链路”，USB 调度是否阻塞 ADC ISR 归“20 kHz 实时性”。

该边界可以避免用“USB 能正常传数”掩盖“USB 唤醒使快环超时”，也避免将
Observer 速度纹波和 Observer CPU 耗时当成同一个问题。
