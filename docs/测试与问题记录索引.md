## 2. 测试数据归档约定

普通功能测试只保留所属专题 Markdown 的测试条件、数值与结论。
Bode、FFT、PSD 等重要频域实验另存 PNG 图和 `.nmixx` 数据，
同一批次及其不同参数工况统一放入 `docs/data/YYYYMMDD_测试主题/`。
正式归档不并存重复的 JSON、CSV、SVG、临时脚本或实验 README。

`.nmixx` 的底层为标准 NumPy NPZ/NPY 格式。数据文件统一采用
`测试名称-YYYY-MM-DD.类型.nmixx`：例如
`Current-D-2026-10-09.bode.nmixx`、`Current-Q-2026-10-10.bode.nmixx`、
`Speed-2026-10-10.bode.nmixx`。类型后缀分别是 `.bode.nmixx`、
`.fft.nmixx`、`.psd.nmixx`，均为小写，不使用固定的 `BODE.NMIXX` 文件名。
Bode 保存实际参考、反馈和控制输出的复数相量用于离线复算；
FFT/PSD 按需要保存复数谱或线性功率谱密度。
同一批次多组 PI 带宽、前馈开关等工况可以按 `[工况, 频点]`
合并到同轴一个 `*.bode.nmixx`，每组独立 Bode PNG 的文件名需包含
轴、带宽、前馈状态等工况信息；FFT/PSD 也按工况命名，防止覆盖。
文件类型不改变 NumPy 读写方法。
扫频仅维护 `tools/current_frf.py` 一个正式工具，支持 `--loop id/iq/speed`；
图片统一为横向 A4 的上下幅相 Bode，固定布局、网格、字号、
坐标轴步距和标题，未测到的截止频率/裕度不得外推。

### FFT / PSD 波形频谱

`tools/fft.py` 是唯一的 FFT/PSD 采集与分析脚本，只使用固件现有
FAST（20 kHz、int16）或 NORMAL（1 kHz、float32）Plot 波形，不注入信号，
也不发送电机 Enable/Run/Stop/Disable。每次采集使用一个 Plot 组；
FAST 最多 8 通道，NORMAL 最多 15 通道，按 Parameter ID 和量化比例还原真实单位。
检查帧序号、数据完整性和接收采样率；丢帧不得拼接成连续均匀采样。

```bash
# 有感电流/相电流频谱；FFT 和 Welch PSD 都绘图
python3 tools/fft.py --port /dev/ttyACM0 --group fast \
  --channels ia ib ic id iq --duration 10 --analysis both \
  --name Current-Noise --out test-data/fft/current

# 速度反馈的低频 FFT（NORMAL）
python3 tools/fft.py --port /dev/ttyACM0 --group normal \
  --channels wm wm_ref --duration 10 --analysis fft \
  --name Speed-Fluctuation --out test-data/fft/speed

# 重新绘图：仅凭已归档频谱，不需要连接固件
python3 tools/fft.py --result \
  test-data/fft/current/Current-Noise-2026-10-10.fft.nmixx \
  --out test-data/fft/replot
```

FFT 采用全采样段去均值、周期 Hann 窗、单边峰值幅度归一化，
保存复数频谱及频率轴；Welch PSD 采用默认 8192 点周期 Hann 窗、
50% 重叠、每段去均值，保存单边线性功率谱密度（物理单位²/Hz）。
两种频谱图均为**横向 A4、180 DPI PNG**，横坐标按采样组固定到奈奎斯特频率。
命名格式为 `测试名称-YYYY-MM-DD.fft.nmixx` / `*.psd.nmixx`，
对应图片为 `*.fft.png` / `*.psd.png`。可通过 `--save-raw` 在本地
额外保存原始时域数据，再以 `--input-raw` 结合原组别与通道顺序离线复算；
正式归档不默认纳入大体积原始波形。

本地原始 FAST 采样留在 `test-data/`（Git 忽略），不默认入库。
历史异常实验可以只留下专题文档结论，旧数据从历史 Git 提交恢复；
删除当前树的文件不等于删除 Git 历史或已经有独立备份。

## 3. 问题归类判断

同一次实验可以为多个专题提供数据，但问题只在其主要责任文档中展开：

- Flux 辨识数值和重复性归“参数辨识”；
- J/B 固定参数扫频、J/B 数值和有效性归“参数辨识”；PLL 速度信号定义归“无感观测器”；
- Flux 结束后的短路制动归“功率级安全语义”；
- Observer 运行时间归“20 kHz 实时性”，其角度和速度质量归“无感观测器”；
- USB 是否丢帧归“USB Plot 数据链路”，USB 调度是否阻塞 ADC ISR 归“20 kHz 实时性”。
- 目标到逐周期参考、轨迹切换及到位验收归“轨迹规划”；Kp/Ki 比较与选值归“控制环调参”。
- 参数保存/恢复语义归“参数存储”；同一次调参试验中的存储验收保留完整试验，用链接关联。
- 电流采样噪声、平均和调制窗口归“电流采样与调制”；同期时序数据作为该试验的验证证据保留。

该边界可以避免用“USB 能正常传数”掩盖“USB 唤醒使快环超时”，也避免将
Observer 速度纹波和 Observer CPU 耗时当成同一个问题。
