## 2. 测试数据格式与归档

所有普通 USB Plot 波形、时域图、Bode、FFT、PSD 均遵循
[测试数据格式与归档规范](测试数据格式与归档规范.md)。
数据和图像以 `.nmixx`（NumPy NPZ）及 PNG 为正式格式，命名统一为
`测试名称-YYYY-MM-DD.类型.nmixx`，正式目录为
`docs/data/YYYYMMDD_测试主题/`，本地采集保留在 Git 忽略的
`test-data/YYYYMMDD_测试主题/`。归档时不加入重复 JSON/CSV/临时脚本。

普通 USB Plot 采集由 `tools/fft.py` 负责，波形的离线查看由
`tools/current_waveform.py` 负责，`tools/current_frf.py` 仅保留带激励的
专用频响工作流。采集不使用 SWD；高速数据连续性必须同时检查 USB 帧与
通过 USB Parameter 可读的固件丢块计数，不能只用 `seq_lost=0` 判定有效。
对于旧固件不能读回丢块计数的记录，质量标记为 unknown，不用于正式
连续频谱或电角度基波拟合。

## 3. 问题归类判断

同一次实验可以为多个专题提供数据，但问题只在其主要责任文档中展开：

- Flux 辨识数值和重复性归“参数辨识”；
- J/B 固定参数扫频、J/B 数值和有效性归“参数辨识”；PLL 速度信号定义归“无感观测器”；
- Flux 结束后的短路制动归“功率级安全语义”；
- Observer 运行时间归“20 kHz 实时性”，其角度和速度质量归“无感观测器”；
- USB 是否丢帧归“USB Plot 数据链路”，USB 调度是否阻塞 ADC ISR 归“20 kHz 实时性”。
- 目标到逐周期参考、轨迹切换及到位验收归“轨迹规划”；Kp/Ki 比较与选值归“控制环调参”。
- 参数保存/恢复语义归“参数存储”；同一次调参试验中的存储验收保留完整试验，用链接关联。
- 电流采样噪声、平均和调制窗口归“电流采样与调制”；同期时序数据作为该试验的验证证据保留。

该边界可以避免用“USB 能正常传数”掩盖“USB 唤醒使快环超时”，也避免将
Observer 速度纹波和 Observer CPU 耗时当成同一个问题。
