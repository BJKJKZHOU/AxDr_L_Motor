## 1. 2026-10-07：转动及 Stop 保持使能时的电流声分析

用户反馈各类模式均能转动，但转动和不转时电流声都大；进一步确认不转指
`Stop` 状态。尚未取得 Disable 后声音是否消失的对照，也没有麦克风声谱或
独立电流探头测量。[ESO 历史保持使能测试（第 14 节）](Mechanical_ESO_有感速度测试记录_20260917.md#eso-hold-20261006)此前已有“无震动，只有电流声”的现场反馈，
现有证据不支持将其直接归因于本次轨迹或分支整理。

### 已有证据

有感模式 Stop 后进入 ENABLED，`Motor_Fast_Run()` 仍返回 FAST_CURRENT，
电流环和 PWM 持续工作。转矩模式参考归零，速度模式继续零速调节，位置模式保持
停止点；后两者的 Iq_ref 不要求为零。此行为符合保持使能的语义，但不能说明较大的噪声合理。

从[轨迹规划测试记录第 1 节](轨迹规划测试记录.md#trajectory-20261007)最终 `samples.csv` 各指定阶段的最后 100 个样本计算总体标准差：

| 工况 | Iq_ref 均值 (A) | Iq_ref 标准差 (A) | Iq 测量标准差 (A) |
| --- | ---: | ---: | ---: |
| 转矩正向稳定参考 | 0.06000 | 0 | 0.13739 |
| 正向转矩 Stop 完成后 | 0 | 0 | 0.16269 |
| 转矩负向稳定参考 | -0.06000 | 0 | 0.12971 |
| 负向转矩 Stop 完成后 | 0 | 0 | 0.14679 |
| 速度模式零速段 | 0.00045 | 0.01425 | 0.13494 |

转矩模式不经过位置/速度 PI，零参考下仍有明显测量波动。因此外环并非这些
波动存在的必要条件，优先排查公共电流采样、电流环与功率级链路。
这里的 Iq 来自板载 ADC 和 Park 变换，包含真实电流纹波及测量误差；
不能把标准差全部等同于真实绕组电流，也不能用 1 kHz 遥测确定可闻声频率。

代码电流换算使用 3.3 V、12 bit、1 mΩ、20 倍增益，约为 **0.04028 A/ADC count**。
这是按固件常量计算的相电流量化步长，实际板卡增益仍须对照硬件；它不是实测噪声 RMS。
当前相电流未做软件低通，直接进入 Clarke/Park 和 PI；电流环设计带宽 2000 Hz，
本轮增益 Kp=0.8970154 V/A、Ki=3550.321 V/(A·s)。单看比例项，0.15 A 的反馈变化
就对应约 0.135 V 的电压修正，说明小电流工况对反馈质量敏感，不能据此单独判定闭环不稳定。

### 当前判断与验证顺序

优先假设是反馈噪声/采样误差与较高电流环增益共同造成电压、电流调节波动；
也需要区分真实 PWM 电流纹波、驱动死区/器件非线性及机械声学共振。
电流带宽 2000 Hz 是设计值，未测频响与稳定裕度，不能直接宣称过高或已振荡。
PWM 为 20 kHz 也不能单独证明听到的声音就是载波：低频电流调节波动仍可能产生可闻声。

建议后续按以下顺序做对照，本节未执行新增带宽扫描，也未改控制代码或持久化参数：

1. 在静止、同一电角位置比较 DISABLED 与 TORQUE/ENABLED、Id_ref=Iq_ref=0，
   采集 20 kHz Ia/Ib、Id/Iq、Ud/Uq 和电流参考，同时记录现场听感。
   DISABLED 时 `Motor_Run.Id/Iq` 可能保持旧值，应以仍在更新的 Ia/Ib 作为采样基线。
2. 保持 PWM 20 kHz、零转矩参考和其他参数不变，仅在 RAM 对照电流带宽
   2000/1000/500 Hz，参数切换在失能状态完成；完成后恢复原值。
   若声音和电压/电流波动随增益明显下降，支持电流环放大反馈扰动的假设，
   但仍需区分测量噪声和真实纹波，不能直接把降带宽当成最终修复。
3. 对照 PWM 关闭时的 ADC 底噪、开启后的放大器稳定时间和采样窗口；必要时用
   示波器核对 ADC 输入、相电流和开关沿。软件量化、模拟噪声、真实电流需要分别测量。
4. 电流层原因明确后再比较速度/位置保持的附加波动。转矩指令斜坡只改变参考，
   对已经恒定为零的参考没有进一步平滑作用，不是本问题的优先处理项。

不宜直接加入很重的电流反馈滤波或仅提高 PWM 频率：前者增加闭环延迟，后者改变
采样与执行时序。本轮快环从周期起点计最大 42.31 μs，而 40 kHz 周期只有 25 μs，
提高频率须重新设计并验证整条时序。

参考：[TI SPRACL1B 第 9.1、11.6 节](https://www.ti.com/lit/an/spracl1b/spracl1b.pdf)
说明电流反馈信噪比差时，高增益闭环可能产生明显可闻声；
[TI SBOA160](https://www.ti.com/document-viewer/lit/html/SBOA160)
解释 PWM 开关瞬态对电流测量放大器输出与稳定时间的影响。后者主要讨论相内采样，
这里只用于说明测量扰动机制，不据此判定本板低边采样的具体硬件故障。

## 2. 2026-10-07：失能底噪与 2000/1000/500 Hz 电流环对照

用户确认进行[第 1 节](#current-noise-20261007)提出的对照。沿用[轨迹规划测试记录第 1 节](轨迹规划测试记录.md#trajectory-20261007)的固件与持久化模型，未修改源码、
重新下载固件或保存参数。通过 SWD 直接读取 Flash，与当前 ELF 导出的镜像逐字节比较；
镜像段间按擦除值 0xff 填充。检查过程未停核，也未调用会借用 RAM 的目标端 CRC 校验。
读回 SystemCoreClock=160 MHz、TIM1 ARR=4000，PWM 全程为 20 kHz。

### 对照条件

测试顺序为 DISABLED → TORQUE/Stop 2000 Hz → 1000 Hz → 500 Hz → 2000 Hz 复测。
各组之间先失能；保持组均为 Id_ref=Iq_ref=0，经 Enable、Run、Stop 确认进入 ENABLED，
MOE=1。每组前 2 s 用于稳定，随后统计约 12 s。结束立即失能，恢复原带宽、模式及目标；
全部持久化 RAM 参数逐项与本组测试前比较一致。未改变速度/位置环参数或电机模型。

FAST 以 20 kHz 采集 Ia、Ib、Id、Iq、Ud、Uq，电流/电压遥测量化分别为 0.001 A/V；
NORMAL 以 1 kHz 采集 Vbus、Wm、Iq_ref、电角度、用户位置。
每组稳态有效 FAST 样本约 240100～240140 个，各保持组 Iq_ref 全程为零。
每组带宽参数写入后读回 PI 增益，2000/1000/500 Hz 的 Kp 分别约
0.897015 / 0.448508 / 0.224254 V/A，Ki 约 3550.321 / 1775.160 / 887.580 V/(A·s)。

DISABLED 下相电流采样继续运行，但 `Motor_Run.Id/Iq` 不更新；因此该组只使用
Ia/Ib 评价底噪，不能把停止更新的 Id/Iq 当成实际 dq 电流。

### 结果

下表均为去掉起始段后的总体标准差；合成电压波动定义为
`sqrt(var(Ud) + var(Uq))`，单位 V。Ud/Uq 是软件输出的电压指令，未用示波器测量端电压。

| 工况 | Ia 标准差 (A) | Ib 标准差 (A) | Ud 标准差 (V) | Uq 标准差 (V) | 合成电压波动 (V) |
| --- | ---: | ---: | ---: | ---: | ---: |
| DISABLED，MOE=0 | 0.15890 | 0.16142 | 0 | 0 | 0 |
| 2000 Hz | 0.18382 | 0.22439 | 0.36728 | 0.12292 | 0.38730 |
| 1000 Hz | 0.17119 | 0.18275 | 0.16024 | 0.05891 | 0.17072 |
| 500 Hz | 0.16136 | 0.16678 | 0.07634 | 0.02933 | 0.08178 |
| 2000 Hz 复测 | 0.18195 | 0.22311 | 0.36493 | 0.12110 | 0.38450 |

相对首次 2000 Hz，1000 Hz 和 500 Hz 的合成电压波动分别下降约 **55.9%** 和
**78.9%**；回到 2000 Hz 后恢复至首次值的 99.3%，表明电气结果可重复。
采样电流波动随带宽降低只部分下降，500 Hz 时已接近失能底噪。
该结果不等同于真实相电流纹波下降同样比例，更不等同于声压下降该比例。

失能组的编码器遥测位置没有变化，Ia/Ib 却分别仍有约 4 个 ADC count 的等效标准差。
按固件 3.3 V、12 bit、1 mΩ、20 倍换算，对应 ADC 输入端约 3.2 mV 标准差。
这是由软件换算关系推回的数值，未使用示波器独立确认；显著大于单个量化台阶，
不能只用“12 bit 量化粗”解释全部波动。
Ia/Ib 的相关系数约 **0.804**，提示两路存在共享扰动，后续应优先核对模拟偏置、
模拟供电/地、ADC 参考和数字开关活动的耦合；相关性本身不能定位具体器件。

保持组稳态位置峰峰值约 0.45～0.62°，电角位置只有小幅变化，未进行转动测试。
各组母线均值约 14.62～14.63 V。采样负载相同，未对遥测开/关引入的干扰单独做对照。

### 结论边界与下一步

已确认的电气证据是：**PWM 关闭时采样链路已有明显波动，提高电流环增益会产生更大的
电压指令波动**。这支持[第 1 节](#current-noise-20261007)的首要假设，且把排查重点进一步移向电流测量链路。
未证明具体模拟器件损坏、ADC 时序错误、PI 不稳定，也未测定真实电流闭环带宽。

用户随后给出的四次使能组听感与测试顺序对应：

| 组次 | 电流带宽 | 现场反馈 |
| --- | ---: | --- |
| 第一次 | 2000 Hz | 声音较大 |
| 第二次 | 1000 Hz | 声音减小 |
| 第三次 | 500 Hz | 声音更小，但仍感觉不是正常的电机声音 |
| 第四次 | 2000 Hz 复测 | 与第一次差不多，声音较大 |

听感与电压指令波动的可逆变化一致，支持电流环增益参与噪声产生的判断；
500 Hz 残余声音仍被用户判为异常，不能把降低带宽记为问题解决。
本轮没有麦克风或电流探头，未得到声压降幅、声音频率或真实绕组电流波形，
也不能排除残余 PWM/驱动非线性及机械共振。
下一步优先检查失能静止时的 ADC 输入偏置/参考/模拟供电与地，区分共享模拟扰动、
ADC 采样及数字开关活动耦合。若需暂时降低电流带宽，应另做运动响应验证；
本次恢复 2000 Hz 原值，不将诊断参数持久化。

### 完整性与结束状态

五组均无保护错误/Trip；编码器错误、CRC、漏采、快环 Deadline 增量均为 0。

即 44.48125 μs（含本次六路 FAST 采集负载）。最终 DISABLED、MOE=0、Ready=1、
Valid=1、Fault=0，原持久化 RAM 参数、控制模式及目标均恢复，未写 NVS。

记录目录：`/tmp/current_noise_20261007/`，主脚本为 `measure.py`、`analyze.py`，
汇总为 `analysis.json`。有效组为 `disabled_baseline/`、`bw2000/`、`bw1000/`、
`bw500/`、`bw2000_repeat/`，各自包含 `result.json`、`fast.raw`、`fast_frames.csv`、

## 3. 2026-10-07：失能电流反馈波动的来源对照

用户确认先定位波动来源。全程 DISABLED、TIM1 MOE=0，未使能电机、未改 C/C++
源码、未烧写固件或 NVS。使用[第 2 节](#current-noise-bw-20261007)同一固件，ELF SHA256 为
`42e7ed18db36b2fbb58f5955c1c8d432df0a3bc5ba3877a89c1cede1cf3c8381`，
预检通过只读 Flash 导出与 ELF 转出的二进制逐字节比较。

### 测量含义与用户反馈

用户指出“几个码波动应该正常”，这个提醒应保留：**不能仅凭 ADC 波动几个码
判定开发板异常，也不能把反馈曲线标准差等同于电机真实电流纹波。**

当前软件按 3.3 V、12 bit、1 mΩ、20 倍增益换算：

- 1 ADC 码 = 0.0402832 A；4 个码标准差约为 0.161 A。
- 理想 1.65 V 中点对应约 ±82.5 A 的测量量程；这是换算量程，不是板卡额定电流。
- 当前 2 A 软件电流上限只占约 50 个码；4 个码标准差相当于该上限的约 8%。
- 本文“约 4 个码”是标准差，不是峰峰值；直接采集组覆盖约 25～28 种码值。
- 失能时的这一波动主要表示测量噪声。使能后 PI 根据带噪反馈调整电压，可能产生
  实际电流扰动；[第 2 节](#current-noise-bw-20261007)带宽与听感对照支持这个机制，但没有独立电流测量，
  不能将 0.16 A 直接当作真实电流纹波。

因此，本轮同时关注采样量程、反馈噪声与电流环增益的匹配，不预设硬件故障。

### 20 kHz 连续采集：采样时间、触发位置、编码器 SPI

通过 SWD 临时修改寄存器。改变采样时间前停止注入转换，恢复 JSQR 后从 ADC2
到 ADC1 重新启动。只修改 A/B 电流通道采样时间；母线通道保持原值。
编码器对照仅屏蔽 TIM1 CC4 中断触发，最后一笔 SPI 完成后不再发起新传输。
所有采集仍在失能状态，未改变编码器持久化配置。

每组先丢弃 1 s，再记录约 8 s，20 kHz FAST 六通道及 1 kHz NORMAL。
FAST 的 Ia/Ib 为 1 mA 量化数据，结合原偏置 Ia=2064、Ib=2044 反推 ADC 原始码；
回算电流与遥测差值均不超过 0.51 mA，远小于半个 ADC 码，确保原始码可唯一恢复。
`adc.raw` 为逐点 uint16 A/B 原始码，`fast.raw` 保留原始六通道 int16 数据。

| 条件 | A/B 标准差（码） | A/B 换算标准差（A） | A/B 相关系数 | Deadline 增量 |
|---|---:|---:|---:|---:|
| 基线，47.5 周期 / CCR5=3665 | 4.032 / 4.080 | 0.1624 / 0.1643 | 0.788 | 0 |
| 采样 92.5 周期 | 4.078 / 4.127 | 0.1643 / 0.1663 | 0.841 | 0 |
| 采样 247.5 周期 | 4.084 / 4.133 | 0.1645 / 0.1665 | 0.848 | 0 |
| 采样 640.5 周期（仅失能诊断） | 4.100 / 4.153 | 0.1652 / 0.1673 | 0.857 | 17 |
| 恢复基线 | 4.100 / 4.150 | 0.1651 / 0.1672 | 0.795 | 0 |
| 触发 CCR5=800 | 4.090 / 4.135 | 0.1647 / 0.1666 | 0.794 | 0 |
| 触发 CCR5=2000 | 4.072 / 4.126 | 0.1640 / 0.1662 | 0.813 | 0 |
| 触发 CCR5=3000 | 4.061 / 4.117 | 0.1636 / 0.1658 | 0.804 | 0 |
| 暂停编码器 SPI 触发 | 3.978 / 4.046 | 0.1602 / 0.1630 | 0.802 | 0 |
| 恢复 SPI / 基线 | 4.048 / 4.095 | 0.1631 / 0.1650 | 0.804 | 0 |

结果：延长采样时间及移动触发点未显著降低主波动；暂停 SPI 后仅小幅下降，
恢复后返回原水平。不能认为当前噪声主要由采样时间太短或编码器传输造成。

640.5 周期组出现 17 次快环跨周期，最大端到端耗时累计达到 8900 CPU 周期
（55.625 μs）。这是人为延长采样后的诊断配置，**不能作为运行参数**。
其余九组各自 Deadline 增量为 0；所有十组连续采集发送丢块、接收序号缺口、
编码器错误、CRC 错误及保护错误均为 0。未清零诊断计数器来掩盖超时。

频谱用 8192 点 Hann 窗、50% 重叠、逐窗去均值的单边 Welch 估计，单位为码²/Hz。
主要表现为宽带波动，未看到一个占主导的窄带尖峰。20 kHz 数据仅分析至 10 kHz，
不能排除更高频模拟噪声混叠到采样带内。

### USB 遥测负载对照

为了避免用 USB 数据评价 USB 自身的影响，改用 SWD 读取 RAM 中同一个 32 bit
字内的 Ia_Raw/Ib_Raw，交替开关 FAST/NORMAL，每组 12 s，约 1400～2100 点。

1. 波动已直接出现在 ADC 原始结果中，电流换算、Clarke/Park、PI 不是其原始产生点；

4. 几个码可以是正常底噪，但当前量程下对应的电流反馈扰动不小。应同时评估量程、

## 4. 注入 ADC 窗口内硬件过采样验证（2026-10-07）

### 目的与配置

验证单个 PWM 采样窗口内连续转换并平均，能否降低[第 3 节](#adc-origin-20261007)的采样波动，以及
零转矩 Stop 下电流 PI 输出的电压扰动。先失能测试，再做短时 Stop 闭环测试。
本轮只临时修改 ADC 寄存器，未修改固件、控制参数或写入 NVS。

依据仓库 RM0440 Rev 9 §21.4.29、§21.4.30、§21.7.5：双 ADC 注入同步模式支持
过采样，两路使用相同倍率和右移设置。停两路注入序列后修改 CFGR2，恢复 JSQR
并重新启动。两路配置分别为：原配置 `0x00`；2 次平均 `0x22`（JOVSE、OVSR=0、
OVSS=1）；4 次平均 `0x46`（JOVSE、OVSR=1、OVSS=2）。结果仍保持原 ADC 码值尺度。

保持 ADC 40 MHz、12 bit、47.5 周期采样时间、TIM1 CCR5=3665、20 kHz 触发不变。
ADC1 首通道 Ia、ADC2 首通道 Ib 同步配置；ADC2 第二通道 Vbus 也会过采样，
并非仅对电流通道生效。单路电流结果的名义转换耗时为 1.5 / 3 / 6 μs，
ADC2 两通道序列为 3 / 6 / 12 μs，均小于 50 μs 触发周期。

两轮均按“原配置 → 2 次平均 → 4 次平均 → 原配置复测”执行。每组先舍弃约 1 s，
再采集约 8 s、16 万个连续 20 kHz 样本；额外读取 100 组运行时诊断字段观察时序。
FAST 采集 Ia、Ib、Id、Iq、Ud、Uq；NORMAL 采集 Vbus、Wm、Iq_ref、Theta_e、Position。
ADC 码由 FAST 电流值按既有换算和偏置反推，并检查量化误差不超过 0.51 mA。
本轮偏置为 Ia=2065、Ib=2045；与[第 3 节](#adc-origin-20261007)跨上电采集的偏置不同，因此采用本轮
首尾基线作比较。本轮开始时 Deadline 与遥测丢块计数均为 0。

### PWM 关闭的采样波动

| 2 次平均 | 2.823 / 2.940 | 0.1137 / 0.1184 | 0.793 |
| 4 次平均 | 1.945 / 2.126 | 0.0784 / 0.0856 | 0.771 |

此检查排除了持续冻结，未用示波器独立验证逐次采样的模拟孔径或数据时龄。

Enable → Run → Stop，确认 ENABLED、MOE=1、Iq_ref=0 后采集；每组结束先失能。
电流 PI 在 Stop 下工作。表中电压指标定义为 √(Var(Ud)+Var(Uq))，去掉直流分量。

| 配置 | Ia / Ib 反馈标准差（A） | Udq 交流 RMS（V） |
|---|---:|---:|
| 原配置 | 0.1883 / 0.2266 | 0.3930 |

## 5. 24 V 空载转速估算与一分钟持续运行（2026-10-07）

### 配置与理论上限

用户已将板上 `PARAM_LIMIT_I_MAX` 从 2 A 调到 10 A，并通过参数保存与重启读回确认
Flash 配置生效；代码的用户默认值仍为 5 A。本轮开始和结束均读得用户限值 10 A，
未改控制增益、运动加减速度或持久化配置。使用有感速度模式，原单次 ADC 转换，
未开启[第 4 节](#adc-oversampling-20261007)测试的硬件过采样，编码器/ADC 触发点保持不变。

当前参数：极对数 p=7、磁链 λ=0.0022811948 Wb、Rs=0.2825255 Ω、
Ld=Lq=71.3822 μH；电流环 2000 Hz、速度环 30 Hz、机械 ESO 100 Hz；
加速度、减速度均为 100 rad/s²。用户速度上限为 12000 rpm。

按当前 SVPWM 电压幅值限制 `Umax=0.95×Vbus/√3`，忽略空载损耗、电阻压降、
电感压降及控制时序误差，不弱磁的电压上限估算为：

`n ≈ (0.95×24/√3)/(7×0.0022811948) × 60/(2π) ≈ 7872 rpm`。

这是理想电气转速上限，不是已经测得的最高转速，也不代表电机机械额定转速。
实际测试母线约 24.55 V，按相同理想模型对应约 8054 rpm；本轮未验证该速度。

### 首轮升速与主机监测中止

0.80 是为当前固定 AB 采样窗口保留裕量的测试边界，不是固件的 0.95 调制度

## 6. 固定两次硬件平均：CubeMX 生成及上板回归（2026-10-07）

## 8. 0.95 调制度采样窗口核验（2026-10-07）

结论：当前固定 A/B 两相、47.5 周期采样、两次硬件平均的配置，不能在 0.95
调制度下保证整个电角周期的有效采样。本次完成板上只读配置核验和实际 SVPWM
算法的离线角度扫描；采样时序前提不通过，因此没有进行 0.95 带电升速试验，
不能将本节称为 0.95 电机运行实测或模拟波形测量。

### 板上核对与验证方法

SWD 读回 ARR=4000、PSC=0、CCR4=2375、CCR5=3800；ADC1/2 CFGR2 均为 0x22，
Ia/Ib 的采样时间字段均为 47.5 周期。对应当前 160 MHz 定时器、40 MHz ADC，
PWM 为 20 kHz，ADC 触发为周期起点后 23.750 μs。
只读 Flash 导出与当前 Release ELF 的二进制一致，ELF SHA256 为
`c229113ac2627a60fa96e8cfca32062f30a830ecdc702e3bc03a25cf73075c18`。

主机直接编译当前 `Algo/Voltage_Mod.c` 和 `Algo/Math.c`，调用 `SVPWM_Calc()`，
按 0.01° 步长扫描电压矢量角度 0～359.99°，每个调制度 36,000 点。
按 `PWM_Update()` 的 float 乘 ARR 后截断规则计算 CCR，再求固定 A/B 两相
共同低侧导通区间。调制度定义为 `m = sqrt(3) * |Uαβ| / Vbus`。

这是每个电压矢量在该 PWM 周期保持不变时的理想窗口检查，未扣除驱动死区、
传播延迟、运放恢复及 ADC 触发同步延迟；未模拟相邻周期占空比的变化。
“完整采样窗口不满足”不等于该角度必然出现某个幅值的电流误差。

### 为什么仅移动触发点不够

在当前设置下，单次采样阶段 47.5/40=1.1875 μs，单次采样加转换
(47.5+12.5)/40=1.5000 μs。两次平均的名义采样区间为：

- 第一次：23.7500～24.9375 μs；
- 第二次：25.2500～26.4375 μs。

从第一次采样开始到第二次采样结束共 2.6875 μs，两次采样保持时刻相隔
1.5000 μs。最后的 SAR 转换可在有效导通窗口之外完成，不计入上述采样跨度。

例如 m=0.95、电压矢量角度 30° 时，实际算法得到 CCR1/2/3=3900/2000/100，
A 相占空比为 97.5%，A/B 共同低侧导通窗口只有 24.375～25.625 μs，宽 1.250 μs。
第一次采样开始早于窗口 0.625 μs，第二次结束晚于窗口 0.8125 μs。
即使仅要求两个采样保持时刻都处于理想窗口，1.500 μs 的间隔也大于窗口宽度，
因此该角度不可能只通过平移触发时刻解决。

对称 SVPWM 最不利固定 A/B 窗口的连续值为 `25 * (1-m) μs`：

| 调制度 | 最窄理想窗口（连续值） | 当前固定触发完整采样窗口检查 |
|---|---:|---|
| 0.80 | 5.0000 μs | 扫描未发现越界 |
| 0.85 | 3.7500 μs | 扫描未发现越界；仍需模拟建立时间余量 |
| 0.885 | 2.8750 μs | 名义尾部余量为零，不能作为工程可用上限 |
| 0.90 | 2.5000 μs | 扫描约 22.88% 角度越界 |
| 0.95 | 1.2500 μs | 扫描约 47.19% 角度越界 |

扫描使用整数 CCR，个别最小窗口与表中连续值有一个计数附近的量化差异。
0.95 下 16,988/36,000 个角度不满足当前固定触发的完整采样区间条件；
其中 15,956 个角度的窗口本身小于 2.6875 μs，即使允许逐角度移动触发点仍放不下。
这些比例描述离线角度覆盖，不是实测坏样本率或故障概率。

在忽略全部建立时间的连续模型下，当前固定触发的完整孔径上限约为 0.885；
优化固定触发位置最多提高至 0.8925。这两个数都是零裕量数学边界，不能当作
经过验证的运行限值。固件 `VOLT_MOD_MAX=0.95` 只是电压矢量限幅，未自动保证
固定 A/B 电流采样在该范围内始终有效。

### 本轮状态与后续方向

全过程保持 DISABLED、MOE=0；母线读数约 24.62～24.63 V，Ready=Valid=1，
Fault/Error/Trip=0。持久化参数前后相同，用户电流限值保持 10 A；没有修改
固件、IOC、控制参数或 NVS。上一节 6000 rpm 一分钟实测仍是当前运行验证边界，
其全程最大监测调制度为 0.8232，不能外推到 0.95。

若保留两次平均并希望覆盖 0.95，应进一步设计按占空比选择有效的两相采样、
接入并校准 C 相电流通道，同时核对相选择、PWM 生效和 ADC 触发的一致性。

## 10. 四次平均配合短采样周期对照（2026-10-08）

**结论：4×24.5 cycles 明显降低本次静止电流反馈及闭环电压波动，4×12.5 cycles 收益很小。**
4×24.5 同时出现 Ib 零点偏移，且采样跨度不能覆盖当前 0.88 上限下的最窄理想窗口，
因此本轮只记录对照结果，结束恢复 2×47.5，不将候选配置写入固件。
同日高速解耦及 6fe 谐波另见[电流环解耦测试记录](电流环解耦测试记录.md)；
本轮没有新增高速运行，也未处理该谐波。

### 条件与配置

沿用同一开发板、电机和下载器。分支 `feat/current-frf-injection`，提交
`aa0425923db2be0a4149828f59a2340b06deff04`，ELF SHA256 为
`30bfa9933369c6af7a987a5570883b9c3f61216342b4803798afe9d13e5f2352`。
母线约 24.6 V，PWM/电流环 20 kHz，ADC 12 bit、40 MHz。
电流环保持 Bandwidth 模式、2000 Hz，d/q Kp=0.8970154、Ki=3550.3208；
解耦前馈关闭、信号注入关闭。转矩模式零参考，临时电流指令上限 2 A。

仅在 DISABLED、MOE=0 时暂停注入转换，通过 SWD 临时修改 ADC1/2 过采样倍率、
右移位数及 Ia/Ib 通道采样周期，再恢复注入触发；不暂停 CPU，不改源码或下载固件。
两次平均右移 1 位，四次平均右移 2 位，保持相同的 12 bit 电流换算尺度。
Vbus 通道仍为 47.5 cycles；ADC2 注入组倍率变化也作用于该通道。
CCR4=2375、CCR5=3800、ARR=4000，保持触发位置与编码器时序不变。

|---|---|---:|---:|---:|
| A | 2×47.5 cycles | 1.1875 μs | 3.00 μs | 基准 |

### 方法与统计口径

先失能、后零转矩使能，两种状态分别按 **A → C → B → A 复测**。
使能段执行 Enable → Run → Stop，最终保持 ENABLED、电流环工作，Iq_ref=0。
每组先等待约 1 s，再采集约 10 s，有效 FAST 样本数为 200,020～200,060。

- FAST：20 kHz，`Ia、Ib、Id、Iq、Ud、Uq`，小端 int16，各通道比例 0.001。
- NORMAL：1 kHz，`Vbus、Wm、Iq_ref、Theta_e、Position`。
- ADC 码值由 Ia/Ib、保留的零点及 `0.040283203125 A/码` 重构，检查与遥测量化相容。
  此处“码”为硬件平均并右移后的输出码，不是每次子转换的原始值。
- 噪声使用总体标准差，不是峰峰值。失能 Id/Iq 保持旧值，不参与失能噪声结论。
- 电压指标为 `sqrt(var(Ud)+var(Uq))`，剔除直流分量；前馈关闭时代表闭环 dq 电压命令扰动。
  降幅以两次 A 的指标均值为基准，不据此推算实际端电压或声压。

主机监测采样相电流（含重构 Ic）2.5 A、母线 22～28 V、速度绝对值 8 rad/s、
零 Iq 参考及遥测中断 300 ms，并检查保护状态、编码器状态、序号和固件计数。
失能 C 的 Ib 均值变化超过脚本预设的 2 码检查门槛，第一段完成四组失能采集后暂停，
自动恢复配置；检查确认偏移约 0.089 A 后，保留原零点继续四组使能对照。
这是主机检查暂停，没有发生固件保护故障；原始失能报告保留此次退出原因。

### 分析与使用边界

相同 PI 下，C 同时降低失能采样噪声与使能电压扰动，支持反馈噪声参与闭环电压波动的判断。
本轮未测声压，不能宣称声音降低 21%；也未测闭环频响或稳定裕度。
B 表明增加平均次数同时缩短单次采样，未必获得预期的降噪收益。
噪声相关性、模拟建立过程及采样时刻均可能影响结果，本轮不足以区分具体原因。

4×24.5 的转换时间更长，不能只根据静止噪声较小就直接替换当前配置。
