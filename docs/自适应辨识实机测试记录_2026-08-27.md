## 8. 基于 `222646` 原始点的后续推导

### 8.1 曲率重复性

将反转数据转换到正速度、正反电势幅值坐标后，四轮 residual 呈相同符号：

```text

P1: 负

P3: 正
```

P0～P2 的拟合斜率中值为 `4.368 mWb`，P1～P3 的拟合斜率中值为
`6.304 mWb`，后者高约 `44.3%`。这说明低 R2 是可重复的系统曲率，不是遥测丢帧或单次噪声。

### 8.2 两轴磁链与 I/F 负载角

在 I/F 同步旋转坐标系下，稳态磁链分量按以下方式估算：

```text
Psi_d = (Uq - Rs*Iq) / We - Ld*Id
Psi_q = -(Ud - Rs*Id) / We - Lq*Iq
Flux  = sqrt(Psi_d^2 + Psi_q^2)
```

使用 `222646` 实际 Apply 的 run 5 参数：

```text
Rs      = 6.369302273 ohm
Ld = Lq = 1647.3948 uH
```

并使用每轮 q 轴拟合的 Voff 修正 `Psi_d` 后，16 个点的推导范围为：

| 推导量 | 结果 |
|---|---:|
| `abs(Psi_q)` | 约 `13.9～15.2 mWb` |
| `abs(Flux)` | `15.106～16.553 mWb` |
| Flux 中值 | `15.839 mWb` |
| I/F 负载角绝对值 | `64.5°～71.0°` |
| 负载角中值 | `68.9°` |

因此旧 q 轴回归得到的约 `5.77 mWb` 主要是磁链在 I/F d 轴上的投影，不是永磁体磁链模长。旧结果不应直接写入 `Motor_Para.Flux`。

### 8.3 电压矢量利用率

按 `Vbus=14.53 V`、`VOLT_MOD_MAX=0.95` 计算：

```text
U_available ~= Vbus / sqrt(3) * 0.95 = 7.97 V
U_hard      ~= 0.80 * U_available    = 6.38 V
```

## 10. ACCEL 失败的后续分析

本节是根据代码和原始失败时刻进行的推导。

`233411` run 5 实际应用参数为：

```text
Rs = 6.157378 ohm
Ls = 1496.0931 uH
```

由预辨识公式：

```text
We_base = 0.02 * Rs / Ls ~= 82.3 rad/s
Acc     = We_base / 6 s   ~= 13.7 rad/s^2
```

从 `ACCEL` 开始到失败约 `0.37 s`，此时指令速度约为 `5.1 rad/s`。即使按
`15.8 mWb` 磁链估算，反电势也只有约 `0.08 V`，远小于约 `6.38 V` 的
80% hard voltage。

同时相电流峰值只有 `0.685 A`，远低于固件 `2.0 A` 和主机 `2.2 A` 限制。
因此该失败不是稳态反电势越界或过流，而是对齐切换/电流环加速过程中某个
20 kHz 周期的 `Ud/Uq` 瞬时指令超过 80% 门限。当前代码没有延时或持续时间判断，单个周期即可进入 `FAILED`。

`235052` 和 `235129` 能够进入 MEASURE，但仍在形成第一个点前失败，说明该门限并非
每次都在固定的 ALIGN/ACCEL 切换瞬间触发；它也可能被加速或测量过程中的单次电压峰值触发。
失败阶段随运行变化、而电流始终远低于限制，进一步支持“瞬时电压质量门被当作
无延迟硬失败条件”的判断。

## 16. 更新后的结论与下一步

### 16.1 已通过或已确认

- 瞬时电压样本不再直接阻断 Flux，使用测量平均电压约束搜索后，正反转四轮两轴磁链辨识可重复完成；
- 两轮完整测试的磁链中值分别为 `14.9750 mWb` 和 `14.9202 mWb`，跨轮差约 `0.367%`；
- 单轮内最大偏差为 `1.507%/1.884%`，正反向差为 `1.648%/3.001%`，两轴 Flux 重复性已经明显好于旧 q 轴线性拟合指标；
- `002320` 的诊断 warning 没有阻断有效结果，Flux 已成功写入 RAM；
- 整条脚本链路首次进入最终无感运行，通信丢帧仍为 `0/0`。

### 16.2 仍需处理

- 最终无感运行在电流模长 `2.0267 A` 时停止，尚未证明能够稳定达到 `200 electrical rad/s`；
- 下一轮需要保存无感启动阶段的 `We_ref/We_est/Id/Iq/Ud/Uq/PLL or observer state`，否则无法定位过流发生在哪个控制阶段；
- 峰值电压利用率在完整 Flux 运行中为 `100.23%~100.82%`。它现在作为 warning 是合理的，但应核对其分母、采样时序和调制限幅后的实际电压定义，避免把命令峰值与可用平均电压混用；
- `000030/000035/002144` 偶发停在 `PROBE_MEASURE`，仍缺少明确失败原因；
- Rs/Ls 仍下发 run 5。`002320` 恰好把偏离中值最大的 Ls (`1676.5672 uH`) 用于后续 Flux，继续支持改为 median/robust estimate 的建议。

### 16.3 下一轮实机测试优先级

1. 不再重复相同的完整辨识作为第一步；先给最终无感运行增加低频阶段诊断，记录过流前的速度、dq 电流、电压和观测器状态；
2. 以更低 `target-we` 或受控的电流/速度斜坡验证无感接管点，再逐步升到 `200 rad/s`；
3. 将 Rs/Ls 下发值改为五轮 median 或明确的 robust estimate 后，比较无感启动峰值是否下降；
4. 保留 Flux 的重复性和方向一致性硬门，继续把点偏差与峰值电压利用率作为诊断 warning，不通过简单降低旧 R² 门限来掩盖模型差异。
