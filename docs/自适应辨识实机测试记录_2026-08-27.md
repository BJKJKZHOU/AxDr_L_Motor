## 8. 基于 `222646` 原始点的后续推导

### 8.1 曲率重复性

将反转数据转换到正速度、正反电势幅值坐标后，四轮 residual 呈相同符号：

```text

P1: 负

```

P0～P2 的拟合斜率中值为 `4.368 mWb`，P1～P3 的拟合斜率中值为
`6.304 mWb`，后者高约 `44.3%`。这说明低 R2 是可重复的系统曲率，不是遥测丢帧或单次噪声。

### 8.2 两轴磁链与 I/F 负载角

在 I/F 同步旋转坐标系下，稳态磁链分量按以下方式估算：

```text
Psi_d = (Uq - Rs*Iq) / We - Ld*Id
Psi_q = -(Ud - Rs*Id) / We - Lq*Iq
Flux  = sqrt(Psi_d^2 + Psi_q^2)
```

使用 `222646` 实际 Apply 的 run 5 参数：

```text
Rs      = 6.369302273 ohm
Ld = Lq = 1647.3948 uH
```

并使用每轮 q 轴拟合的 Voff 修正 `Psi_d` 后，16 个点的推导范围为：

| 推导量 | 结果 |
|---|---:|
| `abs(Psi_q)` | 约 `13.9～15.2 mWb` |
| `abs(Flux)` | `15.106～16.553 mWb` |
| Flux 中值 | `15.839 mWb` |
| I/F 负载角绝对值 | `64.5°～71.0°` |
| 负载角中值 | `68.9°` |

因此旧 q 轴回归得到的约 `5.77 mWb` 主要是磁链在 I/F d 轴上的投影，不是永磁体磁链模长。旧结果不应直接写入 `Motor_Para.Flux`。

### 8.3 电压矢量利用率

按 `Vbus=14.53 V`、`VOLT_MOD_MAX=0.95` 计算：

```text
U_available ~= Vbus / sqrt(3) * 0.95 = 7.97 V
U_hard      ~= 0.80 * U_available    = 6.38 V
```

## 10. ACCEL 失败的后续分析

本节是根据代码和原始失败时刻进行的推导。

`233411` run 5 实际应用参数为：

```text
Rs = 6.157378 ohm
Ls = 1496.0931 uH
```

由预辨识公式：

```text
We_base = 0.02 * Rs / Ls ~= 82.3 rad/s
Acc     = We_base / 6 s   ~= 13.7 rad/s^2
```

从 `ACCEL` 开始到失败约 `0.37 s`，此时指令速度约为 `5.1 rad/s`。即使按
`15.8 mWb` 磁链估算，反电势也只有约 `0.08 V`，远小于约 `6.38 V` 的
80% hard voltage。

同时相电流峰值只有 `0.685 A`，远低于固件 `2.0 A` 和主机 `2.2 A` 限制。
因此该失败不是稳态反电势越界或过流，而是对齐切换/电流环加速过程中某个
20 kHz 周期的 `Ud/Uq` 瞬时指令超过 80% 门限。当前代码没有延时或持续时间判断，单个周期即可进入 `FAILED`。

`235052` 和 `235129` 能够进入 MEASURE，但仍在形成第一个点前失败，说明该门限并非
每次都在固定的 ALIGN/ACCEL 切换瞬间触发；它也可能被加速或测量过程中的单次电压峰值触发。
失败阶段随运行变化、而电流始终远低于限制，进一步支持“瞬时电压质量门被当作
无延迟硬失败条件”的判断。

## 18. Observer Shadow 结果分析与更新结论

> 本节对应第 17 节的早期扫频结果。2026-08-29 10:31 的新一轮测试已经修正“`We_obs_f` 存在约 `16.6~21.8 rad/s` 稳态负偏差”的阶段性判断，详见第 19、20 节。旧结果仍保留，用于追踪两轮之间尚未完全解释的可重复性差异。

### 18.1 Flux 条件不是稳态主要阻塞项

四个带宽点的 Flux ratio 均值为 `0.9916~0.9932`，标准差为 `0.0387~0.0479`。在 `5 s` shadow 统计窗口内，FLUX 拒绝比例只有 `0~0.5%`。磁链模长总体稳定在参考值附近，不能解释接管始终失败。

### 18.2 增大 PLL 带宽能改善 PLL error，但不能解决速度质量

PLL 带宽从 `10 Hz` 增至 `50 Hz` 后：

```text
PLL RMS reject tendency: 0.39757 -> 0.06158 rad
PLL reject polls:        76.0%   -> 15.8%
```

说明提高带宽确实让 PLL 相位误差更快收敛。需要注意，固件质量门检查瞬时 `|PLL_Err|`，而不是 RMS；即使 `50 Hz` 的 RMS 已低于 `0.08`，其 peak 仍为 `0.27657 rad`，所以仍有 `15.8%` 的轮询被 PLL 条件拒绝。

与此同时，WE 拒绝比例由 `47.1%` 上升到 `74.2%`。`We_obs_f` 的标准差始终约为 `28~33 rad/s`，均值也只达到 `98~103 rad/s`，没有跟随 I/F 的 `120 rad/s`。PLL 带宽越高，速度估计噪声和 WE 拒绝并未改善。

### 18.3 单纯 PLL 带宽扫频不能形成可接管窗口

`30 Hz` 的平均速度误差最小，为 `-16.567 rad/s`；`50 Hz` 的 PLL error、poll pass 和最长连续稳定时间最好。但最佳 `Stable max` 仍只有：

```text
26.9 ms @ 50 Hz
```

只达到接管要求 `200 ms` 的约 `13.5%`。四个带宽点都没有形成接近要求的连续稳定区间，因此不能通过选择 10/20/30/50 Hz 中的某一个值直接解决接管问题，也不应只降低或绕过 `200 ms` 条件。

### 18.4 当前主要问题已经定位到 We 估计

本轮把此前未知的三个接管条件明确区分开：

- FLUX 在 steady shadow 中基本通过；
- PLL 可通过提高带宽显著改善；
- WE 在全部带宽下均存在约 `16.6~21.8 rad/s` 的负均值误差和很大的波动，成为主要阻塞项。

下一步分析应优先检查 `We_obs_f` 的来源，而不是继续扩大 PLL 带宽范围。重点包括：PLL 原始速度与 20 ms 低通后的差异、速度估计中的周期性波动频率、I/F 实际同步速度是否稳定，以及电压模型中 `Rs*I` 占比较大时的误差敏感性。

### 18.5 电流与测试安全性

本轮 observer 始终处于 shadow，不存在真正的角度接管或速度环接管。全程峰值电流为 `1.387 A`，低于 `2.000 A` 限制，且通信无丢帧，说明该诊断方法能够在不让不稳定 observer 控制电机的前提下重复采集数据。

峰值仍明显高于稳态自适应 I/F 电流量级，但现有汇总没有记录峰值发生在 ALIGN、I/F 加速还是各轮重启瞬间，不能据此归因。后续脚本如增加原始输出，应同时保存带时间戳的 `Id/Iq`，定位该峰值。

### 18.6 下一步建议

1. 给 `observer_shadow_run.py` 增加 JSON 或 CSV 输出，至少保存每个诊断轮询的原始字段和测试 Git SHA；
2. 在当前 `120 rad/s`、`50 Hz` 条件下保存时间序列，分析 `We_obs_f` 的主波动频率和与 `PLL_Err/Theta_Err` 的相关性；
3. 不进行 observer takeover，先在 shadow 模式扫描 I/F 速度，确认提高反电势后 WE 均值误差和标准差是否下降；
4. 在已有数据支持前，不降低 `WE_ERR_MAX=5 rad/s`、`PLL_ERR_MAX=0.08` 或连续稳定 `200 ms` 门限。

## 20. 新一轮 Observer Shadow 分析与更新结论

### 20.1 早期测试中的速度均值偏差没有在本轮复现

第 17 节早期扫频中，`We_obs_f` 均值仅为 `98.165~103.433 rad/s`，标准差为 `28.401~33.026 rad/s`；本轮去除启动段后，四个带宽的均值均为 `119.867~120.002 rad/s`，标准差降至 `1.152~3.749 rad/s`。

而且本轮两个相对独立的速度量都成立：

```text
We_flux_f mean ~= 120 rad/s
We_obs_f  mean ~= 120 rad/s
```

因此不能继续把“observer 存在固定速度比例或单位误差”作为当前结论。第 18.4 节的判断只描述早期那轮数据，已经被本轮修正。两轮之间改善幅度很大，而 JSON 又没有记录精确固件 SHA，后续仍需在相同镜像和相同机械条件下重复本轮测试，确认改善是否稳定可复现。

### 20.2 当前瓶颈是周期纹波导致判据无法连续保持

本轮 FLUX reject 为 `0%`，速度与磁链模长的平均值均正确，但最佳 `Stable max` 仍只有 `119.7 ms`。不同带宽表现出明确的取舍：

- 10 Hz 将 `We_obs_f` 标准差压到约 `1.15 rad/s`，WE 几乎全部通过，但 PLL reject 仍约 `35%`；
- 50 Hz 将 PLL reject 降至约 `6%`，却把 steady `We_obs_f` 标准差提高到约 `3.75 rad/s`，WE reject 增至约 `22%`；
- 20/30 Hz 位于两者之间，但三项判据仍不能连续同时通过 `200 ms`。

这说明提高 PLL 带宽会减少相位滞后和瞬时 PLL error，同时也会把上游磁链角度纹波更多地传递到速度估计。接管失败不再是均值错误，而是周期扰动反复切断稳定计时器。

### 20.3 约 6~6.6 Hz 的日志波动很可能是二倍电频率混叠

去除前 `0.5 s` 后，对 `We_flux_f`、`We_obs_f`、`PLL_Err` 和角度误差时间序列分析，主波动频率集中在约 `6.0~6.6 Hz`。JSON 中实际主机诊断采样率约为 `44.2~44.8 Hz`，而本轮电频率为：

```text
fe = We / (2*pi) = 120 / (2*pi) = 19.10 Hz
2*fe = 38.20 Hz
```

二倍电频率在约 `44 Hz` 主机轮询下会混叠为：

```text
f_alias = |fs - 2*fe| ~= 6.0~6.6 Hz
```

该数值与日志主峰一致，因此目前最强的工作假设是：真实扰动位于约 `38.2 Hz`，即二倍电频率，而不是控制系统本身产生了一个独立的 6 Hz 低频振荡。由于诊断采样率低于 Nyquist 要求，这仍是基于频率对应关系的推断，不能只凭当前低频日志最终定性。

### 20.4 故障源更可能位于 PLL 上游的磁链矢量

> 第 21、22 节的纯电压诊断进一步把首要嫌疑收敛到 A 相电流采样比例/模拟链。功率级相间不对称仍未被完全排除，但其优先级已经下降。

`Theta flux-IF` 与 `Theta PLL-IF` 的均值高度一致，且 `We_flux_f`、`We_obs_f`、PLL error 和角度误差表现出相同的主频。由此更像是磁链矢量角度本身带有电角周期纹波，PLL 带宽只决定对该纹波的滤除或跟随程度。

优先排查方向为：

1. αβ 电流采样增益或 offset 不一致造成的电流椭圆；
2. 三相电压、死区补偿或逆变器压降不对称；
3. 实际 `Ld/Lq` 差异或凸极性，而当前 observer 使用 `Ld=Lq`；
4. 该高 Rs、低速工况下，`U-Rs*I` 对 Rs 和电流误差过于敏感；
5. 电机或负载引入的电角周期转矩扰动。

### 20.5 下一步测试建议

1. 保持 shadow、`We=120 rad/s` 和现有判据不变，使用当前新增的 αβ/flux diagnostics 重复测试，先确认约 `2*fe` 纹波是否可复现；
2. 使用与 PWM/控制周期相干的更高采样率记录 `Ialpha/Ibeta`、`Ualpha/Ubeta` 和 flux alpha/beta，直接判断轨迹是圆、椭圆还是带 offset；
3. 在多个 `We` 下比较纹波频率是否始终跟随 `2*fe`，以排除固定机械频率或主机采样伪影；
4. 在确认纹波来源前，不降低 `WE_ERR_MAX`、`PLL_ERR_MAX` 和连续稳定 `200 ms` 门限，也不进入 observer takeover；
5. 后续 JSON 增加工具 Git SHA、固件镜像版本和板端构建标识，避免再次出现跨版本测试无法精确对应的问题。

## 22. 电流采样比例假设与故障优先级更新

> 本节记录的是 21:24 纯电压测试之后形成的阶段性 gain 假设。22:31 完成的 ADC injected Rank 交换实验表明，串行采样时差比静态 gain 更能解释当前负序；本节的故障优先级已由第 23、24 节更新。

### 22.1 当前最完整的解释链

当前数据可以形成以下闭环解释：

```text
A 相电流测量 gain 约比 B/C 低 9%
                 |
                 v
真实接近平衡的三相电流被测成 Ia 偏小
                 |
                 v
Clarke 变换得到假的负序/椭圆和 2fe 角纹波
                 |
                 v
Current PI 产生负序 Ucmd，使测得的 Id/Iq 接近平衡
                 |
                 v
Flux Observer 把带补偿分量的 Ucmd 当作端电压
                 |
                 v
Psi 负序 -> flux angle 2fe -> PLL_err/We_obs 2fe
```

当前实现对三个电流通道共用同一个换算系数：

```c
#define CUR_RAW_TO_A (ADC_VREF_V / ADC_FULL_SCALE / CUR_SHUNT_OHM / CUR_AMP_GAIN)

ADC.Ia_A = (...) * CUR_RAW_TO_A;
ADC.Ib_A = (...) * CUR_RAW_TO_A;
ADC.Ic_A = (...) * CUR_RAW_TO_A;
```

Current Loop 和 Sensorless 的 Clarke 变换均直接使用：

```c
Ialpha = Ia;
Ibeta  = (Ia + 2 * Ib) / sqrt(3);
```

因此当前软件没有单通道 gain 校准来吸收 shunt、放大器、ADC 通道或前端阻容网络的比例差异。若 A 相通道确实偏低，该误差会直接进入电流环和 Flux Observer。

### 22.2 数量级一致，但尚不是最终硬件定论

在“真实三相电流理想平衡、只有 A 相测量 gain 为 `r=0.91272`、B/C 相同”的简化模型下，上述 Clarke 变换会产生约 `5.27%` 的负序；实测为 `6.33%`。方向和数量级吻合，支持单相 gain mismatch 能解释主要部分，但仍有约 `1.06` 个百分点未被该简化模型解释。

此外，`Ucmd` 是 SVPWM 前的软件指令，不是直接测得的电机端相电压。纯正序 `Ucmd` 不能完全排除以下因素：

- 实际桥臂压降、死区或栅极驱动不一致；
- PWM 状态相关的 ADC 采样误差；
- B/C 通道也存在较小且不同的比例误差；
- 电机相阻抗或机械负载不对称。

因此当前结论应表述为：**A 相电流采样 gain/模拟链约低 9% 是最强且能统一解释现象的假设，但需要独立静态或交叉通道标定确认。** 暂不应直接把 `0.912` 写成固件补偿常数。

### 22.3 故障排查优先级

根据两轮独立数据，排查优先级更新为：

1. A 相电流采样 gain、shunt 和模拟放大链；
2. A/B/C ADC 通道比例、参考和软件原始值到安培的转换；
3. PWM 状态相关采样窗口、采样保持及开关噪声；
4. 功率级桥臂、死区和端电压相间不对称；
5. 电机本体相阻抗或磁路不对称。

在完成电流通道验证前，不优先修改 deadtime compensation，也不通过调低 observer 接管门限掩盖 `2*fe` 纹波。

### 22.4 下一步验证建议

1. 零电流时分别统计三相 ADC offset 的均值、标准差和温漂，先排除 offset 问题；
2. 使用同一个已知直流电流依次通过 A/B/C 测量链，直接获得各通道 gain 比；
3. 条件允许时交换 A/B ADC 输入或模拟前端，仅改变测量通道而不改变功率相，观察约 `9%` 偏差是否随通道移动；
4. 在 voltage diagnostic 下改变电角速度、电压幅值和旋转方向，检查 `Ia/mean(Ib,Ic)` 是否始终约为 `0.913`；
5. 如果独立标定确认通道比例误差，再增加明确的每相校准系数，并重新执行 voltage sequence、Current Loop sequence 和 observer shadow 三组回归测试。

### 23.1 测试目的与唯一变量

## 24. ADC 串行采样时差分析与优先级更新

> 本节根据纯电压 Rank 交换实验确认 ADC 串行采样时差是重要来源。随后 22:36 的 closed-loop 回归表明，闭环 `Ucmd` 负序并未随 Rank 交换下降，因此采样时差不是唯一来源；补充结论见第 25 节。

### 24.1 Rank 交换对负序有直接且显著的影响

同为 `gain=1.00/1.00` 时，仅交换 Rank1/Rank3：

```text
I neg/pos: 5.06787% -> 2.58888%
ratio:     0.0258888 / 0.0506787 = 0.51084
reduction: 48.92%
```

物理相、电机、功率级、SVPWM、电压目标和采样总跨度均未改变，而负序下降接近一半。这比静态 RMS 比例或闭合拟合提供了更强的干预证据：当前负序对 ADC 转换时间顺序高度敏感，ADC1 三相 injected 串行采样时差应升级为首要嫌疑。

作为对照，在原 Rank 顺序下把 `Ia gain` 从 `1.00` 调到 `1.10`：

```text
I neg/pos: 5.06787% -> 4.13747%
reduction: 18.36%
```

gain 调整确实改变了结果，说明静态通道比例仍可能叠加存在；但其改善明显小于 Rank 交换，而且不能解释“物理相不变、只改变采样时刻就改变负序”的现象。因此第 22 节的 A 相 gain 假设应降为次要因素，不能再作为首要根因。

### 24.2 约 3 us 的三相时间跨度能够破坏瞬时闭合

当前 ADC 配置为：

```text
SYSCLK/PCLK2 = 160 MHz
ADC clock = PCLK2 / 4 = 40 MHz
sampling = 47.5 ADC cycles
12-bit conversion ~= 12.5 ADC cycles
one rank ~= 60 / 40 MHz = 1.5 us
Rank1 -> Rank3 span ~= 3.0 us
```

因此原顺序实际组合近似为：

```text
Ic(t0)
Ib(t0 + 1.5 us)
Ia(t0 + 3.0 us)
```

交换后则变为：

```text
Ia(t0)
Ib(t0 + 1.5 us)
Ic(t0 + 3.0 us)
```

即使真实同步三相电流在同一时刻满足：

```text
Ia(t) + Ib(t) + Ic(t) = 0
```

软件实际相加的却是三个不同时刻的值：

```text
Ia(t0) + Ib(t0 + 1.5 us) + Ic(t0 + 3.0 us) != 0
```

交换首尾 Rank 只改变哪一相领先或滞后，没有消除约 `3 us` 总跨度，所以 closure relative 仍保持 `30%+` 与该解释一致。负序下降而 closure 不下降并不矛盾：前者对相位误差的方向和分布敏感，后者主要暴露三相并非同一时刻。

### 24.3 与 Observer 2fe 的关系

ADC 时间错位使软件构造的 `Ialpha/Ibeta` 产生与电角度相关的椭圆和假负序；Current PI 再把该测量误差转换为 `Ucmd` 补偿分量，Flux Observer 使用该电流和电压后产生 `Psi` 负序，最终表现为 flux angle、PLL error 和速度估计中的 `2*fe` 纹波。

更新后的主要解释链为：

```text
ADC1 三相 injected 串行采样，约 1.5 us/rank
                  |
                  v
三个物理相被赋予不同采样时刻，首尾相差约 3 us
                  |
                  v
三相闭合误差 + Clarke 假负序/椭圆
                  |
                  v
Current PI 补偿 -> Ucmd 负序
                  |
                  v
Psi 负序 -> flux angle/PLL/We 的 2fe 纹波
```

### 24.4 更新后的故障排查优先级

1. ADC1 injected 三相串行采样时差、Rank 顺序和控制周期的采样时刻所有权；
2. PWM 状态相关的采样窗口、开关瞬态和采样保持误差；
3. A/B/C 静态 gain、shunt 和模拟放大链；
4. 功率级桥臂、死区和实际端电压相间不对称；
5. 电机本体相阻抗或磁路不对称。

现在不应优先固化 `Ia gain=1.10`，也不应先修改 deadtime compensation 或降低 observer 接管门限。

### 24.5 结论边界与下一步验证

当前只有一次原顺序与一次交换顺序的 `gain=1/1` 对照。虽然它是强干预证据，但仍需排除重刷固件、温度、转子初始位置和运行间波动造成的偶然差异。

下一步建议：

1. 在同一固件上重复新顺序至少三轮，确认约 `2.59%` 负序的重复性；
2. 恢复原顺序并重复，验证负序能否回到约 `5.07%`，形成 A-B-A 回归；
3. 在正反转和多个 `We` 下比较负序幅值，检查其是否按采样延迟与电角速度变化；
4. 测试其他 Rank 排列，观察负序相位和幅值是否随首尾相位移动；
5. 比较缩短 ADC sampling cycles、双 ADC 同时采两相后重构第三相，或按已知采样时刻做时间对齐的方案；
6. 修正采样同步后，再以 `gain=1/1` 重跑 voltage sequence、Current Loop sequence 和 observer shadow，判断 `2*fe` 是否同步消失。

### 25.5 Rank 时差不能单独解释闭环 Ucmd 负序

若闭环 `Ucmd` 负序只是在补偿 Rank 时差造成的错误电流，那么纯电压电流负序下降约一半后，闭环所需的 `Ucmd` 负序也应呈明显下降趋势。但实测为：

```text
Ucmd neg/pos: 2.05485% -> 2.28059%
```

它没有下降，反而小幅增加约 `11%`。因此“全部 `Ucmd/Psi/PLL` 负序都由 Rank 时差单独造成”的模型已被本轮否定。系统中至少还存在一种在 Rank 交换后仍保留的非对称来源，或者 Current Loop 对 Rank 时差的响应不能只用电流负序幅值描述。

当前较合理的双来源工作模型为：

```text
ADC 串行采样时差
    -> 明确贡献部分 I/Psi 负序和 2fe

剩余的 U->I 或测量/控制链固定不对称
    -> 使纯电压新 Rank 下仍有约 2.59% I 负序
    -> 使闭环需要约 2.28% Ucmd 负序才能把测得 I 负序压低
```

`2.59%` 与 `2.28%` 在数量级上接近，使该模型具有解释力，但不能据此把原来的 `5.07%` 严格写成“约 `2.5%` 采样时差 + 约 `2.6%` 固定不对称”。负序是带相位的复数相量，各来源会按相位矢量叠加；此外，从电压负序到电流负序还经过电机阻抗和控制环传递函数，两个无量纲比值并非天然一比一对应。

### 25.6 更新后的来源候选与排查顺序

目前可以区分“已确认的重要来源”和“剩余来源候选”：

1. **ADC injected 串行采样时差**：Rank 干预已使纯电压 I 负序和闭环 Psi 负序同时减半，是已确认的重要来源；
2. **PWM 状态相关采样误差**：即使顺序交换，三相仍在不同开关时刻采样，可能形成固定的残余负序；
3. **实际 U->I 功率链不对称**：桥臂压降、死区、栅极驱动和实际端电压仍未直接测量；
4. **模拟测量链静态差异**：shunt、放大器、ADC gain/offset 可能与时序误差叠加，但 `Ia gain=1.10` 不能独立解决问题；
5. **电机本体不对称或凸极效应**：需要换方向、换速度或换电机进一步区分。

功率级不对称不再是第一嫌疑，但也不能因 Rank 实验而排除；它现在属于解释“剩余约 2%~3%”的主要候选之一。

### 25.7 下一步验证

1. 保存 `I/Ucmd/Psi` 正负序的复数实部、虚部或相位，不再只比较 `neg/pos` 幅值；
2. 对原 Rank、新 Rank 做 A-B-A 重复测试，确认 `I/Psi` 约 `49%` 的变化可逆；
3. 在多个 `We` 和正反转下观察负序复相量：采样时差分量应随电角速度和 Rank 顺序改变，固定硬件不对称更可能锁定在物理相坐标；
4. 测量或重构实际电机端相电压，与 `Ucmd` 分开分析，区分 SVPWM 前指令与逆变器后端电压；
5. 尝试缩短 injected sampling cycles、双 ADC 同步采两相并重构第三相，比较 I/Psi/Ucmd 三种负序的变化；
6. 在 ADC 时序改善后再做独立静态电流通道标定，不把 `Ia gain=1.10` 预先固化为产品参数；
7. `Psi` 和 PLL 的 `2fe` 未降到接管门限前，继续保持 observer shadow，不进行 takeover。

### 27.2 Ucmd 幅值与 Psi 幅值不存在简单单调关系


不同 Rank 会改变 I、Ucmd 负序复相量的幅值和相位；Observer correction 又是随磁链状态变化的非线性项。因此必须比较负序实部、虚部和相位，不能只比较 `neg/pos` 幅值。

### 28.3 固件实际离散时序

20 kHz 快环中每周期执行顺序为：

```text
采集 I[k]
    |
    v
Sensorless_Run
    Observer 使用 Motor_Run.U[k-1]
    Psi_pre[k] = Lambda[k-1] - Ls*I[k]
    Flux_Err[k] -> Corr[k]
    Lambda[k] / Psi[k] 更新
    |
    v
Current_Loop
    生成新的 U[k]
    |
    v
Plot_Fast_Sample
    保存 I[k], U[k], Psi[k], Theta[k]
```

正确离散方程为：

```text
Psi_pre[k] = Lambda[k-1] - Ls*I[k]

Corr[k] = 0.5*Gamma*(Flux^2 - |Psi_pre[k]|^2)

Lambda[k] = Lambda[k-1]
          + (U[k-1] - Rs*I[k] + Corr[k]*Psi_pre[k])*Ts

Psi[k] = Lambda[k] - Ls*I[k]
```

FAST Plot 同一行的 `U[k]` 与 `Psi[k]` 不属于同一次 Observer 更新。`sequence_correction_diag.py` 使用 Plot 末态 `U[k]/Psi[k]` 重建连续稳态相量，因此其大残差不能用于否定固件离散实现。

### 28.4 FAST block 的隐藏样本缺口

`Plot_Fast_Sample()` 每 `20` 个控制周期形成一个 ready block。若上一块仍未被 USB 线程消费，新完成的整块会被丢弃并增加 `Plot_Fast_Drop`。USB `Fast_Seq` 只在实际生成一个 FAST message 时递增，而且一个 20-sample block 还可能拆成多个 message。

因此可能出现：

```text

USB message seq: 351, 352, 353, 354 ... 仍连续
```

```text
dLambda measured RMS = 2.15588 V
prediction error RMS = 0.02410 V
relative error       = 1.118%
```

Psi FAST scale 为 `1 usWb/count`，单个 LSB 经 `Ts=50 us` 差分后对应：

```text
1 usWb / 50 us = 0.02 V
```

I、U 也分别以 `1 mA/1 mV` 量化。当前 `0.024 V` 残差已与量化经差分后的电压尺度接近，继续要求该日志达到 `0.1%` 没有实际诊断意义；需要更高精度或板端残差累计才能进一步收紧。

### 28.7 更新后的 Observer 结论边界

已经得到强证据确认：

- Observer 离散状态方程与代码实现一致；
- 一周期电压延迟 `U[k-1]` 正确；
- nonlinear correction 的执行顺序正确且不可省；
- 逐样本残差稳定为 `1.12~1.19%`，接近当前 FAST 量化能力。

正式撤回或降级：

- 不再用单个 `-j*We` 稳态负序相量严格验证 Observer；
- 不再把第 27.3 节的 `0.623/0.598 mWb` 幅值接近视为充分证明；
- 不再把该轮剩余 `19 deg` 相位差直接归因于 correction；
- `Flux Observer 数学错误`、`Observer pipeline 错一拍` 和 `correction 实现错误` 不再列为首要嫌疑。

该验证只证明内部离散更新与记录的 `Ucmd/I/Psi` 一致。它不证明 `Ucmd` 等于实际电机端电压，不证明 Rs/Ls/Flux 参数完全准确，也不证明 Observer 已达到 takeover 所需的物理估计精度。

## 29. 正式转向 Current Loop 的诊断方案

### 29.1 先修复 FAST 连续性判定

正式协议/诊断中应增加：

1. **必须：`Control_Tick`**。20 kHz ISR 每周期递增，并随 FAST sample 保存；只有 `Tick[k] == Tick[k-1] + 1` 的样本对才能用于离散差分；
2. **建议：`Plot_Fast_Drop`**。作为整轮丢失 block 的统计；
3. **建议：`Fast_Block_Seq`**。区分板端 ready block 与 USB message 序号。

block position 可由相对起始 tick（例如 `(Control_Tick-Control_Tick_Start) % 20`）或主机端分组派生，不必作为核心独立字段。当前“每 20 行跳过第一点”只适用于已知 block 结构的临时 host workaround。

### 29.2 Current Loop 内部信号分解

当前 PI 对象已经保存 `Sig.Ref/Fbk/Err/Out` 和 `State.Int`，D 默认为 `0`。下一轮至少记录：

| 处理阶段 | 信号 |
|---|---|
| 电流目标/反馈 | `Id_Ref/Id_Fbk/Id_Err`，`Iq_Ref/Iq_Fbk/Iq_Err` |
| PI 比例项 | `Id_P=Kp*Id_Err`，`Iq_P=Kp*Iq_Err`，可离线派生 |
| PI 积分项 | `Id_Ctrl.State.Int`，`Iq_Ctrl.State.Int` |
| PI 限幅前输出 | `Id_Ctrl.Sig.Out`，`Iq_Ctrl.Sig.Out` |
| 联合矢量限幅后 | `Motor_Run.Ud/Uq` |
| 坐标变换 | `Theta_IF` 或本周期实际 `Motor_Run.Theta_e` |
| alpha-beta 输出 | `Ualpha/Ubeta` |

必须同时保存 PI 输出和 `Vector2_Limit()` 后的 Ud/Uq，否则无法区分负序来自 PI 本体还是联合电压限幅。

### 29.3 三类判别结果

同步 dq 坐标中的 `2fe` 可以区分三类原因：

1. **Id/Iq error 本身有明显 2fe**：电流测量、角度、功率级或电机 plant 产生周期误差，PI 在正常补偿；
2. **error 较干净但 integrator 有明显 2fe**：检查 PI 离散状态、anti-windup、限幅和每轮初始积分状态；
3. **dq PI 输出较干净但 InvPark 后出现 alpha-beta 负序**：检查 Theta、SinCos、角度抖动或本周期角度所有权。

### 29.4 run-to-run 重复实验

在冻结的 `47.5 cycles + Ia->Ic->Ib + gain=1/1`、observer shadow 条件下，连续运行 `5~10` 次完全相同的测试。每轮统计：

- Id/Iq error 的 2fe 复相量；
- P/I contribution 的 2fe 复相量；
- PI 前后 Ud/Uq 的 2fe；
- Ualpha/Ubeta negative sequence；
- `Theta_flux - Theta_IF` 稳态均值和波动；
- PI integrator 初值、稳态值和是否触及限幅；
- `Control_Tick` 连续性与 `Plot_Fast_Drop`。

每轮 ALIGN 完成后代码会调用 `Current_Loop_State_Reset()`，按设计 Id/Iq integrator 应归零，但仍需用实测确认。I/F 使用固定 Iq reference 和强制 Theta_IF，转子真实磁链相对 I/F 的负载角可能在不同启动中收敛到不同稳态；该差异经过 Park、PI 和 InvPark 后可能显著改变 Ucmd 负序复相量。

### 29.5 当前工程决策

现阶段优先级调整为：

1. 修复 FAST 控制周期连续性证据；
2. 分解 Current Loop 的 dq error、P/I、限幅和 InvPark；
3. 通过 5~10 次重复运行判断负序与电流测量、PI state、I/F load angle 或实际 inverter voltage 中哪一项共同漂移；
4. 在实测证据支持前不调整 Observer Gamma、PLL 接管门或其他 Observer 参数；
5. 不再继续枚举 ADC Rank，也不把三相 closure `30%` 作为主要问题；
6. observer shadow 继续保持，不执行 takeover。

当前首要问题正式定义为：**为什么 I/F steady state 下 Current Loop 会产生约 `1~2%`、且运行间明显变化的 Ucmd negative sequence？**
