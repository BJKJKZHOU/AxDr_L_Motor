## 2. 方案背景

原 Voltage Align 在电流达到 `1 A` 后停止增加电压，但会继续保持当前
`Ualpha`。实测中电流在保持电压期间继续上升，约 `545.6 ms` 后触发
`2 A` 总保护：

```text
Ia max =  2.054 A
Ib min = -1.047 A
Ic min = -1.088 A
```

禁能时三相零点约在 `±0.16 A` 内，因此上述越限不是静态采样偏置导致的
误触发。这说明“达到目标电流后保持电压”不等于电流闭环，不能直接用于
未知电机的长时间 Align。

## 3. PROBE 后 Align 方案

新方案先用低电压交流激励获取粗略 Rs/Ls，再使用粗略参数设置临时电流环
执行 Current Align，最后完成正式的两段 Rs/Ls 测量。

```text
PROBE_RAMP
    100 Hz Ualpha 正弦激励，无直流分量
    Uac 每个完整周期增加 0.01 V
    Iac 目标 0.2 A
    Uac 最大 0.5 V
        |
        v
PROBE_MEASURE
    测量 5 个 100 Hz 周期
    同步提取复阻抗，获得 Rs_Rough/Ls_Rough
        |
        v
ALIGN
    按 Rs_Rough/Ls_Rough 设置临时 Id/Iq PI
    电流环带宽 200 Hz
    Id 目标 1 A，保持 0.5 s
        |
        v
RAMP
    Ualpha = Uhold + Uac * sin(2*pi*100*t)
    Iac 目标 0.4 A
    Uac 最大 1 V，每周期增加 0.005 V
        |
        v
SETTLE -> MEASURE_A -> MEASURE_B -> DONE/FAILED
```

临时 PI 参数按下式计算：

```text
Wc = 2*pi*200
Kp = Ls_Rough*Wc
Ki = Rs_Rough*Wc
```

Align 结束、辨识失败或中止时恢复原 Id/Iq PI 参数。`DISABLE` 在辨识过程中
仍可以关闭 PWM 并中止辨识。

## 4. 测试方法

普通辨识及阶段观察使用：

```bash

    --port /dev/ttyACM0 \
    --identify rs_ls \
```

第一次完整测试同时通过 USB Plot 采集：

`10 ms` 轮询一次。测试结束后发送 `DISABLE`，再读取辨识状态和 Vbus。

## 7. 结论和后续校验

`a2835b5` 的 PROBE 后 Align 方案实机测试通过：

- PROBE 低电压激励可以得到可用的粗略 Rs/Ls；
- 可以用粗略参数建立临时电流环并将 Id 稳定在约 `1 A`；
- 所有预期辨识阶段均可以进入；
- 三次辨识均成功，Rs/Ls 重复性良好；
- 全过程保持在 `2 A` 总保护以下。

由于 PROBE 命令电压只有约 `0.05 V`，死区、器件压降和逆变器低电压非线性
可能影响 Rs/Ls 绝对精度。当前结果可作为电流环初始参数，后续建议：

1. 用四线法或可靠微欧计测量线间电阻，换算并校验相电阻；
2. 检查 PWM 死区和器件压降对低电压正弦激励的影响；
3. 在不超过电流限制的前提下，对不同激励幅值和频率的辨识结果进行对比。

## 8. 正式辨识工作点扫描

### 8.1 目的和参数

通过改变正式 RAMP 的交流电流目标，检查 Rs 是否因逆变器固定压降或 PWM
死区而随电流增加明显下降，同时检查 Ls 是否随电流变化。

扫描过程中保持以下参数不变：

```text
PROBE Iac target = 0.2 A
ALIGN Id target  = 1.0 A
激励频率         = 100 Hz
Vbus             ≈ 14.5 V
相电流总保护     = 2 A
```

为减少低电压工作点的量化误差，测试固件临时将正式 RAMP 的电压步进从
`0.02 V/周期` 改为 `0.005 V/周期`。分别构建：

```text
Iac target = 0.2 A
Iac target = 0.4 A
Iac target = 0.5 A
Iac target = 0.6 A
```

`0.5 A` 工作点用作进入 `0.6 A` 前的安全检查。每个工作点的详细采集轮
同时记录 `Ia/Ib/Ic/Id`、阶段转换、实际 Iac 和相电流峰值。最终 Uac
根据 RAMP 阶段时间和每周期 `0.005 V` 的步进推算，不确定度约为
`±0.005 V`。

### 8.4 工作点趋势分析

`0.2 A` 和 `0.4 A` 工作点的 Rs 平均值分别为 `0.076661 ohm` 和
`0.076631 ohm`，两者只相差约 `0.04%`。`0.6 A` 工作点的 Rs 平均值为
`0.079648 ohm`，比 `0.4 A` 结果高约 `3.9%`。

本次扫描没有出现“低电流 Rs 偏高，随电流增加而下降”的趋势，因此当前数据
不支持存在显著的逆变器固定压降或死区导致的 Rs 工作点偏差。`0.6 A`
结果略高，且该组内部极差为 `3.78%`，更可能与绕组温升或测量离散有关。

Ls 没有随电流增加而下降，所有工作点整体保持在约 `17 uH`。未观察到
明显的磁饱和趋势，当前 SPMSM 第一版使用单一 Ls 模型是合理的。但低电流
`0.2 A` 组的 Ls 离散度较大，说明该工作点的信噪比和相位误差仍需要注意。


```text

RS_LS_AC_U_STEP_V   = 0.005 V/周期
```

`0.4 A` 工作点在重复性和 2 A 保护余量之间表现最好，因此作为正式默认值。

## 9. 辨识结果 Apply

辨识完成后结果不会自动覆盖电机参数，也不会自动写入 Flash。只有在：

```text
Servo = DISABLED
Identification = DONE
Result.Valid = true
```

时，显式执行 `IDENT APPLY` 才会把结果应用到 RAM：

```text
Motor_Para.Rs = Result.Rs
Motor_Para.Ld = Result.Ls
Motor_Para.Lq = Result.Ls
```

随后按照当前默认电流环带宽重新计算 Id/Iq PI：

```text
Kp_d = Ld * Wc
Ki_d = Rs * Wc
Kp_q = Lq * Wc
Ki_q = Rs * Wc
```

命令行入口：

```bash
python3 tools/control_test.py --port /dev/ttyACM0 --ident-apply
```

Apply 只修改 RAM。Flash 持久化留到新参数下的 Current Loop 实机验证完成后
再单独实现。

## 10. Apply 后低电流电流环验证

### 10.1 测试条件

在一次完整 `RS_LS` 辨识并执行 `IDENT APPLY` 后，通过 USB 运行原
Open Loop 路径。该次辨识结果为：

```text
Rs = 0.0752737 ohm
Ls = 15.9588 uH
IDENT_APPLY OK
Vbus = 14.47 ~ 14.50 V
```

Open Loop 仍使用原固定参数：

```text
ALIGN: Id_Ref = 0.2 A, Iq_Ref = 0 A, 0.5 s
RUN:   Id_Ref = 0 A,   Iq_Ref = 0.2 A, We = 20 rad/s electrical
```

USB FAST 以 `20 kHz` 同步采集 `Id/Iq/Ud/Uq/Ia/Ib/Ic`。为区分开关和
采样纹波与控制环低频振荡，分析时另外对原始数据做 `1 ms` 分组均值；该处理
只用于离线分析，不改变 FAST 采样率。

### 10.2 实测结果

| 阶段 | 信号 | 均值 | 1 ms 误差 RMS | 1 ms min/max |
|---|---|---:|---:|---:|
| ALIGN | Id | 0.19997 A | 8.46 mA | 0.1753 / 0.2255 A |
| ALIGN | Iq | -0.00001 A | 10.06 mA | -0.0290 / 0.0245 A |
| RUN | Id | 0.00001 A | 9.41 mA | -0.0304 / 0.0410 A |
| RUN | Iq | 0.19995 A | 9.49 mA | 0.1639 / 0.2332 A |

电压矢量峰值为 `0.0835 V`。按实测母线电压计算，电流环电压限幅约为
`7.94 V`，峰值只占限幅的 `1.05%`，没有电压饱和。

`700 ~ 1300 Hz` 范围内的 Id/Iq 最大离散谱峰约为 `3 ~ 4 mA`，未观察到
持续的 `1 kHz` 电流环振荡。原始瞬时电流纹波明显大于 `1 ms` 均值误差，
说明主要成分来自 ADC/PWM 采样纹波，而不是低频发散。

三相电流峰值为 `0.483 A`，没有单相异常。`Ia + Ib + Ic` 的 `1 ms` 均值
RMS 为 `34.3 mA`，仍存在可见的三相采样误差，后续测试继续观察。

该阶段结论为：辨识参数 Apply 后，原固定角度 Align 和低速 Open Loop 电流
环工作正常，当前 `1 kHz` 设计带宽没有表现出过激或电压饱和。


当前 I/F 路径没有辨识路径中的 `2 A` 总电流硬限制，因此第一轮使用主机侧

### 11.2 第一次启动中止和原因

第一次 `SENSORLESS START FORWARD` 后约 `24 ms`，USB FAST 检测到：

```text
max(abs(Ia), abs(Ib), abs(Ic)) = 11.078 A
```

主机立即执行：

```text
SENSORLESS_STOP
DISABLE
PLOT_STOP
```

电机没有进入 IF/ACCEL。停止后状态为 `active=0`、`We_IF=0`，USB 通信和
辨识结果保持正常。

PWM 禁用状态下继续通过 USB Plot 读取到：

```text
Ud = +5.63 V
Uq = -5.63 V
sqrt(Ud^2 + Uq^2) ~= 7.96 V
```

该值正好接近当时的电压矢量限幅。原因是 PWM 禁用期间 `Current_Loop()` 仍以
零参考运行，采样偏差使 PI 积分逐渐累积；原 `Servo_Enable()` 会在使能 PWM
前清零 Id/Iq PI，而新的 Sensorless 启动路径在 `PWM_Enable()` 前没有清零。
原代码只在 `ALIGN -> IF` 切换时清零，无法避免启动瞬间把已饱和的 PI 输出加到
电机上。

### 12.2 结束过流问题定位：FAST_OFF 不等于 PWM Hi-Z

Flux 四点测量和回归首次跑通后，结束阶段曾出现间歇性 `FAILED`。回归
数据本身正常，但结果会在完成后被 `2 A` 辨识保护清除。通过连续三版
固件和 FAST `20 kHz` 原始波形，最终将问题定位到 `FAST_OFF` 的软件语义
与功率级真实状态不一致。

三阶段结果为：

| 固件 | 结束处理 | 结束窗口相电流峰值 | 结论 |
|---|---|---:|---|
| `0981105` | Iq 按 `20 A/s` 降到 0，随后返回 `FAST_OFF` | 记录到 `7.452 A` | 收流正常，但 `FAST_OFF` 后仍输出零矢量 |
| `2305372` | `2 kHz` Motor Control 发现辨识完成后关闭 PWM | `2.618 A` | 零矢量窗口缩短，但仍存在约 `150 us` 调度延迟 |
| `f58ac04` | `20 kHz` ADC 快环在 `FAST_OFF` 同周期关闭 PWM | 五次最大 `0.403 A` | 立即进入 Hi-Z，结束尖峰消失 |

#### 12.2.1 第一次记录：收流成功后电流反而上升

`0981105` 已经加入 FINISH Iq 斜坡。高速记录确认该斜坡本身正常：

```text

Iq decrease             = 20 A/s
phase current <= 0.2 A  = 40 consecutive samples = 2 ms
```

样本 `386568~386607` 连续满足三相电流不超过 `0.2 A`，随后 Flux 状态
进入 DONE。电流环停止后的逐周期结果为：

```text

sample 386609  phase peak = 0.564 A
sample 386610  phase peak = 1.732 A
sample 386611  phase peak = 2.417 A
sample 386627  phase peak = 7.452 A
```

`Ia` 在 `-7.452 A` 连续多个样本保持相同读数，说明 ADC 已经出现削顶，
因此 `7.452 A` 是记录到的峰值，实际瞬时电流可能更高。与此同时，
`Id/Iq/Ud/Uq` 停在最后一个电流环周期的值，不再更新，证明电流环已经
退出，异常电流不是 Iq 斜坡跟踪误差。

当时 `Motor_Fast_Run()` 返回 `FAST_OFF` 时，只把 `Id_Ref/Iq_Ref` 和
`Ualpha/Ubeta` 清零。旧版 `ADC_Run()` 仍继续执行：

```text
SVPWM_Calc(0, 0, Vbus)
PWM_Update(0.5, 0.5, 0.5)
```

三相 Duty 相等只表示线电压指令为零。只要 TIM1 的 MOE 和输出通道仍然
开启，逆变器就在主动施加零矢量，电机三相端子被周期性连接到同一母线
电位。对于仍在旋转并产生反电势的 PMSM，这是短路制动状态，不是功率级
高阻态。因此：

```text
FAST_OFF != Ualpha/Ubeta 继续送入 SVPWM
0 V SVPWM != PWM Hi-Z
```

#### 12.2.2 第二次记录：慢速关闭 PWM 仍有调度窗口

`2305372` 将特殊模式的 PWM 生命周期与 Motor State 对齐：辨识完成后，
`2 kHz` Motor Control 调用 `PWM_Disable()`，再从 RUN 回到 ENABLED。
该修改将异常电流持续时间显著缩短，但 FAST 波形仍记录到：

```text
sample 386816  phase peak = 0.645 A
sample 386817  phase peak = 1.652 A
sample 386818  phase peak = 2.618 A
sample 386819  phase peak = 0.081 A
```

这三个上升样本正好对应约 `150 us` 的零矢量窗口；`PWM_Disable()` 生效后，
电流立即恢复到零点附近。结果证明慢速任务最终确实进入了 Hi-Z，但
`20 kHz` 快环进入 DONE 与下一次 `2 kHz` Motor Control 之间的调度延迟
仍足以触发 `2 A` 保护。

#### 12.2.3 最终修复：快环同周期释放 PWM

`f58ac04` 在 `ADC_Run()` 中明确解释 `FAST_OFF`：如果 Motor State 仍为
RUN，则立即调用 `PWM_Disable()`，记录 FAST 样本后直接结束本周期，不再
执行 `SVPWM_Calc` 和 `PWM_Update`。`2 kHz` Motor Control 只保留状态收尾
职责，不再承担安全关键的首次 PWM 释放时刻。

修复后的高速先导测试和后续五次正式测试均正常完成。五次 DONE 前
`30 ms` 至后 `100 ms` 的相电流峰值为 `0.282~0.403 A`，没有再次出现
结束上升尖峰。

该问题最终确认了控制层接口必须区分两个物理含义：

- 零电压矢量：功率级仍在线，三相 Duty 相等，电机端子不是 Hi-Z；
- PWM Hi-Z：关闭 MOE/输出通道，逆变器释放电机端子。

`FAST_OFF` 如果要表达“释放功率级”，必须由 ADC/PWM 执行层在同一个
快环周期落实为真正的 `PWM_Disable()`，不能仅依靠零电压指令或等待
低频状态任务处理。

### 13.4 `+/-81 deg` 角差的坐标解释

`Theta_obs - Theta_IF` 的 `+/-81 deg` 不能直接称为 `81 deg` 的负载角，
也不能据此判断 Observer 固定错了 `90 deg`。

当前 I/F 使用 `Theta_IF` 作为 Park 角。在 `Id_ref = 0` 时，定子电流矢量
相对 Park 角主要由 Iq 决定：

```text
正转，Iq_ref > 0:
Theta_Is  ~= Theta_IF + 90 deg
Theta_obs ~= Theta_IF + 81 deg
Theta_Is - Theta_obs ~= +9 deg

反转，Iq_ref < 0:
Theta_Is  ~= Theta_IF - 90 deg
Theta_obs ~= Theta_IF - 81 deg
Theta_Is - Theta_obs ~= -9 deg
```

因此，正反转的转子磁链与定子电流矢量夹角幅值都约为 `9 deg`。这一关系
对于当前 I/F 稳态是合理的。`+81 deg/-81 deg` 高度对称，反而支持 Park
坐标、Observer 角度和旋转方向的符号关系正确。

### 13.5 停机单点快照不能代表稳态

连续采集前曾在 STOP/DISABLE 后通过调试器读到两个保留末帧：

```text

reverse We_obs snapshot = -115.33 rad/s
```

这些值只能证明 Observer/PLL 状态为有限值且方向基本正确。STOP 后观测器
不再更新，而单个末帧可能位于周期纹波的任意相位，因此不能用于评价稳态
速度误差或锁定质量。

连续数据给出的稳态均值为 `+119.9820`、`+119.9829` 和
`-120.0336 rad/s`，应以这些窗口统计替代停机单点快照结论。

### 13.6 周期纹波和模型误差

三次稳态 `We_obs` 的主频均为 `37.98 Hz`。在
`abs(We_IF) = 120 rad/s` 时，电角频率约为：

```text
fe = 120 / (2 * pi) = 19.10 Hz
2 * fe              = 38.20 Hz
```

因此当前速度纹波的主峰接近二倍电角频率。PLL 已经正确跟踪 DC 速度，
但会将 Observer 角度中的周期误差反映到速度估计。后续需要分别检查电压
模型误差、逆变器死区和压降、相电流采样不对称以及 PLL 带宽；当前数据
只确认二次谐波现象，不单独指定根因。

稳态 `Flux_Err / Flux^2` 约为 `-3.0%~-3.16%`。由于当前定义为：

```text
Flux_Err = Flux_ref^2 - PsiAlpha^2 - PsiBeta^2
```

负值表示观测磁链幅值略高于辨识得到的 Flux 参考值。这是下一步模型误差
校准的另一个量化依据。这里的百分比是平方磁链误差，不是磁链幅值误差：

```text
abs(Psi) / Flux_ref = sqrt(1 - Flux_Err / Flux_ref^2)
```

例如 `Flux_Err / Flux_ref^2 = -3.16%` 时，磁链幅值约偏高 `1.57%`，
不能直接表述为磁链幅值偏高 `3.16%`。三次正反转结果接近，现阶段更像
固定模型偏差，而不是 Observer 发散。

分量，不是频谱底噪。

`Flux_Mag`、`Flux_Err` 和 `PLL_Err` 都在 PLL 输出速度之前出现相同频率，
所以当前 `2fe` 不能归因于 PLL 独立产生的随机噪声。PLL 带宽只决定它将
已有角度纹波传递到 `We_obs` 的程度。

### 14.5 I/F 坐标重建和 alpha-beta 椭圆拟合

使用同步 `Ia/Ib/Ualpha/Ubeta/Theta_IF` 离线重建 I/F 坐标：

| 信号 | 正转均值 | 正转 2fe 幅值 | 反转均值 | 反转 2fe 幅值 |
|---|---:|---:|---:|---:|
| `Id` | +0.00488 A | 0.01992 A | -0.00491 A | 0.01078 A |
| `Iq` | +1.59896 A | 0.01678 A | -1.59905 A | 0.00436 A |
| `Ud` | -0.37534 V | 0.04059 V | -0.37865 V | 0.02209 V |
| `Uq` | +0.25666 V | 0.03422 V | -0.24921 V | 0.00879 V |

进一步将各 alpha-beta 矢量幅值拟合为：

```text
Mag = Mean + A2 * cos(2 * Theta_vec - Phase2)
```

结果为：

| 矢量 | 正转 A2/Mean | 正转 Phase2 | 反转 A2/Mean | 反转 Phase2 |
|---|---:|---:|---:|---:|
| `Ialpha/Ibeta` | 1.172% | +104.19 deg | 0.307% | +63.61 deg |
| `Ualpha/Ubeta` 指令 | 10.522% | +172.21 deg | 5.241% | -9.71 deg |
| `PsiAlpha/PsiBeta` | 0.372% | +12.35 deg | 0.094% | +44.39 deg |

最显著特征是电压指令椭圆二次项在正反转之间相差约 `181.9 deg`，并且
幅值相差约两倍。如果只是固定的 alpha-beta 电流或电压比例误差，按矢量
自身角度拟合时通常应在正反转保持近似相同的椭圆主轴；当前结果与这一
简单模型不符。

该方向相关性更支持优先检查随相电流方向变化的逆变器死区、MOS/二极管
压降以及电流 PI 对实际端电压误差的补偿。但本轮采到的
`Motor_Run.Ualpha/Ubeta` 是电流环指令电压，不是示波器测得的电机端电压，
因此它只能作为强线索，不能单独证明死区或器件压降就是唯一根因。

### 14.6 当前结论

本轮专项采集将问题范围进一步缩小：

- NLOB 状态积分、正反转符号和 PLL 平均速度继续 PASS；
- 磁链实际幅值偏差约 `+1.7%~+1.8%`，没有发散迹象；
- `2fe` 同时存在于电压指令、电流、磁链幅值、PLL 误差和速度估计中；
- 磁链幅值具有明确 `2fe`，说明周期误差在 PLL 之前已经存在；
- 正反转幅值明显不对称，且电压指令椭圆相位近似翻转，优先指向
  电流方向相关的逆变器非线性或其电流环补偿；
- 当前数据仍不足以排除电流采样比例、Ld/Lq/饱和或其他模型误差；
- 继续冻结 Gamma、PLL 带宽和 NLOB 数学模型，不用调参掩盖现象；
- Observer takeover 仍为 NOT READY。
